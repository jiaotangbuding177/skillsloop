# 合同整体风险审阅与批注生成

## 触发

- 用户提供了一份待审阅的完整合同文档。
- 用户明确了审阅的商业立场（例如"代表委托方"、"代表买方"等角色定位）。
- 用户希望输出带修订痕迹和批注的合同文档。

## 输入

- **合同文档**：用户提供的完整合同文本（支持文本格式；若为扫描图片/PDF，需先完成文本提取，本技能不直接处理图片OCR）。
- **审阅立场**：明确的商业角色定位，例如"代表委托方"、"代表甲方"等。
- **业务背景要求**（可选）：用户补充的业务关注点、风险偏好或特定条款关注方向。

## 步骤

### 步骤 1：从指定商业立场识别不利条款和重大风险

<!-- SKILLSLOOP_METHOD:m1 -->

**操作**：基于用户给定的审阅立场，通读合同全文，逐条扫描并识别对委托方不利的条款、失衡的权利义务分配、以及可能构成重大风险的表述。

**参数**：
- 立场类型：用户指定的商业角色定位。

**条件**：已明确审阅立场；合同文档文本可读。

**完成检查**：
- 输出一份风险条款列表，列明每条风险对应的合同条款位置或编号。
- 输出一份风险说明，逐条解释风险性质、可能的不利影响及关注理由。
- 如合同中某些章节因格式或提取质量问题无法读取，应在结果中明确标注范围受限，不对未读取部分做风险结论。

**限制说明**：具体风险识别效果取决于合同文本质量与立场描述的充分程度，未作经验证的效果承诺。

### 步骤 2：将风险点转化为修订痕迹和批注，输出文档

<!-- SKILLSLOOP_METHOD:m2 -->

**操作**：基于步骤 1 输出的风险条款列表与风险说明，针对每条风险生成对应的修订建议（以修订痕迹形式体现修改方向）及批注（说明修改理由和风险提示），并整合为一份完整的输出文档。

**参数**：
- 修订模式：例如"建议性修订"或"强制替换"（默认以建议性修订为主，保留原文对比）。
- 批注格式：例如"侧边批注"或"行内批注"（默认采用侧边批注形式）。

**条件**：步骤 1 已完成风险识别，且风险条款列表可用。

**完成检查**：
- 输出一份文档，包含原始合同文本、修订痕迹、以及对应批注。
- 每条修订痕迹可追溯到步骤 1 中的风险条款。
- 若因技术条件限制无法生成标准 Word 修订格式，则以纯文本或 Markdown 对比形式呈现修订与批注，并在输出中说明格式替代方案。

**限制说明**：文档最终生成质量取决于合同原文的结构化程度和输出工具的能力；本步骤承诺文本流程，不保证特定格式的完美呈现。

## 输出

- 带修订痕迹和批注的合同文档（格式依可用工具而定，可能为 Word 修订模式、Markdown 对比或纯文本标注）。

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 立场类型 | 审阅所代表的商业角色 | 无（必须由用户提供） |
| 风险关注级别 | 对风险严重程度筛选的阈值（高/中/低） | 中及以上 |
| 修订模式 | 修订痕迹的呈现方式 | 建议性修订 |
| 批注格式 | 批注的位置与样式 | 侧边批注 |

## 前提条件

- 用户必须提供可读取的合同文本。
- 用户必须明确审阅立场。
- 若合同为扫描件或图片格式，需先完成文本提取（不在本技能范围内）。

## 完成检查

- [ ] 已基于指定立场输出风险条款列表。
- [ ] 已为每条风险提供说明。
- [ ] 已将风险转化为修订痕迹。
- [ ] 已为每条修订添加批注。
- [ ] 已整合为完整输出文档并交付用户。

## 限制

- 具体风险识别效果未验证，不对识别准确率做承诺。
- 文档生成质量未验证，不对最终格式完美度做承诺。
- 本技能不替代专业法律意见，输出仅供内部审阅参考。
- 不对未读取的合同部分做任何风险结论。
- 若工具能力不支持标准修订格式，将以替代文本形式呈现。

## 市场信息

### 适合人群

- 企业法务、合规人员需要在签约前快速审阅合同并标注风险。
- 商务人员在谈判前需要站在己方立场识别合同中的不利条款。
- 律师助理或项目管理人员需要批量处理合同审阅任务、生成标准化的修订与批注版本。

### 核心亮点

- 以指定商业立场为锚点，系统性地扫描合同全文中的不利条款，避免遗漏关键风险。
- 将风险识别与修订批注生成整合为一体化流程，减少多轮人工转换。
- 输出文档可直接用于内部评审或外部谈判沟通，提升合同审阅效率。
- 支持按风险关注级别筛选，聚焦重要风险而非陷入细节。

### 典型输入/需求

- 一份完整合同文本（Word、PDF 文本层或纯文本格式）。
- 明确的审阅立场描述，如"代表委托方/甲方/买方"。
- （可选）业务背景说明，例如"重点关注付款条款与违约责任"、"关注知识产权归属"。
- （可选）修订模式和批注格式的偏好。

### 输入预填模板

```
合同文档：[粘贴或引用合同全文]
审阅立场：[例如：代表委托方]
业务背景要求：[例如：重点关注付款条件、知识产权归属和违约责任条款]
风险关注级别：[高/中/低，默认：中及以上]
修订模式：[建议性修订/强制替换，默认：建议性修订]
批注格式：[侧边批注/行内批注，默认：侧边批注]
```

### 预期输出/成果

- 一份风险条款列表，列明每条风险的合同位置和简要描述。
- 一份风险说明，逐条解释风险性质和关注理由。
- 一份带修订痕迹和批注的合同文档，修订痕迹体现修改方向，批注说明修改理由。
- 输出文档可直接用于团队内部评审或与对方进行条款谈判。
