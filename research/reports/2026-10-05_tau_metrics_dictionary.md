# τ²-bench 指标怎么读

日期：2026-10-05。适用于本轮远端快照的零售148 v4、航空267 v1、电信268 v1。实际数值见[实验分析报告](2026-10-05_tau_remote_results_analysis.md)及独立复算表。

这里的“无技能”与“有技能”是 AutoSkill 强基线的两个评测条件。当前三域实验没有加入我们新实现的轨迹恢复与工作流聚合算法。

| 指标 | 它回答什么 | 怎么算／具体例子 | 解读限制 |
| --- | --- | --- | --- |
| 任务数与场次数 | 测了多少种问题、重复了多少次？ | 零售40题，每题4次，每组160场。 | 160场不是160道独立题；不同题还可能共享订单或故障模板。 |
| 完整评分场次 | 有多少场得到可用结果？ | 查看原始结果里是否有奖励、终止信息，以及任务与重复编号是否齐全。 | 保存完整结果不等于整个运行期间没有基础设施失败或重试。 |
| 单次任务成功率 | 正常执行一次，有多大机会真正完成目标？ | 零售无技能126/160=78.75%，有技能134/160=83.75%。本批奖励只有0和1，均值与成功率相同。 | 按数据库或环境验收，不能用回复听起来不错代替。 |
| 配对收益（百分点） | 同一批任务加技能后总表现变了多少？ | 83.75%−78.75%=+5个百分点。 | 不等于相对提升5%，也不保证未来一定增加5个百分点。 |
| 同题同次的改善／退步／持平 | 技能帮助了谁，又影响了谁？ | 零售20场从失败变成功、12场从成功变失败、128场结果相同。 | 相同重复编号和种子不代表模拟用户在两组产生了完全相同的对话。 |
| 逐题改善／退步／持平 | 改善是否分布在多个任务？ | 每道题先平均4次，再比较两组；一题从1/4变3/4，是任务层改善。 | 用于找瓶颈，不能只展示改善题。 |
| 四次都成功的任务比例 | 是否可以稳定地做好同一件事？ | 零售22/40→25/40。若一题只有1次成功，不能称稳定掌握。 | 4次仍是有限重复，单种子计划不能代替更多独立条件。 |
| 四次至少一次成功 | 多试几次有没有可能做对？ | 4次里成功1次也计入。 | 它较乐观，不能当作正常一次执行的成功率。 |
| pass^k：重复k次全部成功 | 多次一致成功的概率估计是多少？ | 在每题已保存的4次结果中，计算抽取k次都成功的比例后平均。 | 与“k次至少一次成功”的pass@k不同；专业符号不能混用。 |
| 配对检验p值 | 观察到的改善和退步差异，是否足以支持非零效果？ | 在有差异的配对中计算精确二项／McNemar检验；零售p约0.215。 | 重复场次有相关性，场级p只作辅助；p较大不证明方法没用。 |
| 任务级置信区间 | 当前数据允许的收益范围有多宽？ | 按任务为组抽样重算差值。零售区间跨过0。 | 区间含0说明目前未能排除零收益；不是未来收益保证，也未消除共享实体关联。 |
| 数据库／环境／告知信息检查 | 为什么某场失败？ | 航空查看数据库目标和必须告知的信息；电信查看设备状态和目标连通性。 | 技术动作成功不必然让任务成功；不同域的验收内容不同。 |
| 平均／中位／P95耗时 | 完成任务有多慢？慢任务是否很多？ | 平均看总体；中位看典型场次；P95表示95%的场次不超过该时长。 | 混入网络等待、模型响应及模拟用户开销；不直接等于人类劳动时间。 |
| 对话和工具调用数 | 是否绕了更多弯、进行了更多操作？ | 统计最终保存的会话消息与业务工具调用，区分客服和模拟用户侧。 | 不把技能文件读取混成业务操作；更多调用不等于必然更好或更贵。 |
| 技能读取触发率 | 是否发起了读取技能的动作？ | 远端审计报告航空80/80、电信160/160。 | 原扫描器不校验读取成功或全文；原生归档没上传时，不能独立复验。 |
| 全文读取与实际遵循 | 模型究竟获得并使用了哪些条款？ | 需原生工具返回和后续行为证据。 | 本轮航空／电信固定快照不含原生sqlite，全文读取未知；调用不等于遵循。 |
| 演化来源成功／失败／异常 | 学习材料中有哪些质量与结果差异？ | 航空19成功＋7失败；电信53成功＋17失败。 | 失败经历也可以有学习价值；不能用总分给其中每一步自动判对错。 |
| 学习输入是否含结果评价 | 学习器能否看到真实成败？ | 检查实际提取文件／脚本是否包含评分和评价对象。 | 结果存在于采集文件，不代表它进入了学习器。 |
| 技能数、资源数和字节量 | 库有多大、是否膨胀？ | 航空1个技能；电信1个技能＋29参考文件。 | 文件多、版本多不能证明有效；空参考文件需单列。 |
| 全实验请求数 | 这次探索总共调用了多少资源？ | 从独立实验账本按路由计数，包含哪些阶段必须注明。 | 不能直接当有技能组的成本，账本可能包含dev、采集、学习和重复尝试。 |
| 模型token、金额、每成功任务总成本 | 技能是否降低真实费用？ | 需要模型用量、单价与阶段归属，再把生成和维护成本摊入成功任务。 | 新两域账本缺usage／金额；原结果里cost=0不能证明免费，因此本轮标为未知。 |

论文主表建议优先保留：**单次成功率、配对差值和区间、四次全部成功、耗时、读取证据口径**。其他指标用于解释变化与确认实验有效性，不必把所有指标都变成主要研究结论。
