# 设备侧“无服务”排障清单

在确认账号侧（线路 Active、账单 Paid、无流量封顶）健康后，按顺序执行，每步只让用户做一个动作并回收读数：

1. **飞行模式**：状态栏出现 ✈️ → 关闭；回收状态栏。
2. **SIM 状态**：读取 Active / Missing / Locked；非 Active 或排查需要 → 重新插拔 SIM；回收状态栏。
3. **APN 设置**：读取 APN 名称；非标准值（如 broken）判为 Incorrect → 重置 APN 并**重启**（重置在重启后生效）；回收状态栏。
4. **网络模式偏好**：确认为 4G/5G preferred 等合理值。
5. **流量核对**：`data_used_gb < data_limit_gb` 才排除封顶。

成功判据：状态栏出现信号格（如 Excellent）、网络类型（如 5G）、数据 Enabled。
若全部步骤穷尽仍无服务：标注未解决，建议转人工或更换 SIM。
