# Mobile Data Troubleshooting Checklist

1. Identify customer and active line.
2. Check line status: Active / Suspended.
3. Check data usage vs. plan limit; refuel if exceeded.
4. Check roaming flag; enable if abroad and disabled.
5. Ask for reboot/reconnect and read status bar.
6. If airplane mode on -> guide user to turn it off.
7. If data disabled -> guide user to enable mobile data.
8. If network mode is 2G or slow -> set preferred network to 4G/5G.
9. Re-run speed test after each change.
10. Confirm success only when speed test is good/excellent and data is enabled on 4G/5G.
