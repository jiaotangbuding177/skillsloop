# Mobile Data Diagnostic Ladder

Run in order; re-read device status/speed after each change and only advance when confirmed.

1. Verify account by phone number; confirm the affected line (ignore suspended/unrelated lines).
2. Data usage vs plan limit -> if over, offer priced refuel (state per-GB rate and per-request max); execute only after confirmation.
3. Reboot network services to apply changes (reassure: does not delete photos/contacts/messages/apps).
4. Device/network status: airplane mode OFF, SIM active, cellular connected, signal good, network type modern (not 2G).
5. Network mode preference -> set to 4G/5G preferred if legacy.
6. VPN -> disconnect if present.
7. Data Saver / data-limiting mode -> turn OFF.
8. Roaming state -> confirm it matches the customer's actual need.
9. Re-run speed test -> confirm target quality label before closing.

Fallback: if the target is still unmet after the full ladder, be transparent and escalate instead of claiming success.
