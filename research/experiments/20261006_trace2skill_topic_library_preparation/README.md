# 按现有主题建立Trace2Skill强基线：来源准备

日期：2026-10-06。**只完成本地准备，尚未运行模型或生成技能。**

唯一数据版本为[当前主题数据集](../../datasets/evomind/task_topics_20261006/README.md)，与原柱状图一致：1224场会话＝716保留＋508暂存；719条局部学习片段，分到12个明确主题；另有6场目标尚不明确会话，没有候选片段。此前排除的242场不进入本版。

完整方案、原算法流程及真实任务例子见[强基线方案](../../reports/2026-10-06_trace2skill_all_topic_library_baseline.md)。每个主题多个技能通过预先定义多个目标任务族、分别运行完整Trace2Skill来组织；这层实验分组不是作者自带的自动技能发现，也不用我方workflow聚类替代原补丁合并。

本次交付：

- [各主题来源统计CSV](topic_preparation_statistics.csv)：会话及候选数、来源会话数、消息成员数和文字量。消息按候选成员统计，不是全库唯一消息。
- [719条候选来源索引](private/candidate_registry.jsonl)：当前主题、已有任务标签、原分区行号和消息成员编号。任务族尚未指定，结果尚未裁定，没有创建模型作业。
- [版本与来源指纹](manifest.json)：32个源文件指纹、合同案例的当前LEGAL身份映射、2个数据输出指纹和0模型/0新rollout/0技能状态。
- [免费准备过程核对](local_preparation_verification.json)：记录首次旧主题字段误用及后续修正、来源数量与交叉核对边界。
- [准备脚本](prepare_registry.py)：只读取现存分类建立索引；没有任务识别、轨迹恢复、聚类或模型调用。输出已存在时拒绝覆盖。

两条上轮合同案例确实在当前LEGAL分区中；本目录只登记当前来源，没有加入051恢复版本作为额外输入。分类使用当前 `research_annotations.task_topic`，不使用129处未同步的旧质量画像主题。来源数据本轮没有修改。

后续还需固定任务族、一次任务执行的边界及评价证据、初始化方法与领域验证接口。作者公开脚本绑定表格；覆盖全部主题需要明确最小领域适配而完整保留原算法。该范围已向用户澄清，当前不执行依赖其答案的付费生成。

来源登记经独立只读复算：13主题/1224会话/719候选、全部候选ID与成员、32源指纹及2输出指纹匹配；来源均在当前主题数据树内。此处通过只证明来源登记准确，不是完整轨迹、任务成败或技能效果验收。
