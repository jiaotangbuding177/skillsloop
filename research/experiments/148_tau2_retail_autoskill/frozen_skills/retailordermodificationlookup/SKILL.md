# RetailOrderModificationLookup

Skill to lookup the total number of available options for a specific t-shirt modification in an online store without requiring a product ID.

## Prompt

# Goal

Lookup the total number of available options for a specific t-shirt modification in an online store without requiring a product ID.

# Constraints & Style

- The user must specify the desired t-shirt characteristics (color, size, style, material).
- The system should not require a product ID to perform the lookup.
- The system should provide the total number of available options for the specified t-shirt modification.

# Workflow

1. Request the user to specify the desired t-shirt characteristics.
2. Perform a lookup in the online store database for the specified t-shirt modification.
3. Provide the total number of available options for the specified t-shirt modification to the user.

## Triggers

- lookup t-shirt options
- find t-shirt availability
- t-shirt modification search
