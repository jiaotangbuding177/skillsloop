# 41条会话人工主题复核

2026-10-05。依据上一轮冻结的全量主题标签，提取32条“目标不明确”与9条“平台模板或模拟”。目的仅是让用户人工复核这些探索标签，不替代之前的回复匹配标注。

## 使用方法

打开[人工标注页](private/index.html)，左边选择会话，右边先看完整用户/AI内容，再选择你的判断：有明确任务、仍不明确、确属模板/模拟、真实任务与模板混合、无法判断。可以补选主要任务类别、按行描述实际任务、填写备注。点击“保存本条”或“保存并到下一条待标注”；确实认可AI原判时点击“确认原分类”。默认不预填人工判断。

标注自动存入当前浏览器。建议阶段性点击“导出标注备份（JSON）”；换浏览器或设备后可以导入继续。完成后把导出的JSON文件路径交回，另做验收和合并。CSV便于查看，但JSON才是可导入备份。此页不会直接改全量分类表或原会话。

## 正文及关联边界

- 共41会话、185组去重用户正文、263组去重AI正文，全部原正文保留，没有摘要截断。长正文在框内滚动，也能展开全部高度。
- 使用066正文，回复关系叠加071最终标注；其余关联保留066。用户显示按导出位置排，不宣称原生时间已核实。
- 一个AI正文若对应多个用户提问，只展示一次，其他位置给跳转引用；没有关联的AI内容在后面完整展示。两条没有保留用户正文的会话也不丢掉。
- 原始标题只作参考。已知平台开头包装和原始全文都可看，避免因隐藏模拟/角色提示而误判。
- “无法判断”是明确人工复核结果，不会自动改成有任务或无价值。复核主题不等于任务完成、方法可靠或黄金轨迹认证。

[会话清单CSV](private/会话清单.csv)包含41个编号、原判与规模；`private/conversations/`含逐会话完整Markdown；`private/review_cases.json`保留本轮输入与来源。均在本地受控目录，未上传或外调模型。

`manifest.json`保存输入hash及正文覆盖；`verification.json`记录离线脚本、数据完整性、保存与导出核验。交互核验在隔离的内存DOM/storage中进行，不产生真实人工标签；Windows浏览器自动控制初始化失败，未冒充真实浏览器点击通过。已通过Codex打开工具请求展示标注页。
