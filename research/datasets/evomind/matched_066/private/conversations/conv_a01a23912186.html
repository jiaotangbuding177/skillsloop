## AI Builders Digest — 2026年6月9日

### X / TWITTER

**Anthropic Claude Code 的 Boris Cherny** 分享了5条让 Opus 自主运行数小时甚至数天的技巧：用 auto mode 处理权限、用 dynamic workflows 协调成百上千个 agent、用 `/goal` 或 `/loop` 推动持续工作、在云端运行 Claude Code 以便随时合上电脑、让 Claude 通过自验证检查完整工作链路。

**OpenAI Codex 的 Thibault Sottiaux** 宣布了一个新玩法——一个"大按钮"。接下来100天，每天选一位用 Codex 做超酷或超有用工作的人，给TA一个月10倍用量限制看看能搞出什么名堂。第一天明天揭晓。Sam Altman 转推说"这里有个有趣的递归循环"，暗指他自己就是那个选人的。

**前 Google 产品负责人 Madhu Guru** 点出了一个被严重低估的事实：训练数据不是什么低端苦力活。推动模型前沿需要的是高经济价值任务的训练数据，而这些任务（除了软件工程）几乎没有现成文档——需要数年积累的领域知识和那些互相不兼容的遗留工具。这就是为什么我们已经有了 SWE agent 却还没有知识工作 agent。

**Replit CEO Amjad Masad** 强调 Replit 的使命是消除一切干扰，让你专注于真正重要的事：尽快推向市场、尽快赚钱。

**Vercel CEO Guillermo Rauch** 晒了组惊人数据：Vercel AI Gateway 每月平均恢复超过1万亿 token。就像 Stripe 帮商家挽回失败支付的收入一样，但 Vercel 做这个零加价，还提供冗余、零数据保留、可观测性等能力。

**Box CEO Aaron Levie** 发了三条有分量的推：
- 用例必须在未来一两年内按模型家族分层——高难度任务交给前沿模型，高吞吐量的标准化任务交给便宜模型。而能高效路由 workloads 到合适模型的编排层将变得越来越有价值。
- 市场搞错了一件事：AI 让开发软件变容易了，但企业软件公司最大的成本其实是 GTM（走向市场）。AI 并没有减少这个需求，反而让买家面对更拥挤混乱的选择时更难做决策。
- Box 上线了网页版 markdown 编辑器、完整 CLI 支持、评论功能、版本历史。Box Drive 可以挂载到任何桌面客户端，让你在 Claude Cowork、Codex、Obsidian、Cursor 里直接操作所有文件。

**YC CEO Garry Tan** 三连发：
- 教育人们如何使用 AI 工具已成为严重瓶颈。"这就是为什么我们做了 workattech.com。"
- GBrain v0.42.30 现在能给你一份关于你思考方式随时间变化的详细总结。

**Zara Zhang** 认为她的 Frontend Slides skill 能有机增长的原因是幻灯片天然具有社交属性——人们看到炫酷的幻灯片总会问"这是怎么做的"，而用 HTML 做 deck 的人会被视为更 AI-native。

**FPV Ventures 合伙人 Nikunj Kothari** 观察到一个有趣的 vibe shift：几周前大家还在焦虑 tokenmaxxing 和 token 成本，现在已经开始讨论 tokenoptimizing 了。他坚持认为公司应该给员工充足的 token 预算，让他们保持在最前沿探索——否则太容易回到"以前怎么干就怎么干"的老路。

**Peter Steinberger（OpenClaw 创始人）** 这条彻底爆了——13,700+ 点赞："提醒你一下，你不应该再给 coding agent 写 prompt 了。你应该设计 loop，让 loop 来给你的 agent 发 prompt。"

**South Park Commons GP Aditya Agarwal** 分享了经历两次 IPO（Meta 和 Dropbox）的感悟：巨额财富只会放大你内心的真实渴望，而不是创造新的。对很多人来说，IPO 不是去海滩躺平，而是做更疯狂的事——创业、投资，继续驱动硅谷的循环。接下来几个月很多人会获得流动性，会很精彩。

### 官方博客

**Claude Blog：New in Claude Managed Agents: dreaming, outcomes, and multiagent orchestration**

Anthropic 为 Managed Agents 推出三项重大更新：
- **Dreaming（预览版）**：agent 回顾过去会话，提取模式，自我改进记忆。跨 agent 共享学习成果，自动重构记忆结构。
- **Outcomes**：你写一个成功标准（rubric），agent 向这个标准迭代，独立的评分器在独立上下文窗口评估输出。测试显示任务成功率提升最高10个百分点，其中 docx 提升8.4%、pptx 提升10.1%。
- **Multiagent orchestration**：主 agent 拆解任务，分配给多个 specialist agent 并行处理，共享文件系统。可追踪每个步骤。客户案例：Harvey 用这个协调复杂法律文档起草，完成率提升约6倍；Netflix 平台团队用多 agent 并行分析数百个构建日志；Spiral by Every 用 Haiku 主 agent + Opus 子 agent 并行多稿写作文案，用 outcomes 确保质量。
- https://claude.com/blog/new-in-claude-managed-agents

### Podcast

**The MAD Podcast with Matt Turck — State of Enterprise AI 2026: Aaron Levie on Tokenmaxxing, Rise of Headless, and AI-Proofing Your Job**

核心洞察：企业 AI 部署进入了一个"甜蜜又苦涩"的阶段——技术突破的速度快于客户落地任何标准架构的速度，而每次新突破都可能让上一次的部署变得过时。

Aaron Levie 作为 Box CEO，同时脚踏硅谷最前沿和全球2000强企业的现实，给出了几个关键判断：

- **Token ***，而是范式转移**。从 $20/月/人的订阅模式到单个 coding agent 一次任务可能消耗 $1000 计算资源，这迫使 AI 支出从 IT 预算（约占收入的3-7%）迁移到业务线预算（占60-80%）。这实际上对 AI 产业是好事——不再受限于 IT 预算天花板，但也带来了新的难题：销售团队没有 FinOps，CMO 需要在花 $100万 买算力和花 $100万 办营销活动之间做选择。

- **5亿美元的 startup 机会**：Levie 说还没人做好 AI 算力的 ERP 系统——如何衡量 token 的 ROI？如何让员工知道一次错误的 prompt 结构可能花掉 $200？如何做集中容量规划 + 分散决策？

- **AI coding 不等于 AI 知识工作**。Levie 列出了5个根本差异：
  1. 代码有可验证性——跑起来或跑不起来，一目了然
  2. 代码库天然集中了上下文
  3. 工程师有权限访问整个代码库
  4. 工程师自己就能修 agent 犯的错
  5. 代码最好的是新模型升级不一定破坏旧工作

  而在知识工作中，上下文分散在20个地方（有些甚至不是数字化的），权限一团糟，员工自己没法修 agent 的错误。

- **Headless 软件是必然但不是全部**。Levie 认为未来是双轨制：复杂查询会完全通过 agent 无头操作；但需要精细操作时 GUI 仍有不可替代的价值。"数据库查询层面，headless 的调用量会比人类界面大100倍，但人类仍然需要座位。"

- **关于就业的杰文斯悖论视角**：Levie 是最坚定的"就业不会被消灭"派。原因有三：(1) 知识工作中存在"最后一英里"问题——比如律师无法让 agent 承担合同最终审核责任；(2) 非硅谷的传统巨头（卡特彼勒、礼来等）过去招不到顶尖工程师，现在 agent 让一个工程师产能翻3-10倍，反而刺激了更多工程需求；(3) 小企业用 agent 做营销初见成效后，第一件事往往是——招一个营销人员来管理这些 agent。

听这集有种很踏实的感觉。不是那种"一切都会被颠覆"的宏大叙事，而是一个真正跟几百个 CIO 聊过、看过账单、经历过"AI 精神病期"的人，用具体的数字和真实的企业场景在说话。
