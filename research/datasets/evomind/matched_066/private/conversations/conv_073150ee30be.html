```javascript
// ❌ 之前（只获取 open 状态，不分页）
const issues = await giteeGet(`/enterprises/${enterprise}/issues?per_page=100`);

// ✅ 现在（获取全部状态，分页）
async function getEnterpriseIssues(enterprise) {
  const allIssues = [];
  let page = 1;
  while (true) {
    const issues = await giteeGet(`/enterprises/${enterprise}/issues?per_page=100&page=${page}&state=all`);
    if (!Array.isArray(issues) || issues.length === 0) break;
    allIssues.push(...issues);
    if (issues.length < 100) break;
    page++;
  }
  return allIssues;
}
```

### 方案一：快速授权（推荐）

使用 `lark-cli auth login` 命令进行设备流授权。由于这个命令会阻塞等待用户操作，我们分两步完成：

**步骤 1：获取授权码**

运行以下命令获取授权链接：

```bash
lark-cli auth login --no-wait --json
```

**步骤 2：在浏览器中打开授权链接**

命令会返回类似以下信息：
```json
{
  "verification_uri": "https://open.feishu.cn/device",
  "user_code": "ABCDEF",
  "device_code": "xxxxx"
}
```

1. 打开浏览器访问：`https://open.feishu.cn/device`
2. 输入验证码（user_code）
3. 使用你的飞书账号登录并授权

**步骤 3：完成授权**

授权完成后，使用 device_code 完成流程：

```bash
lark-cli auth login --device-code "你的device_code"
```
