## 📚 知识库指令速查

### 一、核心操作

| 操作 | 触发词 | 说明 |
|------|--------|------|
| **初始化** | 首次使用，无 `wiki/` 目录 | 自动创建 wiki 结构、索引、日志 |
| **收录/入库** | `收录`、`添加到知识库`、`保存这个`、`ingest`、`收录全部` | 提取源文件 → 编译 wiki 文章 → 更新索引 |
| **查询** | `搜索知识库`、`wiki 里有没有`、`知识库里关于`、`query wiki` | 查 index → 读 wiki 文章 → 回答 |
| **整理** | `整理知识库`、`lint wiki`、`检查 wiki` | 检查索引完整性 → 自动修复 → 报告 |

### 二、具体用法

#### 1. 收录知识

```
收录 [文件路径]          # 收录单个文件
收录全部                # 扫描所有未处理的源文件
收录 [URL]             # 抓取网页内容并收录
保存这个 [文本内容]     # 保存粘贴的文本到知识库
```

#### 2. 查询知识

```
搜索知识库 [关键词]      # 搜索知识库内容
wiki 里有没有 [话题]    # 查询特定话题
知识库里关于 [主题]     # 查找特定主题的知识
```

> **优先级规则**：查询时先查本地 wiki，不足时再搜索网络

#### 3. 整理维护

```
整理知识库              # 检查索引、自动修复、报告问题
lint wiki              # 同上
检查 wiki 健康          # 同上
```

#### 4. 归档

```
归档 [文章名]           # 将过时文章移至归档区（不删除）
```

### 三、目录结构

```
个人知识库/
├── wiki/                    # ← 技能管理的 wiki 目录
│   ├── index.md            # 主索引（所有条目入口）
│   ├── log.md              # 变更日志
│   └── {slug}.md           # 各 wiki 文章
├── 你的文件.pdf            # 源文件（只读，不修改）
├── 你的文件.md             # 支持任意格式
└── 子目录/                 # 递归扫描
```

### 四、支持的文件格式

| 格式 | 扩展名 | 提取方式 |
|------|--------|----------|
| PDF | `.pdf` | doc_extractor.py |
| Excel | `.xlsx` / `.xls` | doc_extractor.py |
| Word | `.docx` | doc_extractor.py |
| PowerPoint | `.pptx` | doc_extractor.py |
| 文本 | `.md` / `.txt` / `.csv` / `.json` | 直接读取 |
| 网页 | URL | 网络抓取 |

### 五、核心规则

1. **源文件只读** — 绝不修改 `个人知识库/` 中的原始文件
2. **只写 wiki 目录** — 所有生成的内容都在 `个人知识库/wiki/`
3. **索引必须完整** — 每个 wiki 文章都必须在 `index.md` 中列出
4. **日志必须更新** — 每次操作都记录到 `log.md`
5. **永不删除** — 过时内容归档，不删除
6. **先查 wiki 再搜网** — 本地知识库优先
