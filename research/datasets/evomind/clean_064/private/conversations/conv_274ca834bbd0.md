````text
股权变更涉及的会计分录，根据变更类型不同处理方式也不同。我按常见的几种场景分别说明：

---

## 一、增资扩股

### 1. 新股东现金入资（有溢价）

> 例：新股东投入100万，其中50万计入注册资本，50万计入资本公积

```
借：银行存款                1,000,000
    贷：实收资本——新股东        500,000
        资本公积——资本溢价      500,000
```

### 2. 原股东同比例增资

```
借：银行存款                  XXX
    贷：实收资本——XX股东        XXX
```

---

## 二、股权转让（股东之间转让）

> 例：A股东将10%股权（原出资50万）以80万转让给B

**公司账务处理**（公司层面只变更股东名册）：

```
借：实收资本——A股东          500,000
    贷：实收资本——B股东        500,000
```

> ⚠️ **注意**：股权转让的差价（80万-50万=30万）是A股东的个人所得，**公司不做账**，由A股东自行缴纳个人所得税。

### 如果涉及公司回购

```
借：库存股                    XXX
    贷：银行存款                XXX
```
（后续注销时冲减实收资本和资本公积）

---

## 三、减资 / 退股

### 1. 按原出资额退股（平价退出）

> 例：股东退股，原出资100万，退回100万

```
借：实收资本——XX股东        1,000,000
    贷：银行存款              1,000,000
