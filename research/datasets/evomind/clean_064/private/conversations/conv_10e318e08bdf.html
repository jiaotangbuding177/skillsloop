年终奖3月发这个点，我完全同意你的判断——春节前发=拿钱走人，3月发能有效过滤掉只想拿年终奖走的人。关键是**要提前说清楚规则**，别到时候2月突然宣布，会炸。建议7月这次加薪沟通的时候就一起讲明白。

**年终奖结构（3月发）：**
```
年终奖 = 月薪 × 公司营收系数（0.5~2个月）× 个人绩效系数（S最高2.0, B级0.5~0.8）
```

心理学上说，**A- 比 B+ 好很多**。理由如下：

**B+ 的心理暗示：**
- "我还在B这个池子里，只是比一般的B好一点"
- 潜意识感受：**将就、勉强、差A一截**
- 感觉像安慰奖——"你不是A，但你是B里最好的"

**A- 的心理暗示：**
- "我是A级人才，只是还不够完美"
- 潜意识感受：**惜败、差一点就满分、有上升空间**
- 感觉更像成长路径——"你再努力一下就是A了"

一个真实的心理学现象叫 **标签锚定效应**：把人归到哪个词里，他自己就会朝那个方向认同。B+的人不会认为自己"接近A"，而是"我就是B那一拨的"。但A-的人会觉得自己"本来就是A那拨的，下次拿全A"。

**所以结论：用 A-。**

不过序列要调一下，A 和 A- 放一起：

```
S → A → A- → B → C
```

而不是 S → A- → A（A-跟在A后面才是"离A一步之遥"的感觉）。

要我改吗？就是把评级体系里的 B+ 全部替换成 A-，调薪幅度和年终奖系数都保持不变。
