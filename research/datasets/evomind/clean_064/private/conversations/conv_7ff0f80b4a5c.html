## 结转本期损益的会计分录

结转本期损益，就是将当期所有损益类科目余额结转到 **"本年利润"** 账户，以计算本期净利润（或净亏损）。

### 第一步：结转收入类科目

将各项收入从借方转出，汇总到本年利润的贷方：

```
借：主营业务收入
    其他业务收入
    营业外收入
    投资收益（若为贷方余额）
    公允价值变动损益（若为贷方余额）
    资产处置损益（若为贷方余额）
    其他收益
贷：本年利润
```

### 第二步：结转成本费用类科目

将各项成本费用从贷方转出，汇总到本年利润的借方：

```
借：本年利润
贷：主营业务成本
    其他业务成本
    税金及附加
    销售费用
    管理费用
    财务费用
    营业外支出
    所得税费用
    投资收益（若为借方余额）
    公允价值变动损益（若为借方余额）
    资产处置损益（若为借方余额）
    信用减值损失
    资产减值损失
```

### 第三步：判断盈亏

结转完成后，"本年利润"账户的余额：

| 余额方向 | 含义 |
|---------|------|
| **贷方余额** | 当期实现 **净利润** |
| **借方余额** | 当期发生 **净亏损** |

### 第四步：年末结转

**年度终了时**，再将"本年利润"余额转入"利润分配——未分配利润"：

**盈利时：**
```
借：本年利润
贷：利润分配——未分配利润
```

**亏损时（相反分录）：**
```
借：利润分配——未分配利润
贷：本年利润
```

---

**关键点：** 结转后，所有损益类科目余额归零，从下期初重新累计；"本年利润"在年度中间反映累计盈亏，年末清零转入留存收益。如果用的是财务软件，一般有自动结转损益的功能，但手工做账时按上述步骤操作即可。
