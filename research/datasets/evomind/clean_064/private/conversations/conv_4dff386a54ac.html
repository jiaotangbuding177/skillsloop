## ✅ 做得好的地方

1. **创业公司调性传递到位**——"不搞形式主义"、"实际的事做"、"有发言权"，容易吸引不喜欢大厂流程的自驱型候选人
2. **接受应届生**明确写在标题里，不会让没经验的人直接跳过
3. **硬性 vs 软素质分开**，避免看起来像"什么都想要"
4. 加分项单独标注"没有也没关系"，降低了投递门槛
5. **去掉了学历要求**，符合你"看重学习能力"的表述

## ⚠️ 不够清晰 / 需要修正的地方

### 1️⃣ 职责范围太杂，求职者可能看不懂"这到底是个什么岗位"

你写了五条职责，拆开来其实是**三个角色**的工作量：

| 角色 | 职责 |
|------|------|
| 产品经理 | 收集需求 → 写 PRD → 参与迭代规划 → 跟进研发 |
| 商务/客户成功 | 对齐商务 → 对齐研发 → 确保交付 |
| 内容运营 | 撰写用户案例 → 配合内容产出 →（加分项）短视频 + 运营文案 |

应届生看到可能会想：**我到底是做产品，还是半个运营+半个商务？** 建议把"撰写用户案例""配合内容产出"归到加分项，或者明确说是"工作内容的一部分但不是核心考核指标"。

### 2️⃣ "熟练使用 AI 工具"这个要求太模糊

具体指什么？是：
- 会用 ChatGPT 写 PRD / 做调研？→ **大部分 PM 都能做到**
- 会调 prompt / 用 API 写脚本提效？→ **需要一定技术理解**
- 会用 AI 绘画/视频工具做 demo？→ **更接近创意方向**

这三个完全不是一个难度级别。建议**具体化**，比如：
> "熟练使用 GPT/Claude 等大模型辅助需求分析、文档撰写、用户反馈分类，有体系化的 prompt 使用习惯"

### 3️⃣ "对 AI 产品有热情"面试时没法判断

这是"怎么说都对"的条件。建议换成**可验证的行为描述**：
- ✅ "每周至少使用 5 款以上 AI 产品"
- ✅ "能说出 3 个最喜欢的 AI 产品及为什么"
- ✅ "有自己总结的 AI 使用工作流"

### 4️⃣ 缺少两个关键信息

| 缺什么 | 为什么重要 |
|--------|-----------|
| **薪资范围** | 对应届生求职是核心决策因素，没有等于在劝退 |
| **产品方向 / 做什么的** | "AI 产品"范围太大，是否做 LLM 应用？做 B 端还是 C 端？做海外还是国内？候选人需要判断自己是否感兴趣/适合 |

### 5️⃣ 加分项可能暴露了真实需求

"能出基础的短视频内容脚本"+"能出产品运营推广文案"放在加分项，但前面的职责里已经有"配合内容产出"。如果实际上**需要**这个人做内容，建议直接说清楚，不要放在加分项里让新人在进来后发现"怎么还要拍视频"。

| 问题 | 严重程度 | 建议 |
|------|---------|------|
| 职责跨度太大 | 🔴 致命 | 把运营/内容归到加分项或明确说"有时需配合但不作为考核" |
| "熟练使用AI工具"太模糊 | 🟡 中等 | 具体到使用场景 |
| "对AI有热情"不可验证 | 🟡 中等 | 改成可验证的行为 |
| 没写薪资 | 🟡 中等 | 至少给个范围 |
| 没写产品方向 | 🟡 中等 | 一两句话说明公司在做什么 |
| 加分项可能误导 | 🟢 轻微 | 明确说是否需要做内容 |
