---

## 一、分式的概念

**定义**：形如 $\frac{A}{B}$ 的式子，其中 A、B 是整式，且 **B 中含有字母**，B ≠ 0。

**两个常考条件**（选择题、填空题高频）：
- **分式有意义** ⇔ 分母 ≠ 0
- **分式值为 0** ⇔ 分子 = 0 **且** 分母 ≠ 0（两个条件同时满足，缺一不可）

⚠️ 易错：判断是否为分式，关键看**分母有没有字母**，如 $\frac{x}{3}$ 是整式不是分式，$\frac{3}{x}$ 才是分式。

---

## 二、分式的基本性质（核心）

$$\frac{A}{B} = \frac{A \times C}{B \times C} = \frac{A \div C}{B \div C} \quad (C \neq 0)$$

即：分子分母**同乘或同除以**一个不等于 0 的整式，分式的值不变。

由此引出两个变形技能：

1. **约分**：分子分母同除以公因式，结果要化成**最简分式**（分子分母没有公因式）
2. **通分**：把几个异分母分式化为同分母分式，关键是找**最简公分母**（各分母系数的最小公倍数 × 所有出现的字母（因式）的最高次幂）

---

## 三、分式的运算

| 运算 | 法则 | 公式 |
|---|---|---|
| **乘法** | 分子乘分子，分母乘分母 | $\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}$ |
| **除法** | 除以一个分式 = 乘以它的倒数 | $\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c}$ |
| **乘方** | 分子分母分别乘方 | $(\frac{a}{b})^n = \frac{a^n}{b^n}$ |
| **同分母加减** | 分母不变，分子相加减 | $\frac{a}{c} \pm \frac{b}{c} = \frac{a \pm b}{c}$ |
| **异分母加减** | 先通分，再按同分母加减 | $\frac{a}{b} \pm \frac{c}{d} = \frac{ad \pm bc}{bd}$ |

**混合运算顺序**：先乘方 → 再乘除 → 最后加减，有括号先算括号里的。（结果要化为最简分式）

⚠️ 注意：分式运算结果必须**约分成最简分式**；异分母加减**不能直接去分母**（那是解方程才做的事）。

---

## 四、整数指数幂与科学记数法

1. **负整数指数幂**：$a^{-n} = \frac{1}{a^n}$（a ≠ 0，n 为正整数）
   - 特别地：$a^0 = 1$（a ≠ 0）
   - 拓展：$a^{-n} = \frac{1}{a^n}$，如 $2^{-3} = \frac{1}{8}$

2. **科学记数法表示小于 1 的正数**：$a \times 10^{-n}$（1 ≤ a < 10，n = 原数左边第一个非零数字前面 0 的个数）
   - 例：$0.000032 = 3.2 \times 10^{-5}$

---

## 五、分式方程（本章重难点）

**定义**：**分母中含有未知数**的方程。

**解方程步骤**（四步走）：
1. **去分母**：方程两边同乘最简公分母，化为整式方程
2. **解**这个整式方程
3. **检验**：把解代入最简公分母
   - 最简公分母 ≠ 0 → 是原方程的解
   - 最简公分母 = 0 → 是**增根**，必须舍去
4. 写结论

⚠️ **增根**：去分母时乘的式子可能为 0，导致产生使分母为 0 的根。**解分式方程必须检验**，这是与解整式方程最大的区别。

**应用（列分式方程解应用题）**——常考三类：
- **行程问题**：路程 = 速度 × 时间（如"提速前后时间关系"）
- **工程问题**：工作量 = 工作效率 × 时间（常把总工作量看作 1）
- **销售/购买问题**：如"两次购买数量差"、"单价变化"

---

## 六、高频易错点提醒

1. 分式值为 0 时，**忘检验分母 ≠ 0**（比如分子分母都能使分子为 0 的情况）
2. 约分时**符号问题**：$\frac{b-a}{a-b} = -1$，注意先变形再约分
3. 异分母加减**忘了通分**，直接分子分母相加减
4. 解分式方程**漏检验**，或把增根当解
5. 负指数与科学记数法**数错 0 的个数**
6. 混合运算顺序错乱，或结果没化成最简分式

---

## 七、本章知识框架（背诵版）

```
分式
├── 概念：A/B（B含字母，B≠0）
│   ├── 有意义：B≠0
│   └── 值为0：A=0 且 B≠0
├── 基本性质：同乘/同除非零整式
│   ├── 约分 → 最简分式
│   └── 通分 → 最简公分母
├── 运算：乘除、乘方、加减（先通分）、混合运算
├── 整数指数幂：a⁻ⁿ=1/aⁿ，科学记数法（小于1的数）
└── 分式方程
    ├── 解法：去分母→解整式→检验（防增根）
    └── 应用：行程、工程、销售问题
```
