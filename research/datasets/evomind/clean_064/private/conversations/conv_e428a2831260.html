这个 skill 是用来操作 **Get笔记**（biji.com）的，可以帮你保存、搜索、管理笔记和知识库。不过我看了一下，咱们的 TOOLS.md 里**还没配置 API 凭证**，所以现在还不能真正调用，得先搞定第一步。

## 🔑 第一步：配置凭证（必须）

需要两个东西：
- **GETNOTE_API_KEY**（格式 `gk_live_xxx`）
- **GETNOTE_CLIENT_ID**（格式 `cli_xxx`）

去 https://biji.com 获取，然后把它们发给我（或告诉我怎么配），我会写进 TOOLS.md。

## 📖 第二步：日常用法（配好之后）

跟我说话就行，不用记命令，比如：

| 你想干嘛 | 直接跟我说 |
|---|---|
| 📝 存笔记 | 「记一下：明天下午3点开会」/ 发个链接 / 发张图 |
| 🔍 搜笔记 | 「搜一下我之前存的关于 Python 的笔记」 |
| 📋 看笔记 | 「最近存了什么」「看看我的笔记列表」 |
| ✏️ 改笔记 | 「把那条笔记标题改成 XXX」 |
| 📚 知识库 | 「建个知识库」「把这篇加到 XX 知识库」 |
| 🏷️ 标签 | 「给这篇加个 #工作 标签」 |
| ⚙️ 重新配置 | 「配置笔记」 |

## ⚠️ 几个注意点

- **私密性**：笔记是你的隐私，我不会在群聊里主动展示内容
- **限流**：创建笔记建议间隔 1 分钟以上，避免触发限流
- **会员**：如果提示非会员（错误码 10201），需要开通会员才能用
