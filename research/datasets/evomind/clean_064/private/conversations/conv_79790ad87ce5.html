## 它能干啥

**1. 处理这些典型任务**
- 公众号 / 小红书 / 企业微信内容
- 官网 SEO 内容
- 视频脚本
- 市场演示材料（HTML 演示或图片式 PPT）

**2. 产出标准化的业务产物（Artifact）**
- 渠道文案（.md / .docx）
- 视频脚本（.md）
- HTML 演示 / 图片式 PPT
- 配套素材文件
- 每个产物都带唯一 Artifact_ID、版本、Owner、来源文件等元数据，方便审计追溯

**3. 按固定调用链编排已有基础技能**
- `social-content`（新媒体内容创作）→ 出初稿
- `gtm-strategy`（市场策略，仅新产品/活动时用）
- `image-generation` / `image-editing`（视觉素材）
- `guizang-ppt-skill` / `image-ppt-generation`（演示）
- `humanizer-zh`（去 AI 味，最后润色语言）
- 不重复造轮子，只在需要时调用

**4. 关键特点：严格、可审计**
- **缺资料就停**：输入不齐返回 `NEEDS_DATA`，逐条告诉你缺什么、为什么影响结果，绝不瞎猜
- **事实冲突就报**：发现型号/参数/事实冲突返回 `CONFLICT` 并列出冲突来源
- **人工控制**：对外发布、型号批准等最终决定留给人，模型只出草稿
- **完整运行回执**：每次跑完输出 RUN STATUS、调用记录、产物路径、需要人工处理的事项、下游交接清单
