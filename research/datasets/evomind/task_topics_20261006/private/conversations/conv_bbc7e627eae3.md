可以的！这个技能支持 **多账号配置**。每个账号用不同的前缀来区分。

### 举个例子

假设你现在已经有了 126 的默认账号，想再加一个 QQ 邮箱：

```bash
# 在 .env 文件里追加：
QQ_PROVIDER=qq
QQ_USERNAME=你的qq号@qq.com
QQ_PASSWORD=QQ邮箱授权码
```

使用时指定账号名就行：

```bash
# 用 126 发（默认账号）
node scripts/smtp.js send --to ... --subject ... --body ...

# 用 QQ 发
node scripts/smtp.js --account qq send --to ... --subject ... --body ...
```

### 支持哪些邮箱？

| 提供商 | PROVIDER 值 | 授权码获取方式 |
|--------|------------|--------------|
| 126.com | `126` | 网页设置 → POP3/SMTP/IMAP → 新增授权码 |
| 163.com | `163` | 同上 |
| QQ邮箱 | `qq` | 设置 → 账户 → POP3/IMAP/SMTP → 生成授权码 |
| 188.com | `188` | 同上 |
| yeah.net | `yeah` | 同上 |
| vip.163 / vip.126 | `vip.163` / `vip.126` | 同上 |
| 企业微信邮 | `exmail.qq.com` | 同上 |
