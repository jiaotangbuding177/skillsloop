对接飞书知识库，核心流程其实不复杂，但有一个**特别容易踩的坑**：知识库文档的 URL 里的 token 是「节点 token（node_token）」，不是文档真实的 document_id，直接拿去调文档接口会报错。得先通过节点接口换成 `obj_token` 再取内容。

下面给你完整路径 👇

## 一、准备工作（一次性）

1. **创建企业自建应用**：打开 [飞书开放平台](https://open.feishu.cn) → 开发者后台 → 创建企业自建应用
2. **拿到凭证**：应用凭证页的 `App ID` 和 `App Secret`
3. **开通权限**（在「权限管理」里搜索添加）：
   - `wiki:wiki`（读写知识库）或 `wiki:wiki.readonly`（只读）
   - `docx:document` 或 `docx:document:readonly`（读写文档内容）
4. **发布应用版本**，并确保可用范围包含知识库成员
5. **授权应用访问你的知识库**（最容易漏的一步！）：
   - 方式一（推荐）：飞书里建个群，把应用加为群机器人 → 知识库「设置 → 成员设置」→ 把这个群添加为管理员/成员
   - 方式二：在知识库的某篇文档里，右上角「… → 更多 → 添加文档应用」直接添加应用为协作者

## 二、调用链路（核心就 4 步）

```
获取 tenant_access_token
   → 获取知识空间列表        GET /open-apis/wiki/v2/spaces
   → 获取空间节点列表        GET /open-apis/wiki/v2/spaces/{space_id}/nodes
   → 获取节点信息（拿 obj_token） GET /open-apis/wiki/v2/spaces/get_node?token=[隐藏]
   → 根据 obj_type 取内容：
       文档   → GET /open-apis/docx/v1/documents/{obj_token}/raw_content  （纯文本）
                GET /open-apis/docx/v1/documents/{obj_token}/blocks       （结构化块）
       表格   → 电子表格 API
       多维表 → 查询记录 API
```

## 三、Python 代码示例（用官方 SDK，最省事）

```bash
pip install lark-oapi
```

```python
import lark_oapi as lark
from lark_oapi.api.wiki.v2 import *
from lark_oapi.api.docx.v1 import *

client = lark.Client.builder() \
    .app_id("你的APP_ID") \
    .app_secret("你的APP_SECRET") \
    .log_level(lark.LogLevel.INFO) \
    .build()

# 1. 列出知识空间
spaces = client.wiki.v2.space.list(ListSpaceRequest.builder().build())
for s in spaces.data.items:
    print("空间:", s.name, s.space_id)

# 2. 列出某个空间的节点（传 space_id）
nodes = client.wiki.v2.space_node.list(
    ListSpaceNodeRequest.builder().space_id("空间ID").build())
for n in nodes.data.items:
    print("节点:", n.title, "| node_token:", n.node_token, "| 类型:", n.obj_type)

# 3. 用 node_token 换真实文档 token
*** = client.wiki.v2.space_node.get(
    GetSpaceNodeRequest.builder().token("节点node_token").build())
obj_token = [隐藏]
print("真实文档ID:", obj_token)

# 4. 拉取文档纯文本
resp = client.docx.v1.document.raw_content(
    RawContentDocumentRequest.builder().document_id(obj_token).build())
print(resp.data.content)
```

## 四、常见报错对照

| 报错 | 原因 | 解决 |
|---|---|---|
| `permission denied` / 131006 | 应用没被授权访问该知识库 | 按上面第 5 步把应用加进知识库成员或文档协作者 |
| `document not found` / 文档 ID 无效 | 拿 node_token 当 document_id 用了 | 先调「获取节点信息」换 obj_token |
| `access token *** | token 过期 | tenant_access_token 有效期 2 小时，过期重新获取 |
