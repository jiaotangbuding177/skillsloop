## 📄 文章核心：Rules + Spec + Skills 三位一体

### 痛点：为什么 AI 写代码总"差那么点意思"？

AI 写代码很快，但到了生产环境经常**质量不可控**。作者认为问题不在模型本身，而在于**缺少软件工程化的确定性约束**。

### 核心方法论

作者提出了一套比 OpenSpec **更轻量**的 AI Coding 规范体系：

**🔧 Rules（规则）** — 防跑偏
- 定义架构约束、编码规范、异常处理规则
- 让 AI 在框架内工作，不自由发挥

**📋 Spec（规格）** — 保质量
- 需求分析阶段生成结构化 spec 文档 + 任务拆分
- 关键环节：**需求澄清** — 把 AI 分析中的不确定项一次确认，避免反复返工
- 然后只需对 AI 说"帮我实现编码"，它就能按规范生成全部代码

**🎯 Skills（技能）** — 自动化
- 把流程封装成可复用的 Skills
- 功能分析 → 需求分析 → 编码 → Code Review → 迭代优化

### 实战效果

| 阶段 | 效果 |
|------|------|
| 编码 | 一次生成 **66 个文件、5000+ 行代码**，业务逻辑和异常处理完整 |
| Code Review | 第一次自审 **~70 分** → 迭代后 **96 分** |
| 编译 | **一次性通过** |

### 核心理念

> **AI 不是银弹，而是超级杠杆。用好它，需要更清晰的架构思维、更严谨的规范意识、更深刻的软件工程哲学。**

出现问题时不修代码，而是回退到**规范层面**去调整规则——规范越积越厚，也越来越好用。

> Python 3.10+ * ✓ 有 *
> Node.js 18+ * ✗ 未安装 *
> FFmpeg * ✗ 沙箱环境装不了 *
> 本地渲染能力 * ✗ 无 GPU、无视频输出 *
> 浏览器显示 Backlot 面板 * ✗ 沙箱无浏览器 *

我运行在 **Docker 沙箱** 里，没有显示器、没有 GPU、不能播放视频。装了也跑不出成品。

**2. 设计目标不同**

OpenMontage 是为 **AI 编程助手**（Claude Code、Cursor、Copilot、Windsurf、Codex）打造的——这些工具的特点是：
- 在用户的 **本地机器** 上运行
- 能读写本地文件系统
- 能调用系统命令渲染视频
- 用户就在旁边、能看到产出

而我是 **对话式 AI 助手**，在远程沙箱里，适合做信息检索、分析、建议，而不是运行一个需要数十分钟、多阶段迭代的视频生产线。

**3. 视频输出通道缺失**

就算跑通了生成流程，生成的 MP4 文件我也没法直接展示给你——沙箱里没有视频播放器。

如果你 **自己有一台电脑**，想把它变成 AI 视频工作室，那么：

### ✅ 亮点

**1. 原生支持 OpenClaw 🎯**

这是关键点——它已经在支持列表里了：
```
OpenClaw — SOUL.md + AGENTS.md + IDENTITY.md per agent
```
安装后每个代理就是一个独立的 OpenClaw 工作区，放在 `~/.openclaw/agency-agents/` 下。

**2. 覆盖面非常广**

从工程到设计、销售、营销、安全、金融、游戏开发、GIS——**我目前不具备的许多专业能力它都有**。比如：
- 🎨 **UI 设计师 / UX 研究员** — 设计评审时调用
- 🔍 **Reality Checker** — 质量门禁、生产就绪检查
- 📝 **技术写手** — 写文档
- 🧪 **测试自动化工程师** — Playwright/Cypress E2E
- 🔬 **Prompt Engineer** — 提示词优化
- 🎬 **视频优化专家** — YouTube 算法策略
- 🛡️ **安全架构师** — 威胁建模

**3. 轻量级，零依赖**

跟 OpenMontage 完全不同——它不需要 FFmpeg、Node.js、GPU、API Key。**就是一堆精心编写的 Markdown 文件**，定义每个代理的个性、使命、工作流和交付标准。
