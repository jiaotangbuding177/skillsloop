## AI处理／结果

来源消息组：a_a9fca800e936dc85c0

查好了，WeChatMsg（留痕/MemoTrace）使用流程如下，**全程本地运行、免费开源**：

**① 准备（一次性）**
- Windows 电脑装好最新版微信 PC 端，并**保持微信登录状态**（工具需要从登录中的微信读取密钥）
- 如果手机上的聊天记录比电脑全：手机微信 → 我 → 设置 → 聊天 → **聊天记录迁移与备份** → 迁移到电脑微信（手机电脑同一 WiFi 即可）

**② 下载工具**
- GitHub 搜 `LC044/WeChatMsg`（作者 LC044，中文名"留痕"，最新版叫 MemoTrace，已支持微信 4.0）
- 在 Release 页面下载单文件 exe（免安装）

**③ 运行导出**
1. 双击 `MemoTrace.exe`（如果闪退 → 右键 → **以管理员身份运行**）
2. 点「**获取信息**」→ 工具自动读取微信数据路径并解密（稍等片刻，会显示手机号、微信ID、密钥）
   - 如果路径没自动识别：手动选择微信 → 设置 → 文件管理路径下的 `wxid_xxx` 文件夹（wxid 必须和上面显示的一致）
3. 点「**开始启动**」→ 等待解密完成（**可能假死几分钟，正常现象**）
4. 进入**好友/群列表** → 选中您要导出的那个群或联系人 → 导出
   - 推荐选 **HTML 格式**（文字、图片、语音、文件全包含）
   - 如果记录特别多导出卡死：选 **TXT（仅文本）**，对我们归纳来说文本就够用

**④ 发给我**
- 导出完成后，把文件发到这个对话（或直接告诉我路径）
- 我来做全量归纳：按主题整理成结构化文档，合并进 EvoMind 档案

**⚠️ 提醒**：不支持微信多开和过老版本；超大群（几万条）导出会卡，可以按时间段分批导。

搞定后把导出的文件丢给我就行。另外确认下——您电脑是 Windows 吧？如果是 Mac 我给您换 Mac 的方案。
