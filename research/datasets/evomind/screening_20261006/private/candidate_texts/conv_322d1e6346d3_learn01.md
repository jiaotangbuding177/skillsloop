两周了还报，说明不是"调大就完事"的情况。先把方向搞清楚——**你得先确认报的到底是哪一个错**，因为两种错治法完全不同：

- **"虚拟内存不足"** → 系统内存/页面文件问题（RAM + 页面文件）
- **"显存不足 / Out of video memory"** → 显卡显存问题（降画质、更驱动、指定独显）

很多人把这两个混为一谈。你先看一眼弹窗原文是哪个。

## 请先给我这 4 个数（很重要）

1. **物理内存多大**：任务管理器（Ctrl+Shift+Esc）→ 性能 → 内存，看容量
2. **玩游戏时内存占用**：同页面看"使用中"和"已提交"两个数字，**游戏跑起来后**截图给我
3. **页面文件现状**：高级系统设置 → 性能设置 → 高级 → 虚拟内存"更改"，你现在的设置是"自动管理"还是自定义？数值多少？在哪个盘？
4. **显卡型号 + 显存大小**：任务管理器 → 性能 → GPU，看"专用 GPU 内存"

## 按可能性排查（从高到低）

**① 页面文件设了但没生效 / 设错盘**
- 常见坑：设了自定义却没点右边那个"**设置**"按钮，再点确定 → 根本没保存
- 页面文件所在盘**空间不足**（至少留 30-50GB），或设在了空间小的 C 盘 → 换到空间最大的盘
- 现在的社区共识其实分两派：稳妥做法是**直接选"系统托管"，放在空间最大的盘**（2K 系列这个祖宗毛病，系统托管往往比手动小值更稳）；如果你要手动，按物理内存的 1.5-3 倍设（16GB 内存 → 初始 24576 / 最大 49152）

**② 物理内存真的不够**
- 2K27 推荐就 16GB，**实际玩生涯建议 32GB**。如果你是 8GB 或 16GB，社区里 16GB 一样报"内存不足"的案例一大把（游戏本身有内存泄漏嫌疑）→ 加内存条是根治

**③ 其实是显卡/驱动问题（尤其笔记本双显卡）**
- 更新显卡驱动（NVIDIA/AMD 官网，别用第三方驱动工具）
- **强制游戏用独显**：Windows 设置 → 系统 → 显示 → 图形 → 找到 2K27 → 设为"高性能"；NVIDIA 控制面板 → 管理 3D 设置 → 程序设置 → 添加 2K27 → 电源管理模式设"最高性能"
- 如果游戏跑在核显上，报内存/显存错是必然的

**④ 游戏侧**
- **更新到最新补丁**：v1.3 之后官方又发过修稳定性的补丁（Season 2 前），确认你 Steam 里是最新版
- **Steam 校验游戏文件完整性**
- 游戏内**纹理质量降一档**、分辨率降一档；关掉高清材质包（如果有）
- 进游戏先在标题界面**等着色器编译跑完**再进模式（2K27 着色器构建闪退是已知问题）

**⑤ 后台/系统**
- 关掉浏览器、录屏、加速器等再进游戏（浏览器内存泄漏是隐形杀手）
- 杀毒软件把游戏目录加白名单
- 做一次**干净启动**测试：msconfig → 有选择的启动 → 关掉所有非微软服务，重启后只开游戏，看还报不报

## 如果以上都没用，两个终极手段

1. **重建页面文件**：虚拟内存设为"无分页文件"→ 重启 → 进 C 盘删掉 `pagefile.sys`（要先显示隐藏文件）→ 重新设"系统托管"→ 再重启
2. 命令提示符（管理员）跑 `sfc /scannow` 和 `DISM /Online /Cleanup-Image /RestoreHealth`，修系统文件；再跑一次 Windows 内存诊断（搜索"内存诊断"）

行，直接给你加虚拟内存的操作步骤，照着点：

## 操作步骤

1. 桌面右键「**此电脑**」→「**属性**」→ 右侧「**高级系统设置**」
2. 「性能」区域点「**设置**」→ 切到「**高级**」选项卡
3. 「虚拟内存」区域点「**更改**」
4. **取消勾选**最上面的「自动管理所有驱动器的分页文件大小」
5. 选中**剩余空间最大的那个盘**（SSD 优先，C 盘也行）
6. 选「**自定义大小**」，然后填数值 ↓
7. **⚠️ 关键：填完必须点右边的「设置(S)」按钮**，再点「确定」——不点这个按钮等于白填
8. **重启电脑**才生效

## 填多少（按你的物理内存）

| 物理内存 | 初始大小 | 最大大小 |
|---|---|---|
| 8 GB | 24576 MB | 49152 MB |
| 16 GB | 32768 MB | 65536 MB |
| 32 GB | 32768 MB | 65536 MB |

**说明**：最大大小设大**不会马上占你硬盘**——Windows 是按需增长，只有实际用到才占空间。所以别怕设太大，怕的是**初始值设太小**（这就是你之前还报错的原因之一：初始值小，Windows 来不及扩展）。

## 设之前先确认两件事

- **那个盘剩余空间 ≥ 你设的最大值**（比如设 65536MB 最大，盘里最好留 70GB 以上）。空间不够 Windows 会直接拒绝保存。
- 页面文件**别放机械硬盘**，放 SSD，不然就算设大了也卡。

## 设完怎么验证生效

重启后进游戏前，任务管理器 → 性能 → 内存 → 看「**已提交**」后面的上限（应是 内存 + 页面文件 的总和）。如果上限变大了，就说明设成功了。

一句提醒（不啰嗦）：如果加到 32GB 初始/64GB 最大还报，那就不是虚拟内存的事了，是物理内存不够 + 游戏瞬时吃太快，页面文件补不上——到那一步再加内存条才能根治。但先按上面加，多数情况能压住。
