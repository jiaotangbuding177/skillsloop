查清楚了！你的记忆基本没错，但有个关键细节要纠正：**百度不是"办"了那个榜单，而是在那个榜单上拿了第一**。具体情况如下：

## 📊 DeepResearch Bench 是谁办的？

**不是百度办的**，是中科大（USTC）+ Metastone 科技团队发布的学术评测基准（论文 arXiv:2506.11763，2025年6月），后来交给 **AGI-Eval 评测社区**长期维护。

它的特点：
- **100个博士级研究任务**（中英文各50条），覆盖22个学科
- 由领域专家设计，不是"今天天气怎么样"那种简单题
- 从全面性、洞察力、指令遵循度、可读性四个维度打分（RACE 框架）
- 开放提交制——任何厂商都能报名参赛，相当于一个"全球争霸赛"

## 🏆 百度确实在这个榜单上大出风头

**2026年2月4日**：DeepResearch Bench 公布最新结果，**百度千帆深度研究 Agent 直接登顶**，第一、第二名都被百度包揽（千帆深度研究 Pro / 千帆深度研究），超越 OpenAI、Gemini、Claude 的同类产品。当时媒体标题都是"百度出手，捅破Deep Research全球天花板"。

**2026年5月**：百度搭子 **DuMate 以 58.03 分拿下 DeepResearch Bench 第一**，随后在升级版 **DeepResearch Bench II 上又以 61.95 分登顶**（领先 iFlow-Researcher、华为小艺 DeepResearch、NVIDIA-AIQ 等）。

## 🎯 那你记忆里的"比赛"可能是这个

百度自己办过的是 **"百度搜索·文心智能体创新大赛"**（2024年，总奖金近50万），里面有"基于多工具调用的开放域问答智能体构建"这类技术赛道——是办给开发者参赛的，和 DeepResearch Bench 这种厂商产品评测榜是两回事。

---

**一句话总结**：你记的应该是「百度在 DeepResearch Bench 全球深度研究榜单上拿了第一」这件事（2026年2月千帆、5月搭子 DuMate 两次登顶），榜单本身是学术机构办的开放评测，不是百度办的比赛。需要我深挖某一轮的具体成绩对比吗？

## 📍 榜单地址（4个入口）

| 入口 | 地址 | 说明 |
|---|---|---|

| **AGI-Eval 社区** | https://agi-eval.cn（微信小程序搜"AGI-Eval模型评测"） | 官方合作维护方，评测入口更友好 |

升级版 **DeepResearch Bench II**（132个任务、9430条专家rubric）榜单在：https://agentresearchlab.com/benchmarks/deepresearch-bench-ii/index.html

## 📮 怎么参与（官方提交流程）

**方式一：邮件提交（官方正式渠道）**

把材料发到这两个邮箱：
- `***@***`（中科大杜明轩，一作）
- `***@***`（中科大李睿哲）

需要准备 **3样材料**：
1. **一个临时的 GPT-5.5 API Key** —— 只用于官方验证评测，评测期内保持有效（支持 OpenAI 官方或 OpenRouter）。⚠️ 注意：2026年6月1日起评测模型已从 Gemini-2.5-Pro 全面切换到 GPT-5.5，旧key不再受理
2. **原始生成的研究报告**（raw generated articles）—— 格式要和基准数据一致，参考 `data/test_data/raw_data/claude-3-7-sonnet-latest.jsonl`（JSONL 格式，100个任务各一篇）
3. **可复现性链接** —— 证明你的系统能稳定复现成绩

**方式二：AGI-Eval 平台（更省事）**

DeepResearch Bench 已入驻 AGI-Eval 评测社区，可以直接在平台上跑评测拿分，不用自己搭全套环境，适合先快速摸底。

## 🛠️ 本地先自测（推荐路径）

官方 GitHub 仓库给了完整工具链，NVIDIA 等厂商也是这么跑的：
1. `git clone` 仓库，装依赖（`requirements.txt`）
2. 用 `run_benchmark.sh` 在本地100个任务上跑你的 agent，生成报告
3. 用官方 RACE（报告质量）+ FACT（引用准确性）双框架打分
4. 分数满意了 → 按上面流程邮件提交，进正式榜单

---

**简单说**：榜单是中科大团队维护的开放评测，不设报名门槛，谁都能提交，跑分进榜。关键是你的 deep research agent 得先在100个博士级任务上跑出报告，然后拿 GPT-5.5 key 找官方核验。要不要我帮你把 GitHub 仓库里的评测脚本流程扒得更细一点？
