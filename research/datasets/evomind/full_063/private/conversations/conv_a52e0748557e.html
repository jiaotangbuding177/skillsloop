股权转让的会计分录因转让方和受让方的身份、股权比例、转让价格与账面价值的差异等因素而有所不同，以下是常见场景的分录处理。

## 一、转让方（出售方）的账务处理

### 场景 1：作为长期股权投资核算（成本法 / 权益法）

**转让部分或全部股权时**，按处置长期股权投资处理：

```
借：银行存款                                   （收到的转让价款）
    长期股权投资减值准备                        （如有计提的减值）
贷：长期股权投资 — 投资成本                     （账面余额）
    长期股权投资 — 损益调整                     （如有，可能在借方）
    长期股权投资 — 其他权益变动                 （如有，可能在借方）
    投资收益                                   （差额，损失则在借方）
```

同时，**结转原计入其他综合收益 / 资本公积**的部分：

```
借：资本公积 — 其他资本公积                     （原权益法下确认的）
    其他综合收益
贷：投资收益
```

> 📌 若转让后**丧失重大影响**（如权益法→金融资产），剩余股权需在丧失控制权日按公允价值重新计量，差额计入投资收益。

### 场景 2：作为金融资产核算（交易性金融资产 / 其他权益工具投资）

```
借：银行存款
贷：交易性金融资产                              （账面成本）
    投资收益                                   （差额）
```

若为**其他权益工具投资**，原计入其他综合收益的累计利得/损失需转入留存收益（**不转入当期损益**）：

```
借：其他综合收益
贷：盈余公积 — 法定盈余公积
    利润分配 — 未分配利润
```

---

## 二、受让方（购买方）的账务处理

### 场景 1：取得控制权（企业合并）

- **同一控制下**（同属一个集团）：

```
借：长期股权投资                              （按最终控制方合表净资产份额）
    资本公积 — 股本溢价                        （差额，可能在贷方）
    盈余公积                                   （差额，资本公积不足冲减时）
    利润分配 — 未分配利润
贷：银行存款                                   （实际支付对价）
```

- **非同一控制下**：

```
借：长期股权投资                              （支付对价的公允价值）
贷：银行存款
```

### 场景 2：取得重大影响（权益法）

```
借：长期股权投资 — 投资成本                    （支付对价 + 直接相关费用）
贷：银行存款
```

若可辨认净资产公允价值份额 > 支付对价，差额计入营业外收入。

### 场景 3：作为金融资产

```
借：交易性金融资产 / 其他权益工具投资           （购买成本）
    投资收益                                  （交易费用，如有）
贷：银行存款
```

---

## 三、目标公司（被投资企业）的账务处理

股权转让是**股东层面的变动**，目标公司**一般不涉及损益类分录**，仅需变更实收资本的明细科目：

```
借：实收资本 — 原股东
贷：实收资本 — 新股东
```

若涉及**注册资本变更**或有**资本溢价转增**，再相应调整资本公积。

---

## 四、特殊情形

| 场景 | 处理要点 |
|------|----------|
| **溢价转让** | 转让方确认投资收益（或资本公积变相处置），受让方按实际成本入账 |
| **折价转让** | 转让方确认投资损失；受让方需按公允价值判断是否涉及企业合并的"廉价购买" |
| **股权代持还原** | 按实际权属调整，通常不确认损益，仅做名义股东的变更 |
| **股权置换** | 非货币性资产交换，按公允价值计量，确认换出股权处置损益 |
| **涉及对赌条款** | 转让价款含或有对价的，受让方需确认金融资产/负债，后续按公允价值计量 |

---

## 五、实务提醒

1. **税务优先** — 先处理印花税（股权转让书据，万分之五）、企业所得税/个人所得税的申报
2. **资产评估** — 非关联方转让、国资背景的转让通常需要评估报告
3. **工商变更** — 分录做完后及时完成股东名册及工商变更
4. **合并抵消** — 若转让前后均在合并范围内，合并层面的抵销处理不同
