**"法人扫码"= 目标主体法定代表人扫码刷脸授权。** 是微信小程序主体变更流程里的一道身份验证环节，具体是这样的：

## 它在流程里的位置

主体变更提交资料后，会到**"授权验证"**这一步。微信给两条路二选一：
- **路径A：法定代表人扫码验证**（就是"法人扫码"）
- 路径B：上传公证书

选 A 的话，系统生成一个二维码，**由新主体（接收方）的法定代表人**用自己**实名认证的微信**扫这个码 → 跳转到人脸识别页面 → 刷脸通过 → 完成授权。作用是确认"法人本人知情并同意这次变更"，防止主体信息被冒用。扫脸不通过（比如微信实名和法人身份证对不上、工商数据拉取失败）就只能转路径B。

注意区分两个动作：
- **法人扫码** → 目标主体法定代表人本人，证明"主体愿意接收"
- **管理员扫码确认** → 账号操作人，审核通过后 7 天内点确认，这是最后一步

## ⚠️ 但你的场景（变成高校）大概率走不了"法人扫码"

这是关键点，几个常年做主体变更的代办机构口径一致：

> 双方主体中**有一方是事业单位、政府机关、社会团体等非企业单位时，不支持法定代表人扫码验证，必须走公证书**。

原因很简单：法人扫码验证是微信实时调取**市场监管（工商）系统**数据做比对，而高校是**事业单位法人**，法定代表人（校长）的信息不在工商库里，对不上，所以系统根本不给你这个选项。

也就是说：**不用纠结让校长扫码刷脸这件事**，流程上基本会强制走：
1. 下载《小程序主体变更申请函》模板，双方填好，**原公司盖公章 + 高校盖公章**（两页骑缝章）
2. 拿去**公证处做公证**（公证对象主要是双方盖章的真实性；法人可以委托经办人，不必校长亲自到场，但需学校出授权）
3. 后台提交：双方主体证件（营业执照 + 高校的**事业单位法人证书**）+ 公证书 + 服务类目资质 → 支付 300 元审核费
4. 审核通过 → **双方管理员 7 天内**点确认，超期作废、要重新公证

## 给你的实操建议

- **高校侧提前协调**：事业单位法人证书、公章盖章、公证授权这几件事都得走学校行政流程（校办/信息办/法务），高校盖章周期通常不短，建议先问学校是否有处理过公众号/小程序迁移的先例，有的话直接对接熟人效率翻倍
- **先解绑微信支付商户号**，否则流程会卡住
- 公证现在可以线上办，不用双方法人跑现场，但涉及事业单位材料会比纯企业严一些，留好时间余量
- 最终以公众平台后台实际提示为准（微信规则偶尔调整），发起后每一步照着系统要求走即可

一句话总结：**"法人扫码"是给企业主体用的快捷验证通道，你是转给高校（事业单位），基本用不上，重点把精力放在"申请函盖章 + 公证"这条路上。**

盖完章之后，你们现在处在后台流程的**"授权验证"**环节。我先帮你把这两个词拆清楚，不然容易被界面绕晕：

## 一、"授权"和"公证"到底指什么

小程序后台走到主体变更的提交环节，会出现一个**"授权验证"**选项，二选一：
- ① 法定代表人扫码验证（法人扫脸）
- ② **上传公证书验证**

因为目标主体是高校（事业单位），微信调不到工商数据，**①基本不可用，系统会引导/要求你走②**。所以：
- **"授权"** = 这个环节的名称（"授权验证"），不是要你单独再交一份授权书
- **"公证"** = 真正要办的事：拿着双方盖好章的《小程序主体变更申请函》去公证处，做**印鉴公证**（证明申请函上双方公章真实有效），拿到公证书后上传后台

额外一种"授权书"场景：办公证时双方法人**不需要到场**，但要出具《授权委托书》委托经办人去办——这个才是需要模板的东西（下面给）。

## 二、公证具体怎么做

**公证对象**：那份已盖章的《小程序主体变更申请函》（两页、骑缝章）

**材料清单**：

| 材料 | 公司侧（原主体） | 高校侧（目标主体） |
|---|---|---|
| 主体证件 | 营业执照 | 事业单位法人证书 |
| 法定代表人证件 | 法人身份证正反面 | 校长身份证正反面（有些公证处接受法定代表人名章替代签字） |
| 委托材料 | 法人签字的授权委托书+公章 | 校长签字的授权委托书+学校公章 |
| 其他 | 经办人身份证、小程序主体信息页截图（含AppID、主体名） | 同左 |

**办理渠道**（二选一）：
- **线下**：任一公证处都能办，全国通用不限定属地，提前电话确认材料，双方经办人带齐材料去，几百元公证费，一般 3-5 个工作日
- **线上**：微信里搜线上公证服务（如"一点证""慧办好"等小程序，均为正规公证处线上入口），上传电子材料 + 法人/经办人刷脸核验，最快 1 个工作日出电子公证书，微信认可电子版

**拿到公证书后**：回小程序后台 → 授权验证处选"上传公证书"→ 上传公证书扫描件 + 盖章申请函 → 支付 300 元审核费 → 等审核（1-7 个工作日）→ 通过后**双方管理员 7 天内**点确认链接，超期作废需重新公证 ⚠️

## 三、授权委托书模板（给经办人用）

> ⚠️ 高校侧提醒：大学校办通常有**标准授权委托书格式**（对外事务都要过法务），优先问学校校办/信息办要他们自己的模板，别自己造。没有的话用下面这份：

## 四、给你的落地顺序

1. **高校侧**：找校办/信息办要授权委托书模板 + 事业单位法人证书复印件，问清楚他们以前办没办过公众号/小程序公证（华师大这类学校信息办大概率办过，有现成路径）
2. 确认后台当前显示的验证方式——如果系统仍显示"法定代表人扫码验证"，先别急着交钱，联系微信客服（公众平台右下角）说明事业单位场景，确认走公证通道
3. 材料齐了选线上公证（快），出证后立刻上传后台提交
4. 盯紧审核结果，**提前跟双方管理员打好招呼**，7 天确认窗口别错过

基本可以，但有 **3 个前提**，其中第一个最关键：

## 前提 1：你手里这份必须是微信官方模板的《小程序主体变更申请函》

微信只认它自己后台下载的模板（两页、内容不可改、双方盖章+骑缝章）。如果你是自己在后台下载填写盖章的 ✓ 没问题；但如果你说的"转让协议"是**自己拟的协议/合同**，那公证了微信也不认，必须去后台重新下载官方模板。**先确认这一点。**

## 前提 2：线上办不等于寄原件，要的是高清扫描件

线上公证流程是：上传扫描件 → 公证处核验 → 法人/经办人刷脸 → 出**电子公证书**。纸质盖章原件自己留好备查（不用寄出）。

需要上传的完整材料：
- 盖章的申请函（两页拼一起、四角完整、章要清晰）
- 营业执照 + 高校**事业单位法人证书**
- 双方法人身份证正反面
- **授权委托书**（如果法人和校长不亲自刷脸，就得先签好这份，见上一条模板）
- 小程序后台主体信息页截图（含名称、AppID）

## 前提 3：授权委托书要提前签好

线上公证时"法人不方便配合"就选委托路径，上传委托书由经办人刷脸即可。**先跟学校把委托书办出来再提交**，不然会被打回补材料。

## 操作步骤

1. 微信搜线上公证服务（"一点证""慧办好"等，都是正规公证处线上入口）→ 选"小程序主体变更公证"
2. 按提示传上面材料 → 核验 → 等出证（最快 1 个工作日，一般几百元）
3. 拿到电子公证书 → 回小程序后台"授权验证"处选**上传公证书** → 传公证书+申请函 → 付 300 元 → 提交审核

## ⚠️ 两个容易卡住的点，提前准备

1. **审核中会有电话核验 + 对公账户小额打款**：选了公证验证后，微信的审核机构会电话联系管理员，并要求提供**目标主体（高校）对公账户**，往里面打一笔几分钱的小额款验证真实性。高校对公账户要走学校财务流程，**建议现在就找学校（信息办/财务）打招呼**，约定好：账户信息谁提供、收到陌生小额入账后谁来确认。这一环在高校场景最容易拖时间。

2. **7 天确认窗口**：审核通过后，原、新双方管理员都要在 7 天内点确认链接，超期整个流程作废、公证书失效要重办。提前和两边管理员说好。

所以流程上就差：**确认是官方模板 → 签委托书 → 线上公证 → 上传交钱 → 等审核**。材料齐的话，快的话一周内能走完。

这个思路有个关键误区，我得先帮你拆掉：**小程序没有"迁移"功能，公众号才有。**

## 微信的规则是这样的

- **公众号（订阅号/服务号）**：支持"账号迁移"——A 号整体迁到 B 号（B 号必须已注册），A 号被回收
- **小程序**：**不支持账号迁移**，换主体只有一条官方通道，就是你们现在在办的**"小程序主体变更"**（AppID 不变、代码数据不变，只换"户口本"）

所以"让华师大重新申请一个号，把小程序迁过去"这个动作，在微信体系里**不存在**。华师大新申请的小程序，无法承接现有小程序的任何东西——用户、openid、支付商户、订阅消息、代码全部接不过去，只能**从零重新开发上线**。

## 两条路成本对比

| | 方案A：主体变更（现路径） | 方案B：华师大新申请+重开发 |
|---|---|---|
| AppID / 代码 | 不变 | 全换 |
| 用户数据 | 保留 | 清零，导数据是噩梦（openid体系不同） |
| 微信支付 | 换绑商户号 | 重新签约、重新审核 |
| 类目资质 | 重新核一次 | 全部重新申请 |
| 周期 | 1-2 周 | 按月起 |
| 成本 | 公证费几百元+300元 | 开发+迁移+资质，六位数起步 |

而且注意：主体变更**根本不需要华师大预先注册任何账号**——目标主体没有账号也能变，全程在你现有小程序后台操作。所以"让华师大申请新号"这个前置动作，在正确路径里本来就不存在。

## 说句实在话

你现在觉得麻烦，其实是因为卡在高校侧协调（盖章、公证、对公账户），这些动作**跑完一次就永久生效**，之后华师大主体下再有任何小程序要变更，流程全通。而方案B是把一个 1-2 周、几千块的事，换成一个月起步、重新开发的事——**绕远路躲小坑**。

剩下真正要做的就 3 件事：
1. 让华师大校办出**授权委托书**（问他们要模板，一天能搞定）
2. 线上公证（材料你都有，1 个工作日出证）
3. 上传+300元+等审核，通过后双方管理员 7 天内点确认

要不要我把给华师大对接人（信息办/校办）的沟通话术写出来？把要他们配合的三件事一次说清楚，你直接转发就行。
