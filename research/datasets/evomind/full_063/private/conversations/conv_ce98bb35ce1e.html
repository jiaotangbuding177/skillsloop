## 一、赛制关键点（先别踩坑）

- **8分钟汇报+演示，超时直接掐断**——这是最大风险，必须练到 7:30 以内，留 30 秒缓冲
- **12分钟专家质询**——质询时间比汇报还长，答辩才是决胜局
- 抽签定顺序：抽到**前几个**，评委精神好但标准严；抽到**后面**，评委疲劳，前30秒没抓住注意力就悬了
- 赛场只提供基础投影+音响，**自带笔记本+U盘双备份**，PPT存PDF版兜底

## 二、8分钟时间分配（照着练）

| 时间 | 内容 | 要点 |
|---|---|---|
| 0:00–0:30 | **开场一句话** | 别念标题！直接甩数据（话术见下） |
| 0:30–1:30 | 痛点+赛题响应 | 城乡不均衡、教师负担重，点名"响应赛题四" |
| 1:30–3:00 | 产品方案 | 备教练评研管全流程，教师/学生/管理三端各一句 |
| 3:00–4:00 | 技术壁垒 | 端云协同+多智能体+自采数据资产，**点到为止** |
| 4:00–5:00 | 应用数据+**演示** | 增长曲线 + 60秒内演示一个闭环 |
| 5:00–5:45 | 贵州落地 | 三阶段路径+首期目标数字 |
| 5:45–6:30 | 商业模式+财务 | 三档产品+560/1800/4200万 |
| 6:30–7:00 | 团队+收尾金句 | 科研产品交付一体化，一句slogan结束 |
| 7:00–7:30 | **缓冲** | 宁可早结束，绝不超时 |

## 三、开场30秒话术（背下来）

> "评委老师好。我们的平台已经入驻国家智慧教育平台，服务了全国33省、3162所学校、6.2万用户——过去5个月，学校数从520家增长到6180家。今天我们带来的，是把这套经过国家平台验证的能力，端云协同下沉到贵州城乡课堂的方案。"

**为什么要这么开场**：全场200个项目里，"真实用户增长曲线"是稀缺品，多数项目还在概念阶段。先立住"我们是真用过、真增长"的标签。

## 四、必须突出的3个数字

1. **520 → 6180**（5个月12倍增长）——比"覆盖33省"有冲击力10倍
2. **贵州已有7k+用户**——这是你"本地化"的最好证据，评委最怕上海团队来贵州"讲故事"
3. **10+顶会论文 + 5发明专利 + 12软著 + 20+省部级荣誉**——学术背书是华师大团队独有的，别人抄不走

## 五、演示建议（最容易翻车的一环）

- **只演示一个闭环**，比如"错题诊断 → 生成个性化学习任务"，控制在60秒内
- **准备录屏视频兜底**：赛场网络差、设备不兼容都可能让现场演示失败，视频最保险
- 演示前说一句"给大家看真实系统的实际操作"，比纯PPT可信度高一个档次

## 六、12分钟质询：高频问题+应答要点

这是决胜局，提前把答案写下来练：

**1. "你的用户数据怎么来的？3162所学校是什么性质？"**
→ 国家智慧教育平台AI实验场入驻（官方背书）+ 真实学校教师注册使用。准备好学校名单案例。

**2. "和科大讯飞、希沃这些巨头比，你凭什么？"**
→ 不打正面战：他们做通用智慧教育，我们做**教学全流程闭环+端云协同下沉县域**，讯飞在一体机上有布局但县域低网环境的轻量化部署是我们的差异化。参考你PPT里的四类对比。

**3. "为什么上海华师大的团队来做贵州？"**
→ 三层：①政策——贵州是"东数西算"枢纽，算力+教育普惠是国家战略；②联通赛题——云网边安协同正好是贵州新基建强项；③已落地——贵州已有7k+用户，不是从零开始。**这题答好了，就从"外来者"变成"共建者"。**

**4. "560万营收从哪来？"**
→ 拆结构：软件订阅+私有化部署+一体机+培训，首期10-20所试点学校对应收入模型。准备好单校客单价数字。

**5. "未成年人数据合规怎么做？"**
→ 端云协同本身就是答案：敏感数据本地处理不上云、分级授权、等保合规。你PPT第14页有专门一页，答辩时主动讲。

**6. "种子轮融了多少？下一轮什么时候？"**
→ PPT没披露金额，但**评委大概率会问**，一定要提前统一口径，别现场商量。

**7. "和联通具体怎么合作？"**
→ 出题方是联通！明确说出合作形式：联通云+边缘节点+区域看板，共建"AI教育云网融合样板"。这题答好是送分题。
