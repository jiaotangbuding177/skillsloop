**🎨 设计要点（按 frontend-design 技能方法论落地）**
- **设计令牌**：蓝绿渐变主色 `#2E6BFF→#14B8A6`、暖阳黄 `#FFB020`（星星/印章点缀，负责亲和力）、薄荷底色、深海墨蓝正文
- **字体双轨**：标题/品牌用圆润的「站酷快乐体」，正文用「Noto Sans SC」；离线时自动回退系统字体
- **签名元素**：整套"作业本 + 老师印章"校园器物语言——网格纸纹理背景、练习册式课程卡片（彩色书脊+虚线印章徽标）、贴纸式区块眉标
- **科技感**：Hero「知识星球」纯 CSS 插画（轨道环绕+浮动图标）、深色星空面板承载进度看板，形成明暗节奏反差

**🧩 功能模块**
1. **顶部导航**：Logo、课程分类（悬停下拉：小/初/高/素养）、名师、学习进度、搜索框、个人中心（下拉菜单）
2. **Banner 轮播**：纯 CSS 自动轮播 3 张幻灯（暑期季/限时折扣/AI 错题本），各带主次 CTA、指示点同步动画、hover 暂停、`prefers-reduced-motion` 降级；下方 300万+/5000+/98%/200+ 数据信任条
3. **三大模块**：热门课程 4 张练习册卡片（价格/星级/印章）· 名师介绍 3 位（认证徽章/好评/学员数/预约试听）· 学习进度看板（今日待办勾选、6.5h/7天/328 数据块、conic-gradient 完成环 60%、语数英进度条、继续学习 CTA）
4. **页脚**：品牌+三列链接+版权/备案/客服热线

**📱 响应式**：PC 4 列 → 平板 2 列（搜索收为图标、名师 2×2 补位卡、看板纵向堆叠、插画缩小 20% 保证首屏数据完整）。另含键盘焦点可见、锚点滚动偏移等细节。
