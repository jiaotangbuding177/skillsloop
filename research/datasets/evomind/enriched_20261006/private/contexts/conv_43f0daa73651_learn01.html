## 第1点：主体与业务类型错配

**协议文本核实**：
- 签约主体是 **Yunfeng Asset Management Limited（4/9号牌持牌主体）**，序言明确其持第4类（就证券提供意见）+第9类（资产管理）牌照；

- 而你们此前谈的商业架构是：**Yunfeng 用1号牌主体供 SPC 开立券商账户并交易**——这是"就证券交易"（Type 1 dealing）业务，属于**另一个牌照、另一个法律实体**。

**风险提示**：如果签了这份咨询协议、实际做的是交易通道，会同时踩两个坑：
1. **牌照合规**：4/9号牌主体收钱却干1号牌的活，SFC 可能认定超范围经营/未持牌从事受规管活动；反过来如果只是通道，SPC 开户和交易的实际对手方应是1号牌主体，签约主体错了后续权责都不对；
2. **合同效力**：名为咨询、实为通道，属于意思表示与真实安排不符，可能被认定缺乏真实对价甚至虚假交易。

**建议**：先让对方书面确认商业实质，三选一——
- **纯通道** → 与 **1号牌主体** 签经纪服务协议（佣金制）；
- **真咨询** → 明确咨询服务的具体内容、交付物和费用对应关系；
- **资产管理** → 那是另一套全权委托协议（含托管安排），费用模式才匹配。

## 三、方案一的风险点 ⚠️

1. **集合投资计划（CIS）定性风险——最关键**：如果五名客户的资金都投进这一个 SPC，由第三方操作户口、YAML 提供建议、利益按比例分配，就非常接近 SFO 定义的"集体投资计划"（参与者出资、收益汇集、财产由运营者管理、参与者无日常控制权）。一旦被认定为 CIS，**未经认可的 CIS 不得向公众推销**，且管理 CIS 资产需要 9号牌。规避的关键：SPC 必须是**真正以自己的名义、自主决策投资的公司**（股东只是股东，不是计划参与者），决策流程、签核权限、利益分配全部落到 board resolution / mandate letter——方案里这点写对了，但**实操中"第三方操作户口"是谁、有无决策权，是定性分水岭**；
2. **第三方操作户口的牌照问题**：如果该第三方是外部人员、替 SPC 做交易决策或代客下单，可能构成未持牌从事受规管活动；如果只是 SPC 自己授权的高管/员工按董事会授权操作，则是公司自身投资，相对安全。**这个第三方的身份必须确认**；
3. **附注与方案一自相矛盾**：附注说"客户资产均以客户自身名义持有"，但方案一里资产在 **SPC 名下**、客户只持有股权——这句话只适用于方案二。资产在 SPC 名下意味着客户要承担 SPC 层面的债权人风险、税务风险和治理风险；
4. **SPC 需要香港银行户口 + 满足 YSL 的 KYC/AML**：银行和券商都会穿透查 UBO，五名客户的背景信息都会暴露在开户环节；
5. **专业投资者门槛表述需核实**：方案写"净资产超过 100 万美元"，但香港法下公司类 PI 的门槛是**总资产或投资组合不少于 800 万港币**（100 万美元约 780 万港币，**略低于法定门槛**），个人类 PI 是组合不少于 800 万港币。建议按法定标准核实，别按 100 万美元卡。

## 四、方案二的风险点 ⚠️

1. **执行环节的牌照边界**：流程是"YAML 给建议 → 客户确认 → RO 审批 → Trader 向 YSL 下单"。如果这个 Trader 是 **YAML 的人**、替客户把单下到 YSL，那 YAML 就做了"证券交易"（**1号类**受规管活动）——而 YAML 只有 4/9号牌，草案序言里也只写了 4、9 类。**必须确认下单执行方是 YSL（1号牌）的 Trader**，否则 YAML 要补 1号牌或调整流程；
2. **Group order 分配**：五客户同买卖同一资产用 group order 没问题，但必须有**事先书面订明的公平分配政策**（SFC 行为准则要求），且要防利益冲突（如自营盘与客户单混在一起、抢先交易等）；
3. **成本高**：5 套 KYC、5 份协议、5 个户口，方案二收费更高就是这个原因；
4. 优点：无 CIS 风险、资产各自名下、客户直接收 YSL 的日结单/月结单，**监管上最干净**。

**③ 协议与费用层面**
- IAA 是纸面安排：实际决策是合世家做的，出了问题（亏损、客户投诉），客户可以主张合世家虚假陈述/欺诈，YAML 则会说"我们只是顾问"——**责任全落在合世家身上，费用却要照付**；

## 五、合规的出路（按可行性排序）

1. **合世家（或海外关联方）自己拿牌**：申请 SFC 9号牌（资产管理）+ 视需要 1号牌，由合世家作为合规的投资经理，YSL 只做执行经纪——这才是"借用通道"的正规形态（持牌管理人 + 持牌券商），但申请周期约 6–12 个月，成本不低；
2. **如果海外已有持牌实体**（如新加坡/开曼持牌基金管理人）：由该持牌实体担任 SPC 的投资经理，合世家作为其境内服务方（研究、运营支持），YSL 执行——但**合世家仍不能直接操盘客户资金**；
3. **只做介绍人（introducer）**：合世家把客户介绍给 YAML/YSL，由 YAML 真正提供顾问服务、YSL 执行。但介绍人不能接触客户资金、不能给投资建议、不能经手交易，且介绍费安排需符合 SFC 要求——**如果你们的商业价值就是"操盘"，这条路等于放弃核心业务**；
4. **资金性质改变**：如果这些资金是合世家**自有资金**（而非客户资金），SPC 自有资金投资不需要持牌，结构就简单得多——但客户资金这条路走不通。

这个改动方向**对了一半**——它把 YAML/YSL 这一侧的流程做实了（纸面与操作一致），但**没有解决最根本的问题：合世家在替客户做投资决策**。我拆开说。

## 一、这个流程改动解决了什么 ✅

"YAML 提建议 → 客户确认 → RO 审批 → Trader 下单"是**标准的非全权委托（non-discretionary）咨询流程**。如果按这个流程真实运行：

- YAML 不再"收钱不干活"——它真实提供了建议，IAA 不再是纸面安排；
- YSL 侧的执行链清晰（建议、确认、审批、执行各环节留痕）；
- 之前担心的"YAML 收了顾问费却没服务"的合规硬伤被补上了。

**但有两个前提必须确认：**

1. **RO 和 Trader 是谁的人？**
   - RO 必须是 **YAML 的持牌负责人**（这是 YAML 内部合规流程，没问题）；
   - **Trader 如果是 YAML 的人**、替客户往 YSL 下单 → YAML 在从事"证券交易"（1号类受规管活动），但 YAML 只有 4/9号牌 → **需要补 1号牌**；
   - **Trader 如果是 YSL 的人**、按客户确认的指令执行 → 干净，YSL 的 1号牌覆盖。
   - 这个必须向 YSL 书面确认。

2. **建议从哪来？** 这是关键中的关键——见下。

## 二、这个流程改动解决不了什么 ❌

**根问题没变：客户资金打进开曼 SPC、SPC 由合世家控制、投资观点实际由合世家产生。**

判断这个结构合不合规，SFC 只看一个问题：**"谁在实质上决定买什么、卖什么？"**

- 如果投资观点**仍然由合世家产生**，只是把观点发给 YAML、YAML 包装成"建议"、合世家再"确认"——这就是**fronting（借壳）**，纸面流程再完整，实质还是合世家的决策。SFC 看实质不看形式，这比不签协议更危险（白纸黑字的"确认"流程反而成了明知故犯的证据）；
- 如果投资观点**由 YAML 真实产生**、合世家只做"采纳/否决"和操作执行——那合世家就不是投资决策者，结构可以成立。**但代价是：合世家放弃操盘权**，只做运营方。

**你们要的"操盘权"和"合规"在本质上冲突**——除非合世家自己拿牌，否则没有一个流程设计能让"无牌方实际决定交易"变得合规。

## 三、还有一个没解决的底层问题：SPC 池子

无论流程怎么改，**海外客户资金 → 合世家控制的 SPC → 合世家运营**这个底座没变：

- 多名客户的钱进一个 SPC，由合世家运营 → **CIS（集合投资计划）定性风险**依然在；
- 合世家若向 SPC 收"管理费/服务费" → 就是替客户管钱收费 → 坐实无牌资管；
- 客户持有 SPC 股权而非资产 → 客户资金安全完全依赖合世家信用。
