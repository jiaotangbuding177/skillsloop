## 事实澄清

**毕赤酵母（Komagataella phaffii）早已有无甲醇工艺，且是行业主流做法之一：**
- 传统毕赤用 AOX1 启动子（需甲醇诱导），但工业界普遍改用**无甲醇方案**：
  - **GAP 启动子**（组成型，葡萄糖/甘油驱动）——最经典；
  - **PGCW14（PUPP）等强组成型启动子**——BioGrammatics 用于 IgG-Fc 生产（文献：*Human IgG Fc Production Through Methanol-Free Pichia*）；
  - **改造型 AOX1 启动子/合成启动子**——VALIDOGEN "UNLOCK PICHIA" 明确"无甲醇诱导"，并报道植酸酶无甲醇条件 20 g/L；
  - Eppendorf 亦有 pUPP 无甲醇补料分批方案（仅甘油碳源）。
- **安睿特（通化安睿特）用毕赤酵母做重组人白蛋白、无需甲醇诱导，完全符合行业现状**——这一点是我此前把"毕赤=必须甲醇"当成了通用事实，属于**过时概括，应予纠正**。

## 这个更正意味着什么（哪些结论要改）

**① "无甲醇"不再是 KM 对毕赤的差异化卖点。** 它只能作为"相比传统 AOX1 工艺"的对比，而不是针对安睿特这类现代毕赤工艺的优势。

**② KM 与毕赤的真正差异，应重新落到这几点：**
| 维度 | KM 的差异化是否成立 |
|---|---|
| 无甲醇 | ✗ 不成立（毕赤已有无甲醇工艺） |
| **食品级/可食用底盘、全细胞/活菌场景** | ✓ 成立（毕赤菌体不可食用；KM有GRAS+中国食品菌种名单基础）——**这是最硬的差异** |
| **人源糖型（对糖蛋白）** | ✓ 成立（毕赤人源化需GlycoSwitch授权；高甘露糖型） |
| 生长速度/迭代效率 | ✓ 成立（倍增约50分钟 vs 毕赤约2-4小时） |
| 高密度发酵/分泌量成熟度 | △ 毕赤更成熟（10-40 g/L级分泌），KM需验证 |
| 自主IP | ✓ 成立 |

**③ 具体到安睿特这个对手：** 他们的 rHSA 是**无糖蛋白**（用不上糖型卖点），且已俄罗斯获批、国内III期揭盲、50吨产能——所以对 HSA 品类，KM 的可打点只剩"成本/供应链/食品级场景"，我此前"甲醇"这一条要从竞争页删除。（另注：安睿特宣传"纯度99.999999%"属营销口径，无法核实。）
