退回投资款的账务处理，核心看两点：**① 公司性质**（有限公司还是合伙企业）**② 是否溢价退出**。

---

## 一、有限公司退股（减资）

### 1. 平价退回（退回金额 = 原出资额）

> 例：股东原出资100万，退回100万

```
借：实收资本——XX股东        1,000,000
    贷：银行存款              1,000,000
```

### 2. 溢价退回（退回金额 > 原出资额）

> 例：股东原出资100万，退回250万（溢价150万）

```
借：实收资本——XX股东        1,000,000
    资本公积——资本溢价      1,500,000  ← 溢价部分
    贷：银行存款              2,500,000
```

⚠️ 如果资本公积不够冲，依次冲减：
1. 盈余公积
2. 未分配利润（借：利润分配——未分配利润）

```
借：实收资本——XX股东        1,000,000
    资本公积——资本溢价        500,000  （资本公积只有50万）
    盈余公积                  300,000
    利润分配——未分配利润      700,000
    贷：银行存款              2,500,000
```

### 3. 折价退回（退回金额 < 原出资额）

> 例：股东原出资100万，退回80万（折价20万）

```
借：实收资本——XX股东        1,000,000
    贷：银行存款                800,000
        资本公积——资本溢价      200,000  ← 折价部分计入公积
```

---

## 二、合伙企业退伙

### 1. 按出资额退回

```
借：合伙人资本——XX合伙人       XXX
    贷：银行存款                 XXX
```

### 2. 溢价退回（有减持收益）

参照你之前的**清霜PND-A轮减持**案例（转让方有个税，合伙企业层面做份额减少）：

```
借：合伙人资本——XX合伙人        XXX    （原出资成本）
    贷：银行存款                    XXX
```

溢价部分实际是合伙人的财产转让所得，**合伙企业本身不确认损益**，由合伙人按"经营所得"或"财产转让所得"缴个税。

---

## 三、实质大于形式：怎么看是不是"退回投资款"

有些情况表面是"退回投资款"，实质是：

| 表面形式 | 实质判断 | 会计处理 |
|---|---|---|
| 退回投资款 | 实为利润分配 | 借：利润分配——应付利润 / 贷：银行存款 |
| 退回投资款 | 实为股东借款收回 | 借：其他应付款——XX股东 / 贷：银行存款 |
| 退回投资款 | 实为关联方往来 | 借：其他应付款——XX公司 / 贷：银行存款 |

---

| 事项 | 说明 |
|---|---|
| **是否需要缴税** | 平价退回，有限合伙层面不产生所得，不交税；对方有限公司收回投资成本，也不涉及损益，不交税 |
