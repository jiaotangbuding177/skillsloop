## 📋 PRD 核心内容概览

完整文档覆盖了 8 个部分，这里说几个关键点：

### 🎯 产品定位
把华师大论文查重从「学生自己找平台 → 跑结果 → 截图给导师」的割裂流程，变成**校内一站式闭环**：登录 → 提交 → 检测 → 报告（带公章水印）→ 教师审阅。

### 👥 三端核心功能

| 角色 | 核心流程 |
|------|----------|
| **学生** | SSO登录 → 4步提交向导 → 异步等待 → 预览/下载报告 |
| **教师** | 多渠道通知（站内信+短信+邮件）→ 在线审阅 → 下载PDF → 填写意见 |
| **管理员** | 全局看板 → 进度监控 → 参数配置 → 数据导出 |

### 🔑 关键设计决策

- **异步检测**：不走同步等待，用消息队列解耦，学生提交完可以关页面
- **24h 教师提醒**：三次递进通知（即时 → 12h → 22h），超时自动升级给学院管理员
- **水印+公章**：PDF 自动叠加，不可编辑不可篡改，这是跟校外平台最大的差异化
- **CAS 统一认证**：全程对接华师大现有账号体系，不另外注册

### 🗺️ 发布节奏

- **6-8 周**：MVP 上线（核心流程跑通）
- **+4-6 周**：体验完善（公章、多渠道通知、审核、管理后台）
- **+4-6 周**：深度运营（高级看板、多库切换、数据分析）

### ⚠️ 关键风险

1. 公章授权需要跟校办/教务处走流程——PRD 里给了文字替代的降级方案
2. 检测引擎的选择（自研 vs 采购 vs API 对接）——这是成本和技术路线的大头
3. 域名备案 + CAS 对接都要走华师大信息中心

跟上一版最大的区别：

### 🔄 定位翻转

| | 之前 | 现在 |
|------|------|------|
| **做什么** | 毕业查重（相似度检测） | 论文数据校对 + 引用核验 |
| **谁用** | 学生交 → 教师审 | 只有教师用 |
| **流程** | 5 步（提交→检测→通知→审核→反馈） | 3 步（提交→校对→下载报告） |
| **报告** | 公章 + 水印 | 只有水印 |
| **节奏** | 查重季爆发 | 日常随时用 |

### 🎯 新定位的核心逻辑

教师写论文最怕两件事：**数据出错**、**引用不规范**。现在这两件事都靠人眼检查，费时还漏。平台让老师上传论文 PDF/Word → 系统自动扫一遍数据和引用 → 出一份带水印的校对报告 → 老师下载存档。

### 📊 校对引擎两条管线

- **数据核验**：统计数据一致性、公式推导、图表数字与正文匹配、数据范围合理性
- **引用校对**：参考文献格式、引用一致性、DOI 有效性、自引分析

### 🗺️ 三个阶段

1. **MVP（6-8周）**：上传 → 基础校对 → 下载报告
2. **增强（+4-6周）**：深度数据校对、DOI 校验、反馈标记
3. **智能（+4-6周）**：发表版本对比、质量趋势分析、批量校对
