一、岗位职责

1. 菌株发酵工艺开发与优化

负责天然益生菌与工程菌的发酵工艺开发，包括摇瓶筛选、发酵参数优化与产率提升。

优化培养基配方与补料策略，平衡活菌得率、稳定性与单位成本。

2. 发酵中试放大与过程控制

主导从实验室摇瓶到 5L / 50L / 200L 规模发酵罐的中试放大，建立可转移的工艺窗口。

管控关键过程参数（DO、pH、温度、补料速率、溶氧），保证批次间一致性与可放大性。

3. CDMO / OEM 发酵代工协作

对接外部发酵代工（如天然线 OEM 均瑶润盈等），完成工艺转移、技术审计与批次放行评估。

编制并维护向代工厂交付的工艺规程（DS），确保核心菌株资产留在公司、仅交付当前版本。

4. 菌种库与数据管理

参与菌种库（MCB / WCB）发酵相关管理，维护发酵批记录、工艺数据与偏差台账。

建立发酵数据的结构化归档，支撑 GRAS / IND 的 CMC 模块与质量溯源。

5. 合规与质量体系

编写发酵 SOP、批生产记录（BPR）与验证文件，对接 GMP / 质量管理体系要求。

配合法规与质量团队，准备中美双报（GRAS / IND）所需的发酵 CMC 证据链。

二、任职要求

微生物学、发酵工程、生物工程、生物化工或相关专业，本科及以上学历。

3 年以上发酵工艺开发或中试生产经验；有益生菌 / 乳酸菌 / 基因工程菌发酵经验者优先。

熟悉实验室至中试规模发酵设备（5L–200L 及以上）的操作与维护，了解下游离心、冻干等基本工艺。

具备严谨的数据记录与 GMP / 质量意识，能独立编写 SOP 与批生产记录。

良好的跨团队协作与沟通能力，能适应早期公司多任务、与代工厂现场协同的工作节奏。

三、优先条件（加分项）

有基因工程菌（含智能开关 / 诱导表达系统）发酵放大经验。
