## 一、直接告诉我你想看什么

### 1. AI 新闻日报

你可以说：

> 帮我整理今天的 AI 新闻，选最重要的 10 条。

我会抓取最近 1 天的公司博客、媒体、社区和中文资讯，去重后整理成中文摘要。

### 2. AI 公司动态

> 查一下最近 3 天 OpenAI、Anthropic、Google 和 Meta 有什么重要更新。

对应 `company` 分类，优先抓官方博客，适合跟踪模型发布、产品更新和公司动态。

### 3. AI Agent 专题

> 汇总最近一周 AI Agent 领域的重要动态。

对应 `ai-agent` 分类，重点覆盖 LangChain、LlamaIndex、Ollama、vLLM、Mem0 等来源。

### 4. 中文科技资讯

> 看一下最近 3 天国内 AI 媒体在关注什么。

对应 `cn_media`，主要覆盖机器之心、量子位、36氪、少数派和 InfoQ。

### 5. 最新论文

> 找最近多智能体方向值得关注的 10 篇论文。

或者：

> 查一下具身智能、RAG、世界模型最近有什么论文。

它会调用 arXiv 检索，并可按主题筛选。

### 6. GitHub 热门项目

> 看看本周 GitHub 上有哪些值得关注的 AI 项目。

可以选择今日或本周榜单，并过滤非 AI 项目。

## 二、你可以指定输出要求

建议在问题中加入下面几个维度。

### 时间范围

- 今天：最近 1 天
- 本周：最近 7 天
- 本月：最近 30 天

例如：

> 汇总最近 7 天 AI Agent 新闻。

### 数量

> 只选最重要的 8 条。

### 内容分类

可指定：

- `company`：AI 公司官方动态
- `papers`：论文和研究
- `media`：科技媒体
- `newsletter`：专家博客和通讯
- `community`：社区热点
- `cn_media`：中文媒体
- `ai-agent`：Agent 生态
- `twitter`：AI 业界人物动态
- `all`：全部来源

### 输出形式

你可以要求：

- 一句话摘要
- 详细摘要
- 按重要性排序
- 按公司分类
- 表格输出
- 投资人视角点评
- 只保留原始信源
- 附原文链接
- 区分事实与我的判断

例如：

> 抓取最近一周 AI Agent 新闻，选 10 条，按重要性排序。每条包含事件摘要、原文链接、影响判断和投资机会，不要收录纯营销内容。

这类指令最适合你。

## 四、命令行用法

当前实际安装目录带作者作用域，因此命令如下。

### RSS 新闻聚合

```bash
python3 skills/@lanyasheng/ai-news-aggregator/scripts/rss_aggregator.py \
  --category all \
  --days 3 \
  --limit 10
```

只看 AI 公司：

```bash
python3 skills/@lanyasheng/ai-news-aggregator/scripts/rss_aggregator.py \
  --category company \
  --days 1 \
  --limit 10
```

只看中文媒体：

```bash
python3 skills/@lanyasheng/ai-news-aggregator/scripts/rss_aggregator.py \
  --category cn_media \
  --days 3 \
  --limit 10
```

输出为 JSON：

```bash
python3 skills/@lanyasheng/ai-news-aggregator/scripts/rss_aggregator.py \
  --category all \
  --days 1 \
  --json
```

### arXiv 论文

```bash
python3 skills/@lanyasheng/ai-news-aggregator/scripts/arxiv_papers.py \
  --query "multi-agent" \
  --top 10
```

### GitHub Trending

今日 AI 热门项目：

```bash
python3 skills/@lanyasheng/ai-news-aggregator/scripts/github_trending.py \
  --ai-only
```

本周热门项目：

```bash
python3 skills/@lanyasheng/ai-news-aggregator/scripts/github_trending.py \
  --since weekly \
  --ai-only
```

> **小明，帮我做今天的 AI 新闻简报。**

- 时间：最近 24 小时

- 排序：按重要性，而不是发布时间
- 处理：跨来源去重
