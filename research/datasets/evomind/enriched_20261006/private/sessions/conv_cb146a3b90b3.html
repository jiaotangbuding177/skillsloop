## 一、"做中学"政策分析

**先厘清一个关键点**：你问的"教育部行动计划里的做中学"，指的是 **2026年8月初教育部刚印发的《义务教育阶段科学教育"做中学"领航行动指南》**（9月开学起实施），它并非孤立的文件，而是一条政策链的终点：

- **2022年**《义务教育课程方案和课程标准》→ 首次把"探究实践"列为科学核心素养
- **2023年5月** 十八部门《关于加强新时代中小学科学教育工作的意见》→ **首次提出"强化做中学、用中学、创中学"**
- **2025年1月**《教育强国建设规划纲要（2024—2035年）》→ 部署"加强科学教育，强化核心素养培育"
- **2026年8月** "做中学"领航行动 → 从理念升级为国家专项行动

**领航行动的硬核要求**（这是重点）：

| 维度 | 内容 |
|---|---|
| 定位 | 以学生为主体、兴趣为导向、实践为路径，回答科学教育加法"加什么、怎么加" |
| 内容 | 聚焦**真实问题**，对科学类课程深化、整合、拓展，开展跨学科探究 |
| 课时 | **4—9年级：每学期每人至少完成1个探究任务、不少于4课时**（统筹跨学科主题学习+综合实践+地方/校本课时，不增加总量）；1—3年级不另作要求 |
| 主题 | 官方给了6大参考主题：**生命健康、生态环境、地球奥秘、航空航天、新兴产业、人工智能** |
| 教学 | 项目式、探究式、场景式学习；学生是"问题提出者、方案设计者、问题解决者"；**鼓励试错、包容失败** |
| 评价 | 围绕问题意识、探究实践能力、反思改进能力、合作交流能力四维；**表现性评价记入综合素质档案，不另作考试** |

**我的解读**：这政策本质是"双减"后科学教育加法的落地抓手——加的是真实探究实践，不是课时和负担；直击当前课堂"老师演示、学生看实验"的痛点（官方解读文章标题就叫《从"看实验"到"做中学"》）；评价上"不另作考试要求"是个精心设计，既避免增加学生负担，又用纪实性档案倒逼学校真做探究。

## 二、中小学科学课"探究"包含什么

**1. 素养框架**：探究实践是科学课四大核心素养之一（科学观念、科学思维、**探究实践**、态度责任），课标明确"探究和实践是科学课程学习的主要方式"。

**2. 两条主线**：
- **科学探究8要素**：提出问题 → 作出假设 → 制订计划 → 搜集证据 → 处理信息 → 得出结论 → 表达交流 → 反思评价
- **技术与工程实践6要素**：明确问题 → 设计方案 → 实施计划 → 检验作品 → 改进完善 → 发布成果
- ⚠️ 注意2022版课标把**工程实践**并入了"探究实践"——科学课不只做实验，还包括设计、制作、测试、迭代

**3. 内容载体**：**13个学科核心概念**（物质科学4个、生命科学4个、地球与宇宙3个、技术与工程2个）+ **4个跨学科概念**（物质与能量、结构与功能、系统与模型、稳定与变化）。

**4. 学段进阶**：
- 1—2年级：观察感知、体验为主
- 3—4年级：简单探究、动手操作
- 5—6年级：控制变量等科学方法
- 7—9年级：完整科学探究 + 工程实践（七部门意见还细化到：初中围绕"解决真实问题"做跨学科项目式学习）

**5. 落地形态**：课堂实验教学（按《中小学实验教学基本目录（2023年版）》开全必做实验、提高探究性实验比例）、跨学科主题学习≥10%、综合实践活动、课后服务（观测/创客/项目研究）、"请进来走出去"、以及领航行动的6大主题任务。评价上实验操作已纳入中考，试题增加探究性、开放性比例。
