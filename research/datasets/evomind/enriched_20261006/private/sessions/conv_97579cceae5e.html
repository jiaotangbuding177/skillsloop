## 一、你面对的平台是什么

`deepseek-code.com/plugins` 是 **DeepSeek Harness（DSH）** 的官方插件目录——DeepSeek 的开源 Agent 运行时（"Model + Harness = Agent"）。目前 **316 个插件、8 大分类**（Development / AI & Agents / Interface / Knowledge / Integrations / Media & Vision / Workflow / Utilities），插件就是一个 GitHub 仓库 + package.json，TypeScript 为主。

**两个关键参考**（你的设计可以直接借鉴）：
- **`omdsh-dev/dsh-book2skill`**：书→技能，5 阶段长任务（fetch → parse → understand → generate → install）+ **3 个人工门控** + 浏览器时间线面板——和你"书→视频课→出题"几乎同构，是最佳架构模板
- **`Opr4Mp3r/deepseek-harness-plugin-from-scratch`**：官方认可的从零开发指南（MIT），照着学就能上手

## 二、流水线设计：`dsh-book2course`（书 → 视频课 → 出题）

### 整体架构：3 大阶段 · 9 步 · 3 道人工门控

```
┌───────── 阶段A：书 ─────────┐   ┌──────── 阶段B：视频课 ────────┐   ┌──────── 阶段C：出题 ────────┐
│ A1 解析：PDF/EPUB/MD 清洗    │   │ B1 讲稿：每节口播稿           │   │ C1 按知识点生成题目          │
│ A2 结构化：章节→知识点图谱    │──▶│ B2 分镜：画面/字幕/时长       │──▶│ C2 难度分级+布鲁姆分类       │
│ A3 课程蓝图：目标/时长/重点   │   │ B3 课件：HTML/PPT + 字幕SRT   │   │ C3 组卷+导出(JSON/MD/问卷)   │
└──────────────┬──────────────┘   └──────────────┬──────────────┘   └──────────────┬──────────────┘
          🔒 门控1：确认蓝图              🔒 门控2：抽查风格/深度           🔒 门控3：审题校准
```

### 每阶段的产物（全部落盘到工作区，可断点续跑）

**阶段 A · 书 → 知识**
- 输入：PDF / EPUB / Markdown / 网页 URL（OCR 三级探测，无硬依赖——学 book2skill）
- 产出：`knowledge-graph.json`（知识点+前置依赖+示例索引）+ `course-blueprint.md`（章节、学习目标、时长分配、难度曲线）
- 🔒 **门控 1**：你确认蓝图（删章节、标重点）后才进入下一阶段

**阶段 B · 蓝图 → 视频课**
- 每章产出 `lessons/lesson-XX/`：
  - `script.md` 口播稿（钩子开场→讲解→案例→总结）
  - `storyboard.json` 分镜（画面、字幕、动画提示、逐镜时长）
  - `slides.html` 课件（深色极简风，可复用我之前的PPT技能）
  - `subtitles.srt` 字幕（方便后续接 TTS / 剪映 / 视频合成）
- 🔒 **门控 2**：你抽查 1~2 节，调风格/深度/语速

**阶段 C · 课程 → 题目**
- 按知识点出题：选择/判断/简答/案例分析，难度 L1~L3 + 布鲁姆层级
- 每题带：答案、解析、**知识点溯源**（对应章节+视频时间戳——这是差异化卖点）
- 组卷：章节测验 / 综合卷 / 模拟考；导出 Markdown / JSON / 问卷星·Kahoot 可导入格式
- 🔒 **门控 3**：审题、去重、校准难度

### 插件组成（DSH 规范）

| 部分 | 内容 |
|---|---|
| **宿主工具** | `book_parse`、`blueprint_generate`、`lesson_generate`、`quiz_generate`、`quiz_export`、`pipeline_status` / `gate_approve`（门控） |
| **Skill** | `SKILL.md` 教 agent 按顺序跑完整条流水线 |
| **WebUI 面板** | 三阶段时间线 + 门控确认按钮（参照 book2skill timeline + dsh-task-status） |
| **配置** | `book2course.config.json`：语言、视频风格、单节时长、题量、难度分布 |

## 三、开发路线建议

1. **v0.1 MVP**：只做 Skill + 工具，无面板——agent 对话里跑通"丢一本书 → 出蓝图 → 出1节课 → 出10道题"
2. **v0.2**：门控 + 状态持久化 + 断点续跑
3. **v0.3**：WebUI 时间线面板 + 多格式导出

## 四、动手前需要你定的 4 件事

1. **输入的书是什么形态**？PDF / EPUB / 网页 / 纯文本？中文为主还是中英混合？（决定解析和 OCR 方案）

3. **出题面向谁**？自测 / 课堂教学 / 考试？导出格式有硬性要求吗（问卷星、Excel）？
4. **目标用户**：老师、UP 主、企业培训团队？这决定 UI 和交付形态。

## 🎬 这个生成器的核心能力

一句话：**丢给它一句话需求，自动产出可交付的 MP4**。

```
内容理解 → 创意简报(母题/分镜/镜头规划) → AI素材生成(gpt-image-2)
→ AI配音(Edge TTS词级时间轴) → 字幕(句/关键词/词级三模式)
→ Remotion动画 → BGM(8种预设程序合成+自动Ducking) → 预览QA → 渲染 → 成片QA
```

亮点：
- **强制 Creative Direction**：先出创意简报再动手，禁止"渐变背景+大标题"套模板，16 种场景类型防 PPT 感
- **配音反推时长**：先写口播稿 → TTS 实测 → 场景时长=配音+留白，不是硬塞
- **双 QA 门禁**：技术 QA（分辨率/音轨/卡帧）+ 创意 QA（Anti-PPT/场景多样性检查），不通过不交付
- **平台化**：无个人账号绑定，密钥全走环境变量，失败逐级降级（AI图→SVG→渐变，绝不因单点失败卡死）
