**SPAC（Special Purpose Acquisition Company）**——特殊目的收购公司。

简单说，SPAC 就是一家**什么都没有的空壳公司**，唯一要做的事就是：上市募资，然后去找一家还没上市的优质公司把它「反向收购」了。被收购的公司就借这个壳成功上市。

---

### 流程长这样：

1. **造壳** → 发起人成立一家空壳公司，没有业务，只有一份「将来要收购某家公司」的计划书
2. **募资上市** → 这个壳在美股 IPO（首次公开发行），向公众投资者募一笔钱
3. **找标的** → 壳公司拿着这笔钱，去寻找潜在的没上市的目标公司（一般要求在24个月内完成）
4. **合并（De-SPAC）** → 找到目标公司后，通过反向并购，目标公司「装进」壳里，取代壳公司的上市地位
5. **成功上市** → 目标公司从此成为上市公司，原来的 SPAC 壳完成使命

---

### 举个例子：

假设你是一家中国科技初创公司，想上市但不想走传统IPO（太慢、太贵、不确定性高）。

- 有人已经在美国造好了 SPAC 壳（代码：XXX.U），账上趴着 2 亿美元
- 你跟他谈好条件：把你这公司装进去，你拿到这 2 亿美元，同时你的股份变成上市股票
- 合并完成，你公司的股票开始公开交易 → **这就是 SPAC 上市**

---

### 为什么 SPAC 曾经很火（2020-2021）：

| 相比传统IPO | 优点 |
|------------|------|
| **快** | 传统IPO从启动到挂牌6-12个月，SPAC合并最快3-4个月 |
| **确定性高** | 传统IPO面临路演、定价、市场波动等风险；SPAC的估值和资金是锁定的 |
| **能说「故事」** | 传统IPO需要已有盈利能力或稳定收入；SPAC可以给还没盈利但前景好的公司上市 |
| **条款灵活** | 对赌、earn-out等结构可以定制 |

---

### 但也有一堆坑：

- 很多 SPAC 是赶热潮瞎搞的，标的质量堪忧
- 合并后股价经常大跌（「De-SPAC」后的公司表现普遍差于传统IPO）
- 发起人拿的股份太肥，稀释了普通股东
- 美国 SEC 近年加强了监管

商业模式画布（Business Model Canvas）是 Alexander Osterwalder 发明的，一张图把公司怎么赚钱、怎么运转说清楚。下面教你怎么画。

---

## 一、画布长什么样

一张大图分成 **9个格子**，布局如下：

```
┌──────────────┬──────────────┬───────────────┬──────────────┐
│              │              │               │              │
│  KP          │  KA          │  VP           │  CR          │  CS         │
│  重要伙伴     │  关键业务     │  价值主张      │  客户关系     │  客户细分    │
│              │              │               │              │             │
│              │  KR          │               │  CH          │             │
│              │  核心资源     │               │  渠道通路     │             │
│              │              │               │              │             │
├──────────────┴──────────────┴───────────────┴──────────────┤
│                                                             │
│  C$  成本结构                                               │
│                                                             │
│  R$  收入来源                                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**逻辑流：** 左边（怎么创造）→ 中间（创造什么）→ 右边（给谁、怎么给）→ 底下（能不能赚钱）

---

## 二、9个格子怎么填（按顺序走）

### 第一步：先填右边 — 你的客户

**7. 客户细分（CS）** — 谁付你钱？
- 你的客户是谁？大众市场还是细分 niche？
- 有没有多边市场（比如美团：一边是消费者，一边是商家）？
- 写1-3个最核心的客户群体

**5. 客户关系（CR）** — 怎么和他们保持关系？
- 一对一服务？自助？社区？订阅自动续费？
- 获客成本高不高？

**6. 渠道通路（CH）** — 客户怎么找到你、买到你？
- 线上（官网/APP/抖音）还是线下（门店/代理商）？
- 分四步：认知 → 评估 → 购买 → 售后，每一步用什么渠道

---

### 第二步：填中间 — 你的价值

**4. 价值主张（VP）** — 你帮客户解决了什么问题？
- 这是整张画布的**核心**
- 一句话说清楚：我帮谁解决了什么痛点，为什么选我不选别人
- 可以是：更便宜、更快、更好用、更安全、更有面子…

---

### 第三步：填左边 — 你怎么创造

**2. 关键业务（KA）** — 你每天在做什么？
- 产品开发？内容生产？平台运营？销售交付？
- 没有这些活动，公司就转不起来

**3. 核心资源（KR）** — 你有什么别人没有的？
- 技术专利？品牌？人才？资金？数据？供应链？

**1. 重要伙伴（KP）** — 谁在帮你？
- 供应商、渠道商、合资方、外包团队
- 哪些事你自己做不划算，必须找人合作

---

### 第四步：填底下 — 你赚不赚钱

**9. 收入来源（R$）** — 钱从哪来？
- 卖产品？收订阅费？广告？抽成？授权费？
- 定价方式：一口价、按使用量、按效果

**8. 成本结构（C$）** — 钱花在哪？
- 研发、人力、市场、服务器、房租…
- 固定成本 vs 变动成本

---

## 三、画布画完，要检查的三个问题

1. **一致性** — 你的客户细分和价值主张对不对得上？如果客户是学生，价值主张写的是帮企业省钱，那就错了
2. **可行性** — 收入和成本算下来能赚钱吗？粗略算一下单位经济模型
3. **可持续性** — 竞争对手能不能轻松抄走？有没有护城河？
