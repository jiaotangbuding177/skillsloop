---

## 股权转让的会计分录

### 场景梳理

| 主体 | 角色 |
|------|------|
| **你公司（A）** | 转让方 —— 卖出持有C公司的股权 |
| **C公司** | 被投资公司 —— 你公司持有的股权标的 |
| **B公司** | 受让方 —— 购买你公司持有的C公司股权 |
| **价款** | **125万元** —— B公司打入你公司网银 |

---

### 分录逻辑

你公司转让C公司股权，核心会计处理为：

**① 确认收到转让款：**
```
借：银行存款    1,250,000
    贷：长期股权投资 / 交易性金融资产（原账面价值）
        投资收益——股权处置收益（差额，或借方）
```

> **关键：** 差额 = 转让价款125万 - 该股权在账上的**原始投资成本**（如果长期股权投资还有损益调整，也要冲掉）

---

### 分情况写分录

#### 情况一：按成本法核算（通常母公司对子公司）

假设原始投资成本为 **X元**：

```
借：银行存款                    1,250,000
    贷：长期股权投资——C公司          X
        投资收益——股权转让收益  1,250,000 - X
```

> 如果转让价低于成本，差额记借方（投资损失）。

#### 情况二：按权益法核算（对联营/合营企业）

假设：
- 原始投资成本 = **X**
- 持有期间实现损益调整（贷方余额） = **Y**
- 其他综合收益 = **Z**

分录：
```
借：银行存款                    1,250,000
    贷：长期股权投资——投资成本        X
        长期股权投资——损益调整        Y  （金额以贷方余额为准）
        投资收益——股权转让收益  1,250,000 - X - Y

同时，将原计入其他综合收益的部分转出：
借：其他综合收益                  Z
    贷：投资收益                  Z
```

#### 情况三：分类为交易性金融资产/其他权益工具投资

```
借：银行存款                    1,250,000
    贷：交易性金融资产——成本         X
        投资收益                1,250,000 - X
```

> 若原为其他权益工具投资，公允变动计入其他综合收益的，处置时**不得转入当期损益**，应转入留存收益。

---

### 关于"银行存款"的具体科目

你是在**企业网银**中看到款项到账，在金蝶账无忧录入凭证时，建议用：
```
银行存款——XX银行（基本户/一般户）
```
具体看你公司网银入账的账户是哪一家银行的哪个账号。

---

### 需要你确认的关键信息

要帮你写出**精确的分录**，还需要知道：

1. **该股权在你们账上属于哪类资产？**
   - 长期股权投资（子公司→成本法 / 联营/合营→权益法）
   - 交易性金融资产
   - 其他权益工具投资

2. **原始投资成本是多少？**（买C公司股权时花了多少钱）

3. **之前有无计提过减值或确认过损益调整/其他综合收益？**

4. **这125万的转让价是否等于、高于还是低于账面价值？**
