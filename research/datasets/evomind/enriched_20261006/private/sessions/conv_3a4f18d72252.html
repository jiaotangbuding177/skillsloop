**架构概要：** Humanize PPT 是一个**演讲编排系统**（Outline Director），不是模板渲染器。它解决的是「模板能把一页铺得好看，但你站上去讲不出一条线」的问题。核心流程分三步：

1. **O（大纲）** — 输入原始材料 → AST（观众状态转移）大纲 + 每页媒体决策
2. **P（渲染）** — 交由下游 skill 原生渲染（中文 → `guizang-ppt-skill`，英文 → `frontend-slides` / `beautiful-html-templates`）
3. **Q（质检）** — 对渲染结果做「演讲体检」，最多 3 轮，揪出只能看不能讲的页

⚠️ 该 skill 依赖多个下游渲染技能，建议一并安装获得完整体验：

| Skill | 用途 | 来源 |
|-------|------|------|
| `guizang-ppt-skill` | 中文 deck 原生渲染 | [github.com/op7418/guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill) |
| `frontend-slides` | 英文 deck 原生渲染 | [github.com/zarazhangrui/frontend-slides](https://github.com/zarazhangrui/frontend-slides) |
| `beautiful-html-templates` | 英文 deck 多模板渲染 | [github.com/zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates) |
| `baoyu-image-gen` | 配图生成（本地 Codex CLI，无需 API key） | [github.com/JimLiu/baoyu-skills](https://github.com/JimLiu/baoyu-skills) |
| `remotion-video-production` | 逐页说明视频生产 | Remotion 系 |
