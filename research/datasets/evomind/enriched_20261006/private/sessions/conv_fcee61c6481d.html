# 前台运行（先测试用这个）

openclaw nodes pending    # 查看待处理请求

## 核心原因：先搞清楚你红冲的是哪个月的票

**红冲分两种情况，处理逻辑完全不同：**

### 1️⃣ 红冲「以前月份」的蓝字发票 → 额度不会释放（最常见！）

全电发票的额度是**按月分配的"月初总额度"**：

- 被红冲的蓝字发票，占用的**是它开票那个月的额度**（那个月已经结束了）
- 你**当月**开具红字发票，红字发票本身会**先占用当月额度**
- 结果：蓝字占的额度回不到当月，红字还占了当月额度 → **当月可用额度不增反减**

**这就是你遇到的"红冲不释放额度"的最主要原因**——不是系统bug，是规则就是这样。

### 2️⃣ 红冲「当月」的蓝字发票 → 应该释放，但可能有延迟

当月开的票当月冲，系统会释放对应额度，但要注意：

- **系统有刷新延迟**：通常几分钟到几小时，可以等等再刷新页面
- **红字发票状态没走完**：如果红字发票处于"待确认"（比如购买方未确认），额度不会释放，要等对方确认、红字发票开具成功后才恢复

| 原因 | 表现 |
|---|---|
| **风险管控** | 企业被预警/列入风险名单，额度被人工调减或冻结，红冲也不恢复 |
| **红字发票未开具成功** | 只是发起了红字申请，还没真正开出红字发票 |

## ✅ 你的说法对照

| 情形 | 分录 | 你的说法 |
|---|---|---|
| 借给别人 | 借：其他应收款 贷：银行存款 | ✅ 对 |
| 别人借给我 | 借：银行存款 贷：其他应付款 | ✅ 对 |
| 我还给别人 | 借：**其他应付款**（减少）贷：银行存款 | ⚠️ 半对 |
| 别人还给我 | 借：银行存款 贷：**其他应收款**（减少） | ⚠️ 半对 |

**关键点**：还款不是"挂"科目，而是**冲减**。你的表述容易让人误以为还款时还往其他应付款/其他应收款里加数。

- 我还钱 → 其他应付款在**借方**（负债减少）
- 别人还我 → 其他应收款在**贷方**（资产减少）

## 📌 实操提醒

1. **设辅助核算**：其他应收款/其他应付款务必按对方单位或个人设二级科目，否则对账会疯
2. **长期挂账风险**：
   - 借给**股东/员工**的钱长期不还 → 税务可能视同**分红/工资**，补缴个税
   - 企业间**无息借款** → 税务可能核定利息收入，要交增值税
3. **借款合同**：大额借款建议留合同/借据，做账依据充分

一句话：**借出挂应收、借入挂应付；收回冲应收、归还冲应付**。这样记就不会错。
