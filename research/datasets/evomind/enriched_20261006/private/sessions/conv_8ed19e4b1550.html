# 两套境外投资运营架构方案法律分析（精简版）

**定性前提**：客户资金通过开曼/BVI主体持有，我方（无香港牌照主体）参与实际投资运作。两方案核心差异在于：主体性质（非基金公司 vs 基金）、我方角色（隐名管理人 vs GP）、费用安排（变相平衡 vs 合同明示）。

## 一、方案一：非基金公司 + 我方代为运营

**1. 核心风险：无牌经营资产管理（第9类受规管活动）**

- 香港《证券及期货条例》（SFO）下，"资产管理"（第9类）指为另一人管理证券/期货合约投资组合，以全权（discretionary）管理为特征。客户全资公司的资金权属仍属客户一方，我方员工实际行使投资决策权，即落入"为他人管理资产"范畴。
- 无论书面文件如何表述（"股东委派""代理运营""以自有资金"），SFC按**实质重于形式**原则审查。该主体虽非基金公司，但资金并非我方自有、我方亦非股东，"自有资金"抗辩难以成立。
- 法律后果：违反SFO第114条属刑事罪行，循公诉程序最高可处**罚款500万港元及监禁7年**；并影响未来申领牌照。一旦与客户发生纠纷（投诉、亏损争议），该风险即被触发。

**2. 费用"曲线平衡"的风险**

管理费及超额收益若通过咨询费、服务费等变相收取，易被认定为**规避牌照监管的变相资产管理报酬**，构成加重情节，并引发税务（利得税）与反洗钱审查。凡与业绩挂钩的报酬安排均属高度敏感。

**3. 其他要点**

- 若该主体引入多名投资人，可能被认定为集体投资计划（CIS），触发开曼（共同基金法/2020年私募基金法）或BVI（SIBA）注册义务；单投资人架构可降低该风险，但不改变香港牌照风险。
- 优势：成本低（数千美元）、搭建快、无渠道费，适合短期资金运营；劣势：高度依赖客户信任，合规敞口大。

## 二、方案二：离岸基金 + GP + 持牌机构运营

**1. 合规优势**

- 基金架构合法：开曼/BVI基金注册（含行政管理人、审计、AML等义务），管理费与业绩报酬作为基金合同项下GP的正常经济安排，透明合规，无需变相安排。
- 由持牌机构负责二级市场运营，符合香港监管框架。

**2. 残余风险："我方指定人员在持牌机构中操作"**

此安排须落实为：我方人员以该持牌机构**持牌代表**身份执业（受其监督、以机构名义行事）。否则，若仅由持牌机构执行指令、实际决策权仍在无牌人员手中，则：（1）我方仍可能被认定无牌经营第9类活动；（2）持牌机构亦面临协助无牌活动的合规责任。另一合规路径：我方（或关联主体）自行取得第9类牌照担任基金投资管理人，持牌机构仅作执行经纪。

**3. 成本与税务**

设立约3万美元以上、年维护数千美元、另付渠道费；但收入路径清晰，管理费/业绩报酬可正常入账，合资格附带权益可享香港0%利得税优惠。

## 三、结论与建议

1. **方案一**属"低成本、高敞口"：仅建议限定于单一客户、短期、纯执行性委托场景，并以书面授权明确我方无全权决策权、不收取业绩挂钩报酬；若退而以投资顾问（第4类）形式参与，同样需持牌且不得实质行使决策权。即便如此，无牌风险无法根除。
2. **方案二**为更稳妥的合规路径，但须优先解决"指定人员"的持牌代表身份问题，否则合规优势部分落空。
3. 无论何方案：应完成客户尽职调查与资金来源核验、留存书面文件；费用安排避免任何变相业绩报酬痕迹。
4. 本分析为一般性法律分析，不构成正式法律意见；架构落地前建议取得香港及开曼/BVI执业律师的正式意见。

理解你的逻辑，但这个论点在法律上站不住，需要直接指出问题所在——**"全权授权"恰恰是触发牌照监管的核心特征，而不是豁免理由**。三点辨析：

**1. 关于"客户授权 = 客户自己投资"**
第9类"资产管理"的定义就是"为另一人管理证券/期货合约投资组合"，而全权（discretionary）管理正是其典型形态。客户出具全权授权书，只会坐实"受规管活动"的定性——如果全权授权即可豁免，第9类牌照制度将形同虚设。授权关系（agency）不改变活动性质：受托管理他人资产，无论有无授权、授权范围多大，管理行为本身仍属"为他人管理资产"。

**2. 关于"客户自己的资金"**
资金存放于客户全资持有的开曼/BVI公司名下，公司是独立法人，资产权属上并非我方自有。"自有资金"抗辩只有在管理人本身是资金所有者时才成立。唯一与你们论点相近的监管口径，是SFC关于**单一家族办公室（SFO）**的指引：管理单一家庭的资产（含通过家庭全资持有的投资载体持有的资产）一般不视为经营第9类业务，理由是"资产属于家庭自身"且"不对外招揽"。但该口径有严格前提：单一家庭、资产实质归家庭所有、不对外提供管理服务、不收取第三方报酬。你们的场景是**商业机构为外部客户提供资产管理**，且未来还要"通过其他途径利益平衡"，与该口径不符。

**3. 关于"不收取管理费"**
SFO第114条禁止的是"经营业务"（carrying on a business），收费是认定"经营业务"的重要指标，但**不是必要条件**——持续、有组织地为他人管理资产，即便无偿，也可能构成经营业务。更关键的是：你们方案一明确计划通过其他途径收取对价（利益平衡），这反而坐实了"为报酬而经营"的定性，且可能被认定为变相收费、规避牌照。

**结论**：方案一的无牌经营风险依然成立，授权书和无收费安排均不能消除。若坚持该路径，缓解措施只能是：单一客户、短期、书面明确为执行性（非全权）委托、任何形式报酬均与业绩脱钩。即便如此，残余风险仍在——尤其"全权管理+变相收费"的组合，一旦发生纠纷被SFC调查，定性对你们不利。

# 两套投资运营架构方案法律风险评估（正式文本）

**定义**：本评估中，"管理方"指受托实际运营之主体（我方）；"客户"指资金出资方；"目标公司"指于开曼群岛或英属维尔京群岛（BVI）设立之非基金投资主体。

## 一、方案一：非基金公司架构之法律风险

**（一）无牌经营受规管活动之风险（核心风险）**

1. 依香港《证券及期货条例》（第571章）第114条，任何人未获发牌或注册而经营受规管业务，即属违法。就资产管理而言，第9类受规管活动指为另一人管理证券或期货合约投资组合，并以全权（discretionary）管理为特征。
2. 方案一中，客户资金经由其全资持有之目标公司投入，管理方员工实际行使投资决策权，构成"为他人管理资产"之行为。纵以"股东委派""代理运营"或"自有资金"等名义为之，监管机构依**实质重于形式**原则审查，前述形式安排不改变行为定性。
3. 法律后果：违反第114条者，循公诉程序定罪可处**罚款5,000,000港元及监禁7年**，循简易程序定罪可处罚款及监禁6个月；并可能导致管理方丧失申领牌照之适格性。该风险于客户争议（投诉、诉讼）场景下最易被触发。

**（二）变相收取管理报酬之风险**

管理费及超额收益若通过咨询费、服务费或其他名义变相收取，可能被认定为规避牌照监管之变相资产管理报酬，构成无牌经营之加重情节；并可能引发税务（利得税）及反洗钱合规审查，形成叠加法律风险。

**（三）被认定为集体投资计划之风险**

若目标公司引入多名投资人，或虽名义单一但实质汇集多人资金，可能被认定为集体投资计划（CIS），触发开曼群岛《共同基金法》/《2020年私募基金法》或BVI《证券与投资业务法》项下之注册义务；未依法注册而经营，构成当地法下之违法行为。

**（四）其他风险**

1. 委托关系定性不明之风险：管理方与客户间之权利义务缺乏持牌监管框架下行为准则之约束，发生纠纷时责任划分与举证难度较大，且可能因合同目的违法（规避监管）引发合同效力争议。
2. 反洗钱与资金来源风险：境外出资若未能完整核验资金来源并留存记录，管理方可能违反两地反洗钱法律义务。
3. 人员个人责任风险：若由员工以个人名义实际操作，相关个人亦可能被追究无牌经营之法律责任。

## 二、方案二：离岸基金架构之法律风险

**（一）基金设立与持续合规风险**

1. 于开曼群岛或BVI设立基金，须依当地法律完成注册（开曼《共同基金法》/《2020年私募基金法》；BVI《证券与投资业务法》），并持续满足委任行政管理人、年度审计、反洗钱制度及经济实质等要求；未合规者将面临当地监管处罚乃至撤销注册。
2. 管理方担任普通合伙人（GP），以管理费及业绩报酬（附带权益）作为对价，属基金合同项下之正常经济安排，原则上合法合规，无需变相安排。

**（二）香港持牌合规风险（残余风险）**

1. 基金于香港开立银行及证券账户并交由持牌机构运营，符合监管框架；但管理方"指定人员在持牌机构中操作"之安排，若该等人员未登记为该持牌机构之持牌代表，而仅由持牌机构执行指令，则实质投资决策权仍由无牌人员行使，管理方仍可能被认定无牌经营第9类受规管活动；持牌机构亦可能因协助无牌活动而承担监管责任。
2. 合规路径：管理方（或关联主体）自行取得第9类牌照担任基金投资管理人，或确保运营人员以该持牌机构持牌代表身份执业，二者必居其一。

**（三）成本与税务风险**

设立及维护成本较高（设立约30,000美元以上、年维护数千美元、持牌机构另收渠道费用）；收入端可通过管理费及附带权益正常入账，合资格附带权益可适用香港利得税0%税率优惠。但若基金文件与实质运营不符（如决策权实际旁落），仍存在被穿透定性之税务与监管风险。

## 三、总体结论

方案一法律风险敞口显著高于方案二：方案一以形式安排规避牌照监管，实质定性风险高且难以消除；方案二架构本身合规，但须落实持牌代表身份等运营细节，方可实现预期合规效果。

## 附：两套方案之操作流程（法律程序视角）

**方案一：非基金公司架构之操作流程**

1. **设立目标公司**：客户于开曼群岛或BVI设立投资主体（目标公司），客户以自身名义持有目标公司全部股权；目标公司之章程及注册文件载明其经营范围为一般投资控股，不涉及基金管理业务。
2. **境外出资**：客户以境外合法来源资金，通过认缴股本或股东贷款（shareholder loan）之方式注入目标公司，并留存资金来源证明文件以备反洗钱审查。
3. **开立账户**：目标公司于香港持牌银行及持牌券商处，以公司名义开立银行账户及证券账户，完成开户环节之客户尽职调查（KYC）及资金来源核验。
4. **出具授权文件**：客户（作为股东）向管理方出具书面授权/委托文件，载明由管理方代为执行目标公司自有资金之投资操作；授权文件应明确权限范围、报告义务及责任划分。
5. **实际运营**：管理方员工依授权，以目标公司账户内自有资金于二级市场执行投资决策与交易指令；全部交易以目标公司名义及其账户进行。
6. **收益归属**：投资所得收益留存于目标公司，归客户（股东）所有；管理方不收取管理费或业绩报酬，双方之其他利益安排另行以其他法律关系处理。

**方案二：离岸基金架构之操作流程**

1. **设立基金**：管理方与客户共同于开曼群岛或BVI设立基金实体（通常为豁免有限合伙），管理方担任普通合伙人（GP），客户担任有限合伙人（LP）。
2. **签署基金文件**：各方签署有限合伙协议（LPA）、私募备忘录（PPM）及认购文件，明确基金投资策略、管理费、业绩报酬（附带权益）、分配与赎回机制等条款。
3. **基金注册与合规**：基金依当地法律完成注册（开曼《共同基金法》/《2020年私募基金法》；BVI《证券与投资业务法》），并委任行政管理人、审计师，建立反洗钱制度及经济实质安排。
4. **开立账户**：基金于香港持牌银行及持牌券商处开立银行账户及证券账户，完成KYC及资金来源审查。
5. **委任持牌机构**：基金（或其普通合伙人）与香港持牌机构签署投资管理/经纪服务协议，委托其于二级市场运营基金资产。
6. **人员安排**：管理方指定人员以该持牌机构持牌代表之身份执业，或由管理方（或关联主体）自行取得第9类牌照担任基金投资管理人，确保投资决策权由持牌主体行使。
7. **费用计提与分配**：管理费按基金资产净值定期计提，业绩报酬（附带权益）依基金文件约定于分配时点计提与支付；合资格附带权益可适用香港利得税0%税率优惠。
8. **持续合规**：基金依当地法律履行年度审计、备案、申报（含FATCA/CRS）等持续义务。

**程序性差异小结**：方案一程序简便、环节少、落地周期短，但各环节均缺乏持牌监管框架之约束，形式安排与实质运营之偏离构成其固有风险；方案二程序复杂、涉及多方法律文件及两地监管注册，合规成本高，但各环节均有明确法律依据，风险可控性显著优于方案一。

# 两套方案综合对比（流程·成本·时间·法律风险）

## 一、方案一：非基金公司架构

**（一）大致流程**
1. 于开曼群岛/BVI设立投资主体（目标公司），客户持股100%；
2. 客户以境外合法资金完成出资（认缴股本或股东贷款）；
3. 目标公司于香港开立银行账户及证券账户；

5. 管理方员工以目标公司自有资金于二级市场执行投资操作；
6. 收益留存目标公司，归客户所有；管理方不收取管理费及业绩报酬。

**（二）关键节点与差异**
- 关键节点：公司设立完成 → 香港银行开户（不确定性最高环节，受银行KYC审查影响）→ 授权文件签署 → 账户资金到位并开始交易。
- 与方案二之差异：无基金注册、无持牌机构参与、无明示费用条款；全部环节围绕"形式自营＋实质受托"展开。

**（三）大致成本（估算）**
- 设立：约2,000–5,000美元（含公司注册、注册代理人、政府费用、基础文件起草）；
- 年维护：约1,000–2,000美元/年（注册代理人及年审费用）；
- 无持牌机构渠道费；如另行委托律师起草授权文件，律师费另计；
- 合计首年约3,000–8,000美元。

**（四）时间（估算）**
公司设立1–2周；香港银行及证券开户2–6周（银行审查可能延长）；整体自启动至可运营约**1–2个月**。

**（五）法律风险**
1. **无牌经营第9类受规管活动（核心风险）**：实质重于形式，全权管理＋授权文件不能豁免；违反SFO第114条可处最高罚款500万港元及监禁7年；
2. **变相收取管理报酬之风险**：通过其他途径利益平衡，可能被认定为变相收费、规避牌照；
3. **集体投资计划（CIS）认定风险**：多投资人汇集资金将触发开曼/BVI基金注册义务；
4. **合同效力与纠纷风险**：委托关系定性不明，纠纷时责任划分与举证困难；
5. **反洗钱及资金来源风险**：资金来源核验不足将违反两地反洗钱义务。

## 二、方案二：离岸基金架构

**（一）大致流程**
1. 管理方与客户于开曼/BVI共同设立基金（豁免有限合伙），管理方任GP、客户任LP；

3. 基金完成当地注册（开曼CIMA／BVI FSC），委任行政管理人、审计师，建立AML制度；
4. 基金于香港开立银行及证券账户；
5. 委任香港持牌机构负责二级市场运营；
6. 管理方指定人员以持牌代表身份执业（或管理方取得第9类牌照）；
7. 按基金文件计提管理费、分配业绩报酬；履行年度审计及持续申报义务。

**（二）关键节点与差异**
- 关键节点：基金设立及文件签署 → 基金注册完成 → 行政管理人/审计委任 → 香港开户 → 持牌机构签约及人员持牌安排落实 → 首次募集与投资运作。
- 与方案一之差异：多出基金注册、行政管理人委任、持牌机构合作及人员持牌登记等环节；费用合同化、透明化。

**（三）大致成本（估算）**
- 设立：约**30,000美元以上**（含基金文件起草、法律意见、注册费、行政管理人首年费用）；

4. **成本风险**：设立及维护成本高，渠道费侵蚀收益。
