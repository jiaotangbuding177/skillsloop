请帮我设计一个关于初中物理"力学"的互动学习网页。

【目标受众】初中二年级学生（14-15岁），物理初学者。

【核心主题】力的概念、重力、弹力、摩擦力。

【视觉风格】

1. 整体风格：简洁、明亮、卡通化，不要用默认模板风格。

2. 主色调：科技蓝（#2196F3）搭配活力橙（#FF9800）作为强调色。

3. 字体：标题用圆润的无衬线字体，正文用清晰易读的字体。

4. 布局：顶部导航 + 卡片式内容分区，每个知识点一张卡片。

【页面结构】

1. 顶部导航栏：包含"力的概念""重力""弹力""摩擦力""小测验"五个锚点链接。

2. 英雄区域：一个大标题"探索力的世界"，配一句副标题"初中物理 · 力学入门"，背景用力的示意图或物理公式装饰。

3. 知识点卡片区：四张卡片分别介绍力的概念、重力、弹力、摩擦力，每张卡片包含：知识点名称、一句话定义、一个生活中的例子、一张简单的示意图或图标。

4. 小测验区：设计3道选择题，每题4个选项，点击选项后能立即显示对错反馈。

5. 页脚：显示"本页面由AI辅助生成，仅供教学参考"。

【交互要求】

1. 点击导航链接能平滑滚动到对应区域。

2. 小测验的选项点击后有视觉反馈（正确变绿、错误变红）。

3. 卡片在鼠标悬停时有轻微的阴影和上浮效果。

【技术要求】

1. 使用纯 HTML + CSS + JavaScript，不需要框架。

2. 所有代码放在一个 HTML 文件中。

3. 页面自适应，在手机和电脑上都能正常显示。
