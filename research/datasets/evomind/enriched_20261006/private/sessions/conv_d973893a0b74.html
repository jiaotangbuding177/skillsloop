## 📋 Typeless 竞品调研速览

### Typeless 是干嘛的？
AI 语音输入法。不是你妈用的那种"语音转文字"，而是**说人话 → AI 自动去口头禅、去重复、自动排版、自适应语调、甚至边说边译**，输出成品文字。创始人 Huang Song（斯坦福校友），2025年11月上线，全平台（Mac/Win/iOS/Android），Product Hunt 双端 #1。

### 🏆 核心竞品排排站

| 产品 | 对 Typeless 的威胁 | 一句话总结 |
|------|:---:|-----------|
| **Wispr Flow** | 🔴 高 | 最大对手，$81M融资，$700亿估值，先发优势强，但可靠性翻车多 |
| **Aqua Voice** | 🟡 中高 | 速度最快（450ms），专业词汇识别无敌，但无Android版、仅49种语言 |
| **Superwhisper** | 🟢 中 | 隐私之王，全本地离线，$249终身，但无AI润色功能 |
| **Voibe** | 🟢 中低 | 纯Mac，$149终身，隐私向 |
| **VoiceInk** | 🟢 低 | 开源，$25一次买断，功能极简 |
| **系统自带** | 🟢 低 | 免费但功能天差地别 |

### Typeless 的杀手锏（竞品没有的）

1. **翻译功能** — Real-time 边说边译，主要竞品全无
2. **App自适应语调** — 在Outlook自动正式、在微信自动随意，行业独有
3. **8,000词/周的免费额度** — 是Wispr的4倍，碾压级慷慨

### Typeless 的软肋

1. ❌ 没有 Snippets（快捷短语）— 高频需求，竞品都支持
2. ❌ 月付$30太贵 — Wispr才$15，Aqua才$8
3. ❌ 无离线模式
4. ❌ 延迟数据不透明
5. ❌ 2025年11月刚上线，品牌认知度远低于Wispr

### 💡 核心判断

Typeless 产品力不弱，甚至有特色功能是竞品没有的（翻译 + App语调自适应）。但窗口期在收窄，**尽快补Snippets、优化月付定价、考虑本地混合方案** 是下半场的关键。

## 🎯 科大讯飞确实能搞定，而且可能是最佳选择

讯飞在这块有几个王炸级别的产品：

### ✅ 讯飞语音听写（流式版）WebAPI → 对标 Typeless 的 ASR 层

这是最靠谱的选择。**中文语音识别准确率 98%+**，支持 25 种方言，标点预测、数字格式化、动态修正是标配。而且接入极其简单，一个 WebSocket 搞定。

**定价很良心：** 免费 5 小时体验，之后 ¥9.9/小时起步，用到套餐四只要 ¥3.5/小时。按一个重度用户每天用 1 小时算，**月均成本不到 ¥10**。

### ✅ 星火大模型 → 对标 Typeless 的 AI 润色层

Typeless 的"去口头禅/改写/翻译"功能，用星火 API 做润色层完全可以实现。中文口头禅（"然后"、"就是说"、"那个"）处理是星火的强项，比 GPT 更对味。

### ✅ 星火语音大模型（最新版）

2025-2026 年发布的升级版，支持 37 语种 + 37 种方言免切换识别，甚至三人同时说话都能分离转写。不过这版 API 是否已全面开放需要跟讯飞确认。

---

## 🏆 我推荐的落地路径

**短期（1-4周）：讯飞 ASR + EvoMind 自有 LLM**
- 注册讯飞开放平台 + 开通 API = 1 天搞定
- 润色走你现有的 LLM，不需要另外花钱
- 5 小时免费试用够做 POC 了

**中期（1-3个月）：混合方案（在线讯飞 + 离线 Whisper）**
- 在线用讯飞（中文最佳质量）
- 离线切 Whisper（保底可用）
- 兼顾体验和可用性
