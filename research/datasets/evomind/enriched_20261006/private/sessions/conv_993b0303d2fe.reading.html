---

## Gitee Agent Skills 安装指南

Gitee Agent Skills 底层基于 **Gitee MCP Server**（由 OSChina 官方维护），通过 OpenClaw 的 MCP 集成能力对接 Gitee 平台。

### 总览：两种安装方式

| 方式 | 难度 | 说明 |
|------|------|------|
| **远程连接（推荐）** ⭐ | 简单 | 直接连 Gitee 官方托管的 MCP 服务，无需本地安装服务端 |
| **本地安装 mcp-gitee** | 中等 | 通过 npx / go install 在本地运行 MCP Server |

---

### 前置条件

1. **Gitee 个人访问令牌（access token）**
   - 访问：https://gitee.com/profile/personal_access_tokens
   - 生成一个 token，保存好

2. **OpenClaw 已安装并运行**

---

### 方式一：远程 MCP Server（最简单）

在 OpenClaw 的配置文件 `~/.openclaw/openclaw.json` 中添加：

```json5
{
  "mcpServers": {
    "gitee": {
      "url": "https://api.gitee.com/mcp",
      "headers": {
        "Authorization": "Bearer [隐藏] Access Token>"
      }
    }
  }
}
```

配置完成后，重启 OpenClaw Gateway，你的 Agent 即可使用 Gitee 的所有能力。

**可用的工具包括：**
- 仓库管理：列出仓库、获取文件内容、创建仓库、Fork、搜索开源仓库
- Pull Request：创建/合并/更新 PR、获取 Diff、审阅
- Issue：创建/更新/列出 Issue、评论
- 通知：列出用户通知
- 用户信息

---

### 方式二：本地安装 mcp-gitee Server（功能更完整）

#### 步骤 1：安装 Gitee MCP Server

```bash
# 方法 A：使用 npx（推荐，无需安装）
npx -y @gitee/mcp-gitee

# 方法 B：使用 Go 安装
go install gitee.com/oschina/mcp-gitee@latest

# 方法 C：从源码构建
git clone https://gitee.com/oschina/mcp-gitee.git
cd mcp-gitee
make build
# 将 ./bin/mcp-gitee 加入 PATH
```

#### 步骤 2：在 OpenClaw 中配置

在 `~/.openclaw/openclaw.json` 中添加：

```json5
{
  "mcpServers": {
    "gitee": {
      "command": "npx",
      "args": ["-y", "@gitee/mcp-gitee@latest"],
      "env": {
        "GITEE_ACCESS_TOKEN": "<你的Gitee Access Token>"
      }
    }
  }
}
```

或者使用已安装的二进制文件：

```json5
{
  "mcpServers": {
    "gitee": {
      "command": "mcp-gitee",
      "args": ["--token", "<你的Gitee Access Token>"]
    }
  }
}
```

#### 步骤 3：重启 Gateway

```bash
openclaw gateway restart
```

---

### 方式三：使用 mcporter 管理（OpenClaw 官方推荐方式）

OpenClaw 官方推荐用 **mcporter** 统一管理 MCP Server。

1. 先在 OpenClaw Skills 界面中安装 mcporter skill
2. 通过 mcporter 的配置界面添加 Gitee MCP Server
3. 在 mcporter 的配置中填入 Gitee Access Token

---

### 验证安装

在你的 OpenClaw Agent 中提问：

> "列出我在 Gitee 上的仓库"

如果 Agent 能返回仓库列表，说明安装成功。

---

### 企业版说明

如果你使用的是 **Gitee 企业版**，需要使用 `mcp-gitee-ent`（企业版 MCP Server）：

```json5
{
  "mcpServers": {
    "gitee-ent": {
      "command": "npx",
      "args": ["-y", "@gitee/mcp-gitee-ent@latest"],
      "env": {
        "GITEE_ENT_MCP_ACCESS_TOKEN": "<企业版Token>",
        "GITEE_ENT_API_BASE": "https://api.gitee.com/enterprises"
      }
    }
  }
}
```

企业版额外支持：项目管理、Scrum 迭代、团队管理、工作项类型等。
