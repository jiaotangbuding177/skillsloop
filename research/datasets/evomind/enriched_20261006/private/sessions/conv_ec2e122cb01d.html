老板，我先看一下你截图里的显示设置，再告诉你具体怎么改。老板，这通常是 Windows 记住了“仅第二屏幕”模式。按你的需求这样改：

### 如果只想用笔记本屏幕
1. 按 **`Win + P`**
2. 选择 **“仅电脑屏幕”**

### 如果想两个屏幕都用，但笔记本作为主屏
1. 右键桌面 → **显示设置**
2. 点击上方的 **屏幕 1**
3. 在“多显示器”里选择 **“扩展这些显示器”**
4. 勾选 **“设为主显示器”**
5. 点 **保留更改**

注意：**屏幕编号 1、2 不代表谁是主屏**，编号一般无法手动修改；只要选中笔记本对应的屏幕，再勾选“设为主显示器”即可。

如果每次开机仍自动跳到屏幕2，先拔掉扩展坞或 HDMI 线，按 `Win + P` 选“仅电脑屏幕”，重启一次，再重新连接外屏。

明白了，老板。既然“仅电脑屏幕”重启后会失效，就不是普通设置问题，通常是**显卡驱动、扩展坞/外接设备，或 Windows 快速启动保存了错误状态**。按下面顺序处理：

### 1. 先关闭“快速启动”（最常见）
1. 打开 **控制面板**
2. 进入 **硬件和声音 → 电源选项**
3. 点击左侧 **选择电源按钮的功能**
4. 点击上方 **更改当前不可用的设置**
5. 取消勾选 **启用快速启动**
6. 保存后，选择一次 **关机**，再重新开机测试
> 不要只点“重启”，要完整关机再开机。

### 2. 删除系统记住的“幽灵显示器”
1. 右键开始菜单 → **设备管理器**
2. 点击顶部 **查看 → 显示隐藏的设备**
3. 展开 **监视器**
4. 将灰色的、重复的 **通用即插即用监视器**卸载
5. **不要卸载当前正在使用的笔记本屏幕**
6. 重启电脑，再按 `Win + P` 选择 **仅电脑屏幕**

### 3. 更新或重装显卡驱动
在设备管理器中展开 **显示适配器**，看看是 Intel、AMD 还是 NVIDIA：

- 优先去**笔记本品牌官网**下载对应机型的显卡驱动；
- 不建议只依赖设备管理器里的“自动更新”；
- 如果问题是最近更新后才出现，可进入显卡属性 → **驱动程序 → 回退驱动程序**。

### 4. 排查扩展坞或虚拟显示软件
如果连接过扩展坞、Type-C 显示器或无线投屏，先全部拔掉再开机。也检查是否装过：

- DisplayLink
- spacedesk
- Duet Display
- 向日葵虚拟屏
- DeskIn、ToDesk 等远控软件的虚拟显示驱动

这些程序可能在开机时重新创建“屏幕2”。不需要的话，卸载其**虚拟显示驱动**。

**我判断最可能的是快速启动或虚拟显示驱动。**建议先做第1步；如果开机时即使没有接任何外屏，系统仍然显示“屏幕2”，就直接做第2和第4步。
