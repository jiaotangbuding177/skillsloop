这个技能我已经加载并应用过了（刚才初始化了 wiki）。简单说下它的功能：

**karpathy-wiki（LLM 本地知识库）** 是一个完整的知识管理技能，主要做这几件事：

**两种模式：**
- **模式 A**：有 `个人知识库/` 目录 — 从那里扫描源文件
- **模式 B**：没有 `个人知识库/` — 扫描整个工作区（我们用的这个）

**核心操作：**

| 操作 | 说明 |
|------|------|
| **初始化** | 建 `wiki/` 目录 + `index.md` + `log.md`，扫描源文件 |
| **收录** | 提取 PDF、Word、Excel、图片等文件内容，编译成 wiki 文章 |
| **查询** | 先查本地知识库，找不到再联网搜索 |
| **检查** | 检查 wiki 文件质量、索引完整性，自动修复 |
| **归档** | 过时内容归档但不删除 |

**设计理念：**
- 源文件只读不写，知识库只写 `wiki/` 目录
- 每次操作都更新索引和日志
- 使用 `doc_extractor.py` 脚本提取各类文档内容（PDF、Office、图片 OCR 等）
