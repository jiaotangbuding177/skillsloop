看图片应该是 ElevenLabs 的 ElevenAgents 后台页面。我按常见界面给你操作路径，分两种情况：

**情况 A：你看到的是 Agents 列表页（有 "Create agent" 或 "+ New Agent" 按钮）**

1. 点击 **Create agent**（新建 Agent）
2. 填写基本信息：
   - **Agent name**：随便起个名字（如 test-agent）
   - **System prompt**：写 agent 的角色设定/指令
   - **Language**：选中文的话记得在设置里允许多语言，否则它默认只说英文
3. 配置对话能力：
   - **LLM**：默认即可（或选你想要的模型）
   - **Conversation voice**：选一个语音（或用 Instant Voice Cloning 克隆声音）
   - 其他（温度、超时等）先用默认值
4. 点击右下角 **Create Agent** 完成创建

**情况 B：你想找已创建 Agent 的 Agent ID**

创建成功后会自动跳转到该 Agent 的详情页，此时：

- **方法 1（最快）**：看浏览器地址栏 URL——
  `https://elevenlabs.io/agents/xxxxxxxxxxxxxxxx`
  最后那串字符就是 **Agent ID**（通常 32 位字母数字）
- **方法 2**：在 Agent 详情页点右上角 **Settings**，页面上会直接显示 Agent ID，旁边有复制按钮
- **方法 3**：回到 Agents 列表页，点击任意 agent 卡片，URL 同上取 ID

**拿 ID 之后要干嘛？**（看你后续用途）
- 如果是接 **Twilio/Webhook/API**：在 Settings → API / Integrations 里拿，同时会用到你的 **API Key**（在头像 → API Keys 里创建）
- 如果是做 **Web 对话测试**：详情页右上角 **Share** → 生成链接或嵌入组件，直接跟 agent 语音对话测试效果

看到了，你现在停在 **Create API Key（创建 API Key）弹窗**。按你的用途（接 ElevenAgents 语音 Agent），这样选：

**1. Name（名称）**
随便填，比如 `eleven-agents` 或 `my-agent`，方便以后认出来

**2. Expire After（过期时间）**
- 选 **Never**（永不过期）就行，个人项目不用折腾轮换

**3. Restrict Key（限制用途）**
- 如果你是给自己 Agent 用：**保持关闭**（不用勾）
- 如果这个 key 要给客户/线上产品用：打开它，可以限定只能用某个 Agent

**4. Usage Limits（用量限制）**
- 保持 **Unlimited**（不限量）即可，扣费走你账户余额

**5. Endpoints（权限）— 这里最关键，按需开：**

| 端点 | 怎么选 | 原因 |
|---|---|---|
| **Text to Speech** | ✅ Access | Agent 回复你时要合成语音，必开 |
| **Speech to Speech** | ✅ Access | 语音 Agent 对话会走这个，建议开 |
| **Speech to Text** | ✅ Access | 把你的语音转文字给 LLM，必开 |
| Sound Effects / Audio Isolation / Music / Image&Video | ❌ No Access | 用不到就别开，减小泄露风险 |

**选完后：**
1. 点底部 **Create API Key** 蓝色按钮
2. 弹出窗口会显示一次完整 key（`sk_` 开头）——**立刻复制保存**，关掉就再也看不到了
3. 回到 ElevenAgents 的 Agent 设置里，把 key 填进对应位置即可

⚠️ 小提醒：如果只想让 Agent 能用、不想给太多权限，至少保证 TTS + STT 两个 Access，S2S 看你的对话模式是否需要。
