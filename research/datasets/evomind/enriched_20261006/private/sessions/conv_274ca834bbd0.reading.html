股权变更涉及的会计分录，根据变更类型不同处理方式也不同。我按常见的几种场景分别说明：

---

## 一、增资扩股

### 1. 新股东现金入资（有溢价）

> 例：新股东投入100万，其中50万计入注册资本，50万计入资本公积

```
借：银行存款                1,000,000
    贷：实收资本——新股东        500,000
        资本公积——资本溢价      500,000
```

### 2. 原股东同比例增资

```
借：银行存款                  XXX
    贷：实收资本——XX股东        XXX
```

---

## 二、股权转让（股东之间转让）

> 例：A股东将10%股权（原出资50万）以80万转让给B

**公司账务处理**（公司层面只变更股东名册）：

```
借：实收资本——A股东          500,000
    贷：实收资本——B股东        500,000
```

> ⚠️ **注意**：股权转让的差价（80万-50万=30万）是A股东的个人所得，**公司不做账**，由A股东自行缴纳个人所得税。

### 如果涉及公司回购

```
借：库存股                    XXX
    贷：银行存款                XXX
```
（后续注销时冲减实收资本和资本公积）

---

## 三、减资 / 退股

### 1. 按原出资额退股（平价退出）

> 例：股东退股，原出资100万，退回100万

```
借：实收资本——XX股东        1,000,000
    贷：银行存款              1,000,000
```

### 2. 溢价退股（高于原出资额）

> 例：股东原出资100万，退回250万（溢价150万）

```
借：实收资本——XX股东        1,000,000
    资本公积——资本溢价      1,500,000  （溢价部分先冲资本公积）
    贷：银行存款              2,500,000
```

> 资本公积不够冲时，依次冲减盈余公积、未分配利润。

### 3. 折价退股（低于原出资额）

> 例：股东原出资100万，退回80万（折价20万）

```
借：实收资本——XX股东        1,000,000
    贷：银行存款                800,000
        资本公积——资本溢价      200,000
```

---

## 四、有限公司变更为合伙企业 / 持股平台调整

结合你之前处理的**清霜PND-A轮减持**案例，涉及的是**合伙企业合伙人退伙/份额转让**，处理方式如下：

### 1. 合伙人退伙（合伙企业层面）

```
借：合伙人资本——XX合伙人       XXX
    贷：银行存款                 XXX
```

### 2. 份额转让

```
借：合伙人资本——转让方         XXX
    贷：合伙人资本——受让方       XXX
```

---

## 五、关键注意事项

| 要点 | 说明 |
|---|---|
| **计税基础** | 股权转让差价按"财产转让所得"缴20%个税 |
| **资本公积顺序** | 溢价退股时，先冲资本公积 → 盈余公积 → 未分配利润 |
| **减资程序** | 减资需登报公告45天，债权人异议期 |
| **工商变更** | 股权/注册资本变更后30日内做工商变更登记 |
| **印花税** | 股权转让书据按万分之五缴印花税 |

退回投资款的账务处理，核心看两点：**① 公司性质**（有限公司还是合伙企业）**② 是否溢价退出**。

---

## 一、有限公司退股（减资）

### 1. 平价退回（退回金额 = 原出资额）

> 例：股东原出资100万，退回100万

```
借：实收资本——XX股东        1,000,000
    贷：银行存款              1,000,000
```

### 2. 溢价退回（退回金额 > 原出资额）

> 例：股东原出资100万，退回250万（溢价150万）

```
借：实收资本——XX股东        1,000,000
    资本公积——资本溢价      1,500,000  ← 溢价部分
    贷：银行存款              2,500,000
```

⚠️ 如果资本公积不够冲，依次冲减：
1. 盈余公积
2. 未分配利润（借：利润分配——未分配利润）

```
借：实收资本——XX股东        1,000,000
    资本公积——资本溢价        500,000  （资本公积只有50万）
    盈余公积                  300,000
    利润分配——未分配利润      700,000
    贷：银行存款              2,500,000
```

### 3. 折价退回（退回金额 < 原出资额）

> 例：股东原出资100万，退回80万（折价20万）

```
借：实收资本——XX股东        1,000,000
    贷：银行存款                800,000
        资本公积——资本溢价      200,000  ← 折价部分计入公积
```

---

## 二、合伙企业退伙

### 1. 按出资额退回

```
借：合伙人资本——XX合伙人       XXX
    贷：银行存款                 XXX
```

### 2. 溢价退回（有减持收益）

参照你之前的**清霜PND-A轮减持**案例（转让方有个税，合伙企业层面做份额减少）：

```
借：合伙人资本——XX合伙人        XXX    （原出资成本）
    贷：银行存款                    XXX
```

溢价部分实际是合伙人的财产转让所得，**合伙企业本身不确认损益**，由合伙人按"经营所得"或"财产转让所得"缴个税。

---

## 三、实质大于形式：怎么看是不是"退回投资款"

有些情况表面是"退回投资款"，实质是：

| 表面形式 | 实质判断 | 会计处理 |
|---|---|---|
| 退回投资款 | 实为利润分配 | 借：利润分配——应付利润 / 贷：银行存款 |
| 退回投资款 | 实为股东借款收回 | 借：其他应付款——XX股东 / 贷：银行存款 |
| 退回投资款 | 实为关联方往来 | 借：其他应付款——XX公司 / 贷：银行存款 |

---

1. **退回的是有限公司还是合伙企业？**
2. **退回金额 = 原出资额，还是多了/少了？**
3. **是从公司账户直接打款给原股东？**

有了这些我直接给你写完整分录。
