## 获取 Token

1. **注册天眼查开放平台账号**
   - 前往 [https://openapi.tianyancha.com/](https://openapi.tianyancha.com/)
   - 注册并完成企业实名认证

2. **申请 API Key**
   - 在开放平台控制台创建应用，获取 `API Key`（即 Token）

---

## 配置方式

### 方式一：环境变量（推荐）

安装技能时已带了 `package.json`，可以添加环境变量配置。修改 `/workspace/skills/tianyancha-cn/package.json`：

```json
{
  "name": "tianyancha-cn",
  "version": "1.0.0",
  "description": "企业信息查询 - 天眼查/企查查/爱企查数据查询",
  "keywords": ["tianyancha", "qichacha", "china", "company"],
  "author": "money-maker-ai",
  "env": {
    "TIANYANCHA_API_KEY": "你的Token放这里"
  }
}
```

### 方式二：传参使用

查询时直接在 curl 中带入 Token（Skill 中已有模板）：

```bash
curl "https://open.api.tianyancha.com/services/open/search/2.0?keyword=上海胆大求索科技有限公司" \
  -H "Authorization: Bearer [隐藏]"
```
