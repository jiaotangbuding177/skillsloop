## 核心结论

搜狗 ssf 皮肤格式**不支持运行时代码**，所以不能靠皮肤包自身实现"打字→匹配关键词→换肤"的闭环。必须搞一个外部运行时代理来桥接。

我整理了 **6 条技术路线**，按推荐优先级：

| 优先级 | 路线 | 一句话 |
|--------|------|--------|
| 🥇 | **Web Demo** | 1-2天出活，单 HTML 文件模拟全流程，用来做传播和用户验证 |
| 🥈 | **Android 伴侣 App** | 无障碍服务监听输入 + 浮动层叠加动效，真正可用的产品 |
| 🥉 | **官方合作** | 给 `***@***` 发邮件，推动搜狗开放皮肤 API |
| 4 | **PC 端外挂** | Windows 键盘钩子 + 替换 ssf 文件，PC 版补充 |
| 5 | **独立输入法** | 自己造轮子，不推荐（获客成本太高） |
| 6 | **Xposed 魔改** | 需要 Root，仅 Geek 玩家场景 |

Web Demo 我建议用纯单文件 HTML（不依赖框架），500行以内搞定虚拟键盘 + AC 自动机关键词匹配 + CSS 氛围切换 + Lottie 动效。快速出活、快速传播。
