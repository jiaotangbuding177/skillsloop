老板，这是一组**跨境汇款收款信息**，一般填写你在国内银行开立的账户资料：

- **Company**：公司英文名称
- 如果是个人账户，通常写个人姓名，不写公司。
- 公司英文名最好与银行备案一致，不要自己随意翻译。

- **Name of account / Bank Account**：账户名称（户名）
- 对公账户：公司的完整开户名称
- 个人账户：开户人的拼音或银行登记的英文姓名
- 必须和银行系统里的信息完全一致。

- **ACC NO（Account Number）**：银行账号
- 国内银行卡通常填写银行卡号。
- 对公账户填写公司银行账户号码。
- **不是身份证号，也不是开户许可证编号。**

- **SWIFT Code / BIC**：银行的国际汇款识别代码
- 主要用于境外汇款到中国。
- 通常是 **8位或11位字母数字组合**，例如中国银行总行是 `BKCHCNBJ`。
- 不同银行、分行的 SWIFT Code 可能不同；有些支行没有独立代码，需要使用上级分行代码。

### 国内账户怎么查

最稳妥的方式是联系**开户行客服或开户网点**，直接问：

> 我要接收境外汇款，请提供账户英文户名、开户银行英文名称、开户行英文地址和正确的 SWIFT/BIC Code。

也可以：

1. 查看银行 App 中的“跨境汇款”“境外汇入”“收款信息”；
2. 打银行客服电话；
3. 对公账户联系开户行客户经理；
4. 搜索银行官网的 SWIFT Code，但最终最好让开户行确认。

境外付款方通常还可能需要：

```text
Beneficiary Name：收款人/公司英文户名
Beneficiary Account No.：收款账号
Beneficiary Bank Name：开户银行英文名称
Bank Address：开户行英文地址
SWIFT/BIC Code：银行国际代码
Branch Name：开户支行名称
```

注意：**国内联行号/CNAPS Code 不等于 SWIFT Code**。如果只是境内人民币转账，通常只需要户名、账号和开户行，不需要 SWIFT；只有境外汇款才会用到。对公账户如果没有银行确认的英文户名，别直接自己翻译，容易导致退汇。

我帮你查一下公开信息，但 SWIFT 码涉及跨境到账，最终还得以川沙支行或中国银行客服确认的口径为准。中国银行上海市川沙支行通常**没有单独对外使用的 SWIFT Code**，境外汇款一般使用中国银行上海市分行的代码：

**SWIFT / BIC：`BKCHCNBJ300`**

可按下面填写：

- **Bank Name**：BANK OF CHINA, SHANGHAI BRANCH
- **SWIFT Code**：BKCHCNBJ300
- **Beneficiary Bank Branch**：BANK OF CHINA, SHANGHAI CHUANSHA SUB-BRANCH
- **Branch Address**：NO. 4958 CHUANSHA ROAD, PUDONG NEW AREA, SHANGHAI, CHINA
- **Beneficiary Name**：你的银行登记英文户名
- **Beneficiary Account No.**：你的中国银行账号

中国银行官网公布的上海市分行 SWIFT Code 确实是 **BKCHCNBJ300**：
<https://www.boc.cn/en/aboutboc/ab6/200812/t20081216_493523.html>

不过跨境汇款容易因**英文户名、币种或开户地址**不一致而退汇。正式提交前，建议打川沙支行电话 **021-58921931** 或中行客服 **95566**，让银行根据你的具体账户确认“境外汇入汇款路径”。尤其要确认这个账户是否能直接接收相应外币。
