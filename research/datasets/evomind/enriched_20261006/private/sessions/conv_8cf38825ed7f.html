先说结论：**小程序主体变更不是一定要公证**。如果原、新主体都是正常存续的公司/个体户，且两边法人都能配合扫码，直接在微信公众平台后台走「法人扫码验证」就行（审核费 300 元），不需要公证。**只有当走不了扫码验证时才需要公证书**，典型场景：

- 原主体公司已注销（最常办公证的情况）
- 法人失联 / 不配合 / 扫脸反复失败（平台调取工商数据失败）
- 原主体是个人、转让给企业等无法扫码的情况

如果你确认需要公证，线上公证的做法如下：

**1. 准备材料（按场景略有差异）**
- 新旧主体营业执照彩色扫描件、双方法人身份证正反面
- 从微信后台下载的《小程序主体变更申请函》，填好、双方法人签字盖公章（两页要盖骑缝章）
- 小程序后台截图（含 AppID、原始 ID、主体信息页）
- 原主体已注销的：额外提供注销通知书、原股东身份证件，需原法人和股东配合人脸识别
- 法人不配合的：可走委托公证，加授权委托书 + 受托人身份证，由受托人做人脸识别（注意：原主体已注销的不能委托）

**2. 找渠道**
- 线下公证处现在普遍支持远程线上办理，你在上海可以直接找**上海市东方公证处**（公众号「上海市东方公证处」→ 在线办理，或随申办入口）或**上海市张江公证处**（公众号在线申办）先在线咨询，确认他们接这个业务后按指引提交
- 也有「一点证」等第三方线上公证平台（本质是帮你对接公证处），出证快（约 1-3 个工作日），但要先核实是正规公证处出证，别找纯代办黄牛

**3. 线上办理流程**
提交材料 → 公证处预审 → 系统生成电签链接发给双方法人（或受托人），各自在微信里**电子签名 + 人脸识别**（不用约同一时间）→ 公证员审核 → 出具电子公证书（与纸质同等法律效力）→ 下载后上传到微信后台的公证验证位置

**4. 后台变更操作**
原主体管理员登录 mp.weixin.qq.com → 设置 → 基本设置 → 主体信息 → 主体变更 → 按提示填双方信息、上传申请函和公证书 → 交 300 元审核费 → 审核约 7 个工作日 → 通过后**新管理员 7 天内确认**，重新签协议、绑新主体商户号。

几个坑提醒：公证书是**单次、单账号专用**，AppID/原始 ID 填错就得重新办；证件别用黑白复印件和模糊翻拍；变更前先解绑关联的支付服务商、异主体商户号，否则会卡流程。

我先翻一下之前的记录，确认你说的这个变更的背景，再帮你定用哪家在线公证。找到了背景——EvoMind/胆大求索相关的华师大科技处项目，小程序要转给学校主体。我再确认一下"事业单位作为接收方"的公证细节，然后给你定方案。查完了，先给你结论：**你这种情况（转给华师大这样的事业单位）基本只能走公证验证，你的判断没错** —— 因为主体变更的授权验证里，"法定代表人扫码"要求学校负责人（校长）用个人微信实名扫脸，事业单位实际做不到，所以只能选"上传公证书"验证路径。

**办的是什么公证**：不是"迁移公证"那么玄，本质是对双方法定代表人签字的《小程序主体变更申请函》做**签名、印鉴公证**（证明申请函上双方签字盖章属实、变更意愿真实）。

**用哪家在线公证，我的建议（按优先级）：**

**① 首选：上海市张江公证处**（zjnotary.com，就在浦东张江，离你近）
- 他们"一次都不跑"平台明确说明：委托、声明、协议这类非标公证不走自助机，而是**加公证专员"张小江"微信 → 对接公证员一对一在线办理**——小程序主体变更公证正好属于这类，流程完全对口
- 在线办证 + 人脸识别 + 电子公证书，本地公证处对事业单位的用章、授权结构更熟悉，不会因为"接收方是学校"卡你

**② 备选：上海市东方公证处**（公众号「上海市东方公证处」→ 业务办理 → 在线办理/在线咨询）
- 上海最大、线上平台最成熟、支持电子公证书，在浦东大道有分部
- 有 AI+人工在线咨询（400-821-4848），可以先问清楚接不接再走流程

**③ 兜底：一点证这类第三方线上公证平台**
- 优势是快（号称 1-2 个工作日）、标准化、企业↔企业场景很顺
- 但你这单带事业单位，学校印章核验、授权链比企业复杂，第三方模板流程容易卡；除非学校那边流程极其配合，否则不建议首选

**学校侧关键准备（先启动，这个通常最慢）：**
1. 《事业单位法人证书》（统一社会信用代码证书）复印件盖章
2. **校长授权委托书**：校长授权具体经办人（建议科技处/信息化办公室的人）代表学校签署申请函，盖学校公章——公证时由受托人做人脸识别即可，校长本人不用出面
3. 《小程序主体变更申请函》盖**学校公章**（用印要走校内审批，提前排期）
4. 学校对公账户信息：微信审核公证书时会做小额打款核验，需要提供

**建议的下一步顺序：**
1. 先让学校侧启动用印/授权审批（最耗时）
2. 同时加张江公证处"张小江"专员，把场景（公司→事业单位、双方都在上海、学校出授权委托书）说清楚，确认能办后拿材料清单
3. 小程序后台发起主体变更、下载申请函，两边并行准备
