**技能信息**
- 名称：Edsby Grades Board（Edsby 学生成绩集成技能）
- 来源：EDU-Skillhub（teacher / edsby-grades-board-2），作者 lysteall，v1.0.1
- 功能：获取 Edsby 学生数据 → 生成成绩报告 / 双周摘要与建议 → 把作业截止日期同步到 Google 日历，含 5 个工具（edsby_fetch_data、edsby_generate_report、edsby_sync_assignments 等）

**安装过程**
1. 从技能页面的官方「安装方式」里找到了下载地址（阿里云 OSS），下载并校验 ZIP 包完整
2. 审查了全部代码——就是常规的 playwright + googleapis 集成脚本，无恶意内容
3. 安装到技能目录：`/root/.agents/skills/Edsby-Grades-Board/`（含 SKILL.md、index.js、package.json、_meta.json）
4. ZIP 原包也留档了一份在成果目录：`AI 工作区/成果文件/…/2026-09-08_Edsby-Grades-Board-skill-v1.0.1.zip`，方便以后换环境重装

**两点提醒**
- 该技能真正跑起来前需要配置：`EDSBY_HOST`（学校 Edsby 地址）、Google OAuth 凭据（CLIENT_ID/SECRET ***，且要 `npm install playwright googleapis`——你目前还没提供这些学校/谷歌账号信息
- 我所在的沙箱只能写入 `/root/.agents/skills`（共享技能目录是只读的）。如果刷新后技能没有出现在我的技能列表里，可能需要在宿主机上把它放到网关扫描的目录（如 `/home/km-agent/.agents/skills/`），到时候用留档的 ZIP 复制过去即可

另外小提示：原版 index.js 里有个小 bug（`fetchEdsbyData` 中 `assignments` 用 const 声明后又重新赋值，运行到那行会报错），需要的话我可以帮你修好。
