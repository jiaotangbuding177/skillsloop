## 二、这一页 PPT 怎么做：四块布局

一页 PPT 的铁律：**一个结论 + 一张对比图 + 少量支撑点**，别贪多。

```
┌─────────────────────────────────────────────────────┐
│ 标题：2026 H1 经营回顾：收入滞后，费用前置，订单与资金提供支撑 │
├──────────────────────────┬──────────────────────────┤
│ 左：预测 vs 实际 对比图      │ 右：销量目标对比（设备/耗材）  │
│ （收入、毛利、费用、净利）    │   实际销量 vs 300台/45,000套  │
│   → 用"子弹图"或双柱对比图    │   → 用简单柱状图+达成率%      │
├──────────────────────────┴──────────────────────────┤
│ 底部条1：差异原因（2-3条）                              │
│ 底部条2：下半年展望 + 需要股东支持的事                     │
└─────────────────────────────────────────────────────┘
```

**各区块具体内容：**

**① 左图——四指标对比（最核心）**
用"实际（上半年）×2 年化 vs 全年保守目标"或直接"上半年实际 vs 全年目标"双柱对比，标注达成率。四个指标：营业收入、毛利率、期间费用、净利润。图下面一行小字写死结论：*"收入达成 2.2%，为全年目标最大缺口；费用支出节奏正常（19.5%），利润缺口主要由收入端造成。"*

**② 右图——销量对比**
设备：实际销量 **? 台** vs 目标 300 台（保守）
耗材：实际销量 **? 套** vs 目标 45,000 套

## 二、你手里的王牌：预测 vs 实际 的差异分析（Bridge Analysis）

建议按这个逻辑逐层拆：


## 一、什么是现金跑道（Runway）

**定义**：按当前的烧钱速度，公司账上现金还能撑几个月。

**公式**：
```
现金跑道（月）= 手头现金 ÷ 月均净现金消耗（Net Burn）
```

**两个核心口径（必须区分，股东可能会问）：**
- **总消耗（Gross Burn）**：每月现金总支出（费用+成本+税，不看收入）——你们上半年约 **92 万/月**
- **净消耗（Net Burn）**：每月总支出 − 每月回款——**这才是算跑道用的数**

为什么要看"净"不看"总"：因为公司有回款进来，真实消耗是支出减流入。如果只看总消耗，会严重低估跑道（把公司说得比实际更危险）。
