## 一、直接相关条款

### 1️⃣ 第7.1条 — 标的成果转让后的维持费
> "本协议下标的成果转让后的维持费及应对无效、侵权等费用由乙方或丙方协商承担。"

- **义务方：** 乙方（叶海峰）或丙方（合生纪），**双方协商确定**，甲方不承担
- **范围：** 标的成果（2项专利：201710797238.5、202010443080.3）转让后的维持费 + 应对无效、侵权费用
- **时限/金额/逾期责任/通知机制：** 均未约定

### 2️⃣ 第7.2条 — 甲方关联成果的维持费
> "本协议第4.2条所述甲方关联成果，除另有协议约定外，经在甲方登记备案后，其维持费及应对无效、侵权等费用由乙方或丙方协商承担。"

- **义务方：** 乙方或丙方协商承担，甲方不承担
- **例外情形：** ⭐ **"除另有协议约定外"**——若另行签订转让/许可协议，以该协议为准
- **适用前提：** 经甲方登记备案的关联成果
- **时限/金额/逾期责任：** 均未约定

### 3️⃣ 第3.5条 — 未缴年费失效的归责情形（最重要）
> "如因乙方选择不予回转的，或乙方、丙方及关联方原因（**包括但不限于未缴年费失效**、专利质押、抵押等情形），造成标的成果无法估计或无法完成回转的，乙方应当按照本协议第3.4条约定，向甲方支付应付价款的未付部分。"

- **义务方：** 乙方（丙方及关联方原因亦归责于乙方）
- **触发链：** 丙方关停（破产/注销）→ 甲方要求回转 → 因**未缴年费致专利失效**无法回转 → 乙方须支付**应付价款未付部分**（应付价款 = 评估价与150万意向价孰高者的30%）
- **责任性质：** 未缴年费本身无直接罚则，但构成触发全额补付义务的归责事由

> "乙方和丙方承诺应勤勉尽职……**维护相关知识产权权利**，积极应对无效、侵权主张等事项。"

## 一、结论：年费应由合生纪缴纳，学校（华师大）没有缴费义务

### 协议依据

**第7.1条**（直接适用）：
> "本协议下标的成果转让后的**维持费**及应对无效、侵权等费用**由乙方或丙方协商承担**。"

- 甲方（华师大）**不在承担主体范围内**——"学校缴纳"没有协议依据；
- 承担主体限定在乙方（叶老师）/丙方（合生纪）之间。

### 为什么指向合生纪（而非叶老师个人）

1. **专利权人身份**：专利目前登记在合生纪名下，按专利法，维持专利权有效（缴年费）是专利权人的义务。这笔欠费发生在**合生纪持有期间**，理应由持有期间的专利权人承担；
2. **费用归属逻辑**：年费对应的是"专利在合生纪名下期间"的维持成本，属于持有期费用，不因现在要转回叶老师名下而转嫁给叶老师或学校；
3. **协议费用框架**：第7.3条约定评估费、转让费、**变更费**等转化过程费用由丙方承担，虽未直接列年费，但体现了"丙方承担转化落地成本"的整体安排。

⚠️ 注意一个细节：协议写的是"**乙方或丙方协商承担**"——严格说协议没有强制指定某一方。所以最稳妥的做法是**合生纪缴纳**（最符合现状和法理），同时**合生纪与叶老师之间做个书面确认**（邮件或补充协议写明"本次补缴年费由合生纪承担"），避免日后扯皮。

## 二、年费缴纳如何办理（实操流程）

### 第1步：查专利状态（最关键，先做）
登录国家知识产权局**专利业务办理系统**（cpquery 或专利缴费信息补充系统），或致电国知局，查询这两件专利的欠费状态：
- **专利号①**：201710797238.5（原儿茶酸）
- **专利号②**：202010443080.3（红光/远红光）

确认处于哪个阶段（见下表）：

| 状态 | 判断标准 | 处理方式 |
|---|---|---|
| 滞纳期内 | 年费到期后 **6个月内** | 补缴年费 + **滞纳金**（每超1个月加收年费的5%，最高25%） |
| 已终止，恢复期内 | 收到《专利权终止通知书》后 **2个月内** | 提交恢复请求 + 缴**恢复费1000元/件** + 补缴年费及滞纳金 |
| 已过恢复期 | 终止超过2个月 | 专利权**无法恢复**，该专利失效（后果严重，见下方风险提示） |

### 第2步：补缴费用
- **渠道**：优先用国知局"专利业务办理系统"**网上缴费**（实时对账、有电子收据）；也可银行汇款（需在缴费信息补充系统登记）或上海专利代办处窗口；
- **缴费信息**：需填写专利号、费用种类（年费/滞纳金/恢复费）、缴费人名称（建议以**合生纪**名义缴，与专利权人一致）；
- **金额**：以系统查询到的应缴金额为准（含历年欠费、当年年费、滞纳金）。

### 第3步：重新办理转让
缴清年费、确认专利状态正常后，**重新提交著录项目变更（转让）申请**：转让方合生纪 → 受让方叶海峰，附转让协议、双方主体证明等文件。之前被退回就是卡在欠费上，缴清后即可正常办理。

### 第4步：留存凭证
保留缴费收据/电子凭证，用于国知局审核及日后对账。

---

## 三、时间紧迫性提示 ⏰

年费欠缴**越早处理越好**，因为：
1. 滞纳金随时间递增（最高年费的25%）；
2. 一旦进入"终止"状态，恢复窗口只有 **2个月**，且每件专利要额外花 1000元 恢复费；
3. 如果彻底失效无法恢复——**这两件专利就没法转让了**，而且按协议第3.5条，若因未缴年费导致专利失效并影响成果回转，乙方（叶老师）可能要对学校承担补付义务，风险不小。

## 一、欠费失效的法定条件与时间节点

**法条依据：**
- **《专利法》第44条**：没有按照规定缴纳年费的，专利权在期限届满前终止，由国务院专利行政部门登记和公告；
- **《专利法实施细则》第98条**：年费应在上一年度期满前缴纳；未缴的，国知局通知自应缴期满之日起 **6个月内** 补缴并缴纳滞纳金（**每超1个月加收当年全额年费的5%**，最高25%）；期满未缴的，**专利权自应当缴纳年费期满之日起终止**。

**时间轴：**

```
缴费截止日 ── 滞纳期(6个月) ── 终止 ── 恢复窗口(2个月) ── 权利永久丧失
            每超1月+5%滞纳金    (溯及至截止日) (自收到终止通知书起算)
```

| 节点 | 时限 |
|---|---|
| ① 正常缴费截止日 | 上一年度期满前（授权当年在办登记手续时缴） |
| ② 滞纳期 | 截止日后6个月，可补缴年费+滞纳金（5%~25%） |
| ③ 终止时点 | 滞纳期满未缴 → **自缴费截止日起终止**（注意：法律上溯及至截止日） |
| ④ 恢复窗口 | 收到《专利权终止通知书》之日起 **2个月内** |
| ⑤ 永久丧失 | 恢复期满未请求 |

## 二、失效后的权利状态变化

**1. 技术进入公有领域，可被自由实施**
- 专利权消灭后，任何人可**免费自由实施**该技术（制造、使用、销售、进口），无需许可；
- 专利文献本身早已公开、本就构成现有技术，失效丧失的是**独占权**而非"保密性"；
- 原权利人**不能再就相同方案重新申请专利**（已公开、丧失新颖性，第22条）。

**2. 终止无溯及力——与"无效宣告"的本质区别**

| | 欠费终止（第44条） | 无效宣告（第45-47条） |
|---|---|---|
| 效力 | 自终止日起消灭 | **自始无效** |
| 已收许可费 | 不退还 | 原则上返还 |
| 已决侵权赔偿 | 不受影响 | 原则上不追溯 |

- 终止**不影响此前已发生的权利**（已收许可费、已发生的侵权赔偿请求权）；
- 但持续性许可合同：权利终止后，被许可人原则上**无需再付后续许可费**（合同另有约定除外）。

**3. 对本案的直接后果**
- 失效专利**无法办理转让**（著录项目变更以专利有效为前提）；
- 触发华师大协议**第3.5条风险**：因未缴年费失效致成果无法回转的，乙方（叶老师）须按第3.4条补付应付价款未付部分；
- 技术（红光/远红光基因表达开关、原儿茶酸平台）一旦进入公有领域，**竞对可免费实施**。

## 三、恢复程序：法定路径、时限、补救条件与成功率

**法条依据：**《专利法实施细则》第6条，两条路径：

| 路径 | 适用 | 时限 | 恢复费 |
|---|---|---|---|
| **不可抗力** | 不可抗拒事由致延误 | 障碍消除后2个月内（最迟期限届满后**2年内**） | **免缴**（需附证明） |
| **正当理由** | 其他正当理由 | 收到国知局通知之日起 **2个月内** | **1000元/件** |

**实务标准流程（欠费恢复，三者缺一不可）：**
1. 提交**《恢复权利请求书》**（书面说明理由）；
2. **补缴欠缴年费 + 滞纳金**（5%~25%）；
3. **缴纳恢复费 1000元/件**（正当理由路径）；
4. 国知局审查 → 发出《恢复权利请求审批决定》→ 法律状态恢复"有效" → 再办转让变更。

**成功率影响因素：**

| 因素 | 影响 | 说明 |
|---|---|---|
| 是否在2个月窗口内提出 | ⭐ 决定性 | 超期基本无路可走 |
| 补缴是否足额（年费+滞纳金） | 决定性 | 缺一不可 |
| 恢复费是否缴纳 | 决定性 | 未缴视为未提出 |
| 理由陈述 | 中等 | 实务审查宽松，"因故未及时缴纳"通常可获准 |
| 超期情形 | 不可逆 | 仅剩行政诉讼等非常规途径，成功率极低 |

> 📌 **实务经验**：欠费恢复的审查门槛不高，**只要在2个月窗口内交齐材料并缴清费用，绝大多数能恢复成功**——真正的风险是错过窗口期。

## 四、对合生纪的紧急实务提示

1. **立即查状态**：登录国知局系统查询两件专利处于"滞纳期内 / 已终止可恢复 / 已过恢复期"哪种状态；
2. **在恢复期内** → 以合生纪名义：恢复请求书 + 补年费滞纳金 + 恢复费（1000元/件）→ 恢复后马上重提著录项目变更；
3. **已过恢复期** → 专利灭失，立即与叶老师、华师大沟通（涉及协议第3.5条补付风险），评估补救与谈判方案；
4. **长期机制**：建立年费台账（截止日/滞纳期/恢复期三重提醒），缴费后1-3个工作日核对销账，或委托代理机构年费监控兜底。
