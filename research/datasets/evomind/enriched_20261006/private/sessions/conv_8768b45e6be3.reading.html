## 📊 第一步：Market Segments — 谁需要企业技能管理？

**目标市场：** 需要系统化管理员工技能、提升组织能力的中大型企业及快速成长的创新团队。

## 💪 第二步：SWOT Analysis — 企业技能管理市场的战略评估

### Strengths（内部优势）
1. **刚需明确** — 人才红利消退后，组织能力建设是CEO级命题
2. **数据引擎** — 一旦上线，天然积累员工技能数据，形成网络效应
3. **多场景延伸** — 技能管理可扩展至招聘、绩效、薪酬、学习，天花板高
4. **AI时代红利** — AI可大幅降低技能图谱构建、技能差距分析的边际成本

### Weaknesses（内部劣势/进入壁垒）
1. **交付重** — 大型企业需要定制化，产品化程度取决于"标准化 vs 灵活"的平衡
2. **数据初始冷启动** — 技能管理依赖初始数据（岗位技能、员工技能），空系统没人用
3. **决策链长** — HR系统采购涉及HRVP、IT、法务、财务，销售周期3-6个月
4. **学习成本** — 终端员工需要主动更新技能记录，行为改变难

### Opportunities（外部机遇）
1. **AI原生技能管理** — 现有竞品大多老旧（SAP SuccessFactors、Cornerstone等），AI原生产品有机会颠覆
2. **零工经济兴起** — 灵活用工下，企业更需要实时了解"我有什么人、能干什么"
3. **技能货币化** — 技能数据可衍生出内部人才市场、技能认证、培训推荐等新收入
4. **全球化远程办公** — 分布式团队更需要透明化的技能管理

### Threats（外部威胁）
1. **HR SaaS巨头不可忽视** — SAP、Workday、北森若快速集成AI技能模块，挤压独立产品空间
2. **员工隐私顾虑** — 技能管理可能被视为"监控"，引发文化抵制
3. **经济下行** — 企业缩减HR tech预算，技能管理常被归类为"可选的HR软件"
4. **碎片化竞争** — 市场上已有几十家小团队做技能图谱，差异化空间收窄

### 🔗 交叉分析战略建议

| 组合 | 策略 |
|------|------|
| **S+O** | 利用AI降低冷启动门槛（自动从工作产出推断技能），抢占"AI原生技能管理"心智 |
| **W+O** | 用AI生成初始技能图谱 + Linkedin/招聘平台数据导入，解决冷启动 |
| **S+T** | 专注做巨头不擅长的事：轻量化、AI-native、数据灵活连接不同HR系统 |
| **W+T** | 通过PLG模式降低销售门槛（轻量版免费、付费模块化），规避长决策链 |

## 📝 第四步：User Stories — 核心用户故事

### 角色1：HR负责人（Lily）

**Story 1: 技能图谱搭建**
```
As a HR负责人,
I want to 快速搭建公司级技能图谱（岗位→技能需求→等级标准）,
so that 各部门有统一的技能语言，支撑人才盘点和晋升评估。

Acceptance Criteria:
1. 支持从行业标准库（SFIA/NICE）导入并自动匹配公司岗位
2. 支持自定义技能名称、描述、等级标准
3. 支持一键生成岗位技能需求模板
4. 支持多人协作编辑技能图谱，带审批流
5. 支持版本管理和变更历史追溯
```
**Story 2: 技能差距分析**
```
As a HR负责人,
I want to 查看各部门技能差距分析报告,
so that 我能精准规划培训预算和招聘优先级。

Acceptance Criteria:
1. 报告自动对比"当前技能"与"岗位需求"的差距
2. 支持按部门/岗位/技能类别下钻
3. 差距热力图支持颜色编码（绿/黄/红）
4. 每个差距点自动推荐1-3个学习资源
5. 支持导出PDF/PPT给高管汇报
```
### 角色2：技术负责人/CTO（Alex）

**Story 3: 团队能力可视化管理**
```
As a 技术负责人,
I want to 在团队扩张中实时了解每个成员的技能分布,
so that 我能做出更好的项目分配和招聘决策。

Acceptance Criteria:
1. 团队技能面板展示按技能分类的能力分布图
2. 支持快速识别"谁是某技能最强者"
3. 支持"如果A离职，谁会受影响"的技能风险评估
4. 招聘需求自动关联技能差距分析
5. 历史趋势对比（团队能力是上升还是下降）
```
**Story 4: Onboarding技能加速**
```
As a 技术负责人,
I want to 新同学入职自动获得个性化技能成长计划,
so that 缩短新人产出周期，提升留存率。

Acceptance Criteria:
1. 新员工入职自动触发技能评估问卷
2. 基于评估结果生成90天渐进式学习路径
3. 支持设置定期技能检查点（30/60/90天）
4. 学习路径关联实际代码练习和review checklist
5. 管理者可实时查看新人技能成长进度
```
### 角色3：一线员工（小张）

**Story 5: 零摩擦技能记录**
```
As a 一线工程师,
I want to 不费任何额外精力就能记录和展示我的技能成长,
so that 我的能力能被看见，获得匹配的机会。

Acceptance Criteria:
1. 系统自动从GitHub/GitLab PRs推断技术技能变化
2. 每周推送一次Slack/飞书消息："这周学了什么？" 15秒可完成回答
3. 同事可互评技能标签，互相+1认证
4. 个人技能面板像portfolio一样可分享给招聘方或项目经理
5. 完成的培训/认证可一键同步至技能记录
```

## 🎯 第六步：Product Strategy — 产品战略总结

### Vision
**让每一个企业的组织能力变得可量化、可增长、可预测。**

### 市场首选
成熟大型企业的HR/L&D团队 —— 预算充足、痛深、决策后可快速推广

### 成本定位
**溢价型教育(value-based pricing)** — 从"节省培训预算"和"降低招聘错误成本"中提取价值

### 核心价值主张
> **"从摸黑管理到可视化增长的技能操作系统"**

| 当前(Without) | 产品(How) | 未来(With) |
|--------------|----------|-----------|
| 技能数据在HR脑袋里、Excel里、系统孤岛里 | AI自动推断 + 零摩擦记录 + 开放集成 | 每项技能可衡量、可追踪、可投资 |
| 培训预算凭经验拍 | 技能差距分析驱动精准投入 | 每块钱培训产生可量化的技能增长 |
| 内部人才靠人缘和运气被发现 | 内部人才市场全局匹配 | 每个人找到最适合的项目和机会 |

### 关键取舍（Trade-offs）
- ✅ **做平台不做孤岛** → 花工程精力做API集成而非重金自研学习内容
- ❌ **不做ATS/HRIS替代** → 专注技能管理层，对接而非替代大系统
- ✅ **AI-first 而非 data-entered** → 赌AI推断足够准，而非逼用户手动录入
- ❌ **不做中小微企业免费版** → 初期聚焦高客单价企业，不稀释聚焦

### 防御性（Can't easily copy）
1. **技能图谱的网络效应** — 企业内员工越多用，技能数据越厚，差距分析越准，切换成本越高
2. **AI推断的飞轮** — 越多企业使用，AI模型越懂行业技能关联，新企业冷启动越快
3. **集成壁垒** — 对接过的HRIS/生产力工具越多，新竞争者需要追赶的集成越多

### 需验证的关键假设
1. 🧪 AI自动推断准确率是否能做到80%+？（可先做50人手工验证）
2. 🧪 HR负责人是否愿意为"技能管理"而非"培训管理"单独付费？
3. 🧪 员工是否愿意被动回答"学了什么"（每周一次）？回复率能否维持>50%？
