这个 skill 是个**中文论文标准化交付工作台**，不是一键生成论文的工具，而是把毕业设计论文拆成可审查、可回退的流程管理工具。

## 怎么用

**直接用自然语言跟它交互就行**，比如：

### 启动工作流
> "帮我写本科毕业论文，这是我的项目代码在 `xxx/`，学校模板在 `xxx/`"
> "帮我启动论文工作台，材料在桌面上的 `毕业设计/` 文件夹"

它会自动走完整流程：
1. **收集材料** → 记录有什么、缺什么、影响多大
2. **初始化工作区** → 建 `paper-context/` 和 `paper-output/`
3. **解析标准** → 填标准配置文件
4. **分析样文/模板** → 提取格式、字数、结构
5. **构建证据链** → 从代码/截图/文献提取事实
6. **生成论文规约** → 确定章节结构、字数预算
7. **分章写作** → 基于确认的证据写正文
8. **生成 DOCX** → 四种路径（默认/样文贴近/模板填充/初稿编辑）
9. **质量检查** → 标准、证据、引用、图片、AIGC 风格检查
10. **交付报告**

### 也可以在中间任意步骤介入：
- `"帮我看一下样文分析结果"`
- `"确认大纲，第一章3000字"`
- `"用学校模板填充 DOCX"`
- `"检查一下 AIGC 痕迹"`
- `"帮我排版参考文献"`
- `"给我生成论文截图"`

### 几种 DOCX 输出路径

| 路径 | 场景 |
|------|------|
| M1 默认样式 | 从 Markdown 直接生成，宋体小四正文 |
| M2 样文贴近 | 有往届样文，提取风格后生成 |
| M3 模板填充 | 有学校 docx 模板，填充内容不动样式 |
| M4 已有稿编辑 | 已有初稿，做修改编辑 |

**关键原则：** 这个 skill 不会乱猜缺的材料。缺代码截图、缺实验数据、缺参考文献，它会停下来告诉你缺了什么、影响多大，等你有材料了再继续。
