随机种子（random seed）是机器学习里一个看似不起眼但极其重要的概念。简单说，它就是**随机数的"起点"或"编号"**。

## 直观理解

想象有一个巨大的"随机数生成器"，你给它一个种子，它就会按一套固定算法吐出一串看起来随机的数字。**同一个种子，永远产生同一串随机数。**

```python
# 用种子 42
np.random.seed(42)
print(np.random.rand(3))  # [0.3745, 0.9507, 0.7320]

# 重置种子 42，再跑一次
np.random.seed(42)
print(np.random.rand(3))  # [0.3745, 0.9507, 0.7320]  ← 一模一样
```

改变种子数字（比如从 42 改成 123），整个随机序列就完全不同了。

## 为什么在 ML 里这么重要？

机器学习里到处都是"随机"操作：

| 操作 | 随机的是什么 |
|------|-------------|
| 数据集 shuffle | 分训练集/测试集的顺序 |
| 权重初始化 | 神经网络的初始参数 |
| Dropout | 哪些神经元被丢弃 |
| 数据增强 | 旋转、裁剪的变换参数 |
| SGD 采样 | mini-batch 里的样本 |

**没有固定种子 → 每次跑结果不一样 → 你改了个超参数，效果变好了还是纯属随机？你没法判断。**

种子就是让实验**可复现**的核心工具。

## 实际怎么用

```python
import random
import numpy as np
import torch

# 在训练脚本最开头统一设置
random.seed(42)
np.random.seed(42)
torch.manual_seed(42)
if torch.cuda.is_available():
    torch.cuda.manual_seed_all(42)
torch.backends.cudnn.deterministic = True
```

然后你改了一行代码跑两遍——**看到的变化是代码造成的，不是随机运气。**

## 常见误区

1. **种子 42 比 0 好吗？** — 不，种子本身没优劣，只是入口编号
2. **设了种子就完全复现？** — 不，GPU 并行运算本身有非确定性，绝大多数情况下能复现，极端情况（特定 CUDA 操作顺序）可能仍有细微差异
3. **选不同的种子就是在做超参数调优？** — 你可以跑几个不同种子看稳定性，但调种子本身不是调参手段

## 一句话总结

> 随机种子让随机变"伪随机"——看似随机，但只要你记住入口（种子），就能精确重复每次实验。它是机器学习中**可复现性**的基石。

## 一、模型参数是怎么设置的？

首先厘清一个关键区分——

### 两种"参数"

| 类型 | 含义 | 谁在设置 | 怎么设置 |
|------|------|----------|---------|
| **模型参数**（weights & biases） | 神经网络里几十万到几十亿个数字，决定了"输入→输出"的映射 | **训练算法** 自动学出来的 | 梯度下降 + 反向传播，从随机初始化开始，逐步调整 |
| **超参数**（hyperparameters） | 控制训练过程本身的旋钮 | **你** 手动设置 | 经验 + 实验 + 调优 |

下面重点说**超参数**。

### 你需要关心的核心超参数

**① 学习率（learning rate）** — 最重要的一个
```
lr = 0.001  # 常用起点，Adam 优化器默认
```
设置规则：
- 太大 → 震荡不收敛（Loss 忽高忽低）
- 太小 → 训练极慢，卡在局部最优
- 常用策略：初始 0.001（Adam），观察 Loss 曲线再调

**② 批大小（batch size）**
```
batch_size = 32 或 64  # 常见值
```
- 越小 → 梯度噪声大，但泛化能力好，显存需求低
- 越大 → 训练稳定，但可能泛化差，吃显存
- 2 的幂（32/64/128/256）是惯例，因 GPU 架构对齐

**③ 优化器选择**
```
optimizer = Adam    # 90% 场景首选，自适应学习率
optimizer = SGD     # 经典，需要手动调 lr 和 momentum，调好了效果可能更好
```
- **新手无脑用 Adam** — 自适应、鲁棒、不需要调 lr schedule
- 老手在 CV 里可能用 SGD + momentum

**④ 轮数（epochs）**
```
epochs = 100  # 自己调，看 validation loss 停
```
- 设一个足够大的数，用 **Early Stopping** 在验证集不再变好时自动停

**⑤ 权重初始化**
```
# PyTorch 默认的 Linear 层用的是 Kaiming Uniform
# 通常不需要你自己设，框架帮你做了
```

### 这些值到底怎么来的？

不是算出来的，是**试探出来**的：

1. **看别人的论文/代码** — 同架构的经典配置直接抄
2. **做实验** — 先跑一两个 epoch 看 Loss 是不是在下降
3. **网格搜索 / 贝叶斯调参** — 自动试不同的组合
4. **经验法则** — 比如"学习率从 0.001 起步，如果 Loss 不降就试 0.0001"

## 二、两天掌握深度学习概念，看什么？

先说实话：**两天不可能"掌握"，但可以"搭起完整骨架"**。下面是一条极限浓缩路线。

### Day 1：理论基础（8-10 小时）

**上午：数学根基（2h）**
- 导数、链式法则 → **这就是反向传播的本质**
- 矩阵乘法 → **这就是神经网络的本质**（权重矩阵 × 输入向量）
- 推荐：[3Blue1Brown 的神经网络系列](https://www.youtube.com/playlist?list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi) — 视觉化做得极好，4 个视频只看前 2 个就够了

**下午：核心概念（4h）**
- **线性层 + 激活函数**（ReLU，为什么需要非线性）
- **损失函数**（Cross-Entropy、MSE）
- **梯度下降 + 反向传播**（理解"Loss → 各层求导 → 更新权重"这个链条）
- **过拟合 vs 欠拟合** + 正则化（Dropout、Weight Decay）
- **训练/验证/测试集划分**

**晚上：动手写一个（2h）**
- 用 PyTorch 写一个 **手写数字识别（MNIST）**：
  ```python
  # 核心代码就这几行
  model = nn.Sequential(
      nn.Linear(784, 128), nn.ReLU(),
      nn.Linear(128, 10)
  )
  ```
- 跑起来，改改学习率、层数，看效果变化。**这是最有价值的一步。**

### Day 2：深度扩展（8-10 小时）

**上午：三大架构（3h）**
- **CNN** — 处理图像，理解"卷积核"概念
- **RNN / LSTM / Transformer** — 处理序列，理解"注意力机制"
- **Transformer 是现在最火的** — 按这个顺序理解：RNN 的问题 → 注意力机制 → Self-Attention → Transformer = Attention Is All You Need

**下午：现代神器（2h）**
- **预训练模型 / 迁移学习**（为什么现在不用从零训练了）
- **GPU / 分布式训练**（为什么需要这么大算力）
- **Hugging Face**（一行代码调用 BERT/GPT，感受"开箱即用"）

**晚上：跑一个现代项目（3h）**
- 去 Hugging Face 找一个示例：文本分类或图像分类
- 把预训练模型换掉、调几个参数跑一遍
- 体验完整流程：数据 → 模型 → 训练 → 评估
