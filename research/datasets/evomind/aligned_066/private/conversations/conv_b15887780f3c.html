tyc login --no-open --no-block

tyc login --resume

tyc company companies "上海胆大求索科技有限公司" --md

## 方式二：MCP 模式（配置到 .mcp.json）

如果客户端支持 MCP，直接配到 `/workspace/.mcp.json`：

**OAuth 模式（推荐）：**
```json
{
  "mcpServers": {
    "tyc-mcp": {
      "url": "https://mcp.tianyancha.com/"
    }
  }
}
```

**API Key 模式：**
```json
{
  "mcpServers": {
    "tyc-mcp": {
      "url": "https://mcp.tianyancha.com/",
      "headers": {
        "Authorization": "你的API_KEY"
      }
    }
  }
}
```
