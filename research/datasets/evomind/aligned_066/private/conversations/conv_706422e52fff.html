这个需求一般是**笔记本键盘没有独立的 Page Up/Page Down 键**（很多轻薄本和紧凑键盘都没有），想用别的键映射出来。分系统给你方案：

## Windows（最常见）

**首选：微软 PowerToys Keyboard Manager**（免费、官方、图形界面）
1. 装 PowerToys → 打开 **Keyboard Manager** → **Remap a key**（改单键）或 **Remap a shortcut**（改组合键）
2. 例：把 `右Ctrl` → `PgUp`、`右Alt` → `PgDn`；或者映射组合键 `Ctrl+↑` → `PgUp`
3. 支持**只对特定应用生效**，比如只在浏览器里映射

**进阶：AutoHotkey**（脚本，最灵活）
```ahk
; CapsLock 当修饰键，I/K 模拟 Vim 风格翻页
CapsLock & i::Send {PgUp}
CapsLock & k::Send {PgDn}
```
保存为 `.ahk` 文件双击运行即可，还能叠加长按/短按区分等骚操作。

**简单粗暴：SharpKeys** —— 注册表级改键，单键对单键，重启后全局永久生效，但做不了组合键。

## macOS

- **Karabiner-Elements**（免费，功能最强）：可以设 `Fn+↑` → Page Up、`Fn+↓` → Page Down，或任意组合
- 系统自带「系统设置 → 键盘 → 键盘快捷键」只能改修饰键，做不了 Page Up/Down，基本得靠 Karabiner

## 我的建议

如果只是想要翻页，最顺手的是 **`Fn + ↑/↓`**（部分笔记本出厂自带）或者 **`CapsLock + I/K`**（手不离主键区，写代码很爽）。

好，Windows 下把 **F11 → Page Up、F12 → Page Down**，最简单的是用 PowerToys，给你现成步骤：

## 方法一：PowerToys（推荐，图形界面）

1. 装 PowerToys（Microsoft Store 搜 "PowerToys"，或 GitHub 下载）
2. 打开 **Keyboard Manager** → 把开关打开
3. 点 **Remap a key** → 右侧 **Add remapping**
4. 第一行：左边按 `F11` → 右边点 "Type" 按 `Page Up`
5. 再 Add 一条：`F12` → `Page Down`
6. 立即生效，不用重启

## ⚠️ 先注意一个坑：Fn Lock

很多笔记本（联想/华硕/戴尔等）的 F11/F12 **默认是媒体键**（图标是亮度、音量之类），按下去根本不输出 F11，PowerToys 就抓不到。

解决办法（三选一）：
- 按 **`Fn + Esc`**（或 `Fn + CapsLock`）开启 **Fn Lock**，让 F 键默认输出标准 F1-F12
- 或者进 **BIOS**（开机按 F2/F10/Del），把 "Function Key Behavior" 设为 **Function mode**
- 如果是 ThinkPad，用 Lenovo Vantage 里也能改

## 方法二：SharpKeys（注册表级，零后台）

不想常驻后台程序的话，用 SharpKeys：
1. Add → 左边选 `Special: F11 (0x57)` → 右边选 `Page Up (0x21)`
2. 再 Add：`F12 (0x58)` → `Page Down (0x22)`
3. **Write to Registry** → 注销或重启生效
4. 改之前它会自动备份注册表，想还原一键搞定

## 方法三：AutoHotkey（两行脚本）

```ahk
F11::PgUp
F12::PgDn
```
保存为 `.ahk` 双击运行，但要常驻后台。

---

**我的建议**：如果不想装软件，SharpKeys 最干净；想随时改回来看效果，PowerToys 更方便。

另外提醒一句：映射后 **F11 的全屏快捷键（浏览器）就没了**，如果你常用全屏，可以考虑改用 `Ctrl+Shift+F` 之类替代。

找到原因了——红米游戏本（Redmi G）的小键盘是**双功能键**：默认输出数字，导航功能要走 **Fn 组合**。而且注意键位：

## 正确触发方式

- **Page Up = Fn + 小键盘 `9`**（9 键帽上印着 PgUp）
- **Page Down = Fn + 小键盘 `3`**（3 键帽上印着 PgDn）

也就是说，**按住左下角的 Fn 不放，再按 9 或 3**。不是直接按 9/3（那是数字），也不是关 NumLock——游戏本默认数字优先，导航功能全靠 Fn 切换。

同理：`Fn+7`=Home、`Fn+1`=End、`Fn+0`=Insert、`Fn+.`=Delete，方向键则是 `Fn+8/2/4/6`。

## 如果 Fn + 9/3 还是没反应

按顺序排查：

1. **先试 Fn 锁没锁**：按 `Fn + Esc`（或看键盘上有没有 Fn Lock 指示灯）切换一次，再试 Fn+9。有些机型 Fn 被锁定后组合行为会反过来。
2. **测试 Fn 本身正不正常**：按 `Fn + F5`（调亮度）或 `Fn + F4`（切换显示），如果有反应说明 Fn 正常，那就是组合键按法问题；如果 Fn 组合整体失效，可能是键盘驱动挂了。
3. **更新驱动**：装/更新「小米电脑管家」或去红米官网下键盘驱动，游戏本刚重装系统后 Fn 组合容易失灵。

等一下，你描述的这个症状（**Fn 正常、唯独整个小键盘区全部失灵**）指向一个很经典的元凶——**Windows 的"鼠标键"（Mouse Keys）被误开启了**。

## 最可能的原因：鼠标键被误开

开启鼠标键后，**整个小键盘会被占用为鼠标控制**：9=鼠标右上移、3=右下移、数字键全变成移动/点击，你按什么都"没反应"。而且它的开关快捷键是 `左Alt + 左Shift + NumLock`，很容易误触。

**验证方法：**
- 看屏幕右下角托盘区，有没有一个**小鼠标图标**（鼠标键开启时会显示）
- 按一次 `左Alt + 左Shift + NumLock`，再试小键盘
- 或者在「设置 → 辅助功能 → 鼠标指针和触摸 → 鼠标键」里关掉

## 顺便纠正我上一轮的说法

红米游戏本的小键盘，**9/PgUp、3/PgDn 是 NumLock 切换的，不是 Fn 组合**（Fn 组合是轻薄本无小键盘时的做法，我上轮说岔了，抱歉）。

标准逻辑是这样的，你在**浏览器里**（能滚动的地方）测试：

| NumLock 灯状态 | 按小键盘 9 | 按小键盘 3 |
|---|---|---|
| 灯亮 | 输出数字 9 | 输出数字 3 |
| 灯灭 | **Page Up**（往上翻页） | **Page Down**（往下翻页） |

所以正确姿势：**按 `Fn + NumLock`（或小键盘上的 NumLk 键）把 NumLock 灯灭掉，然后直接按 9 / 3 就是翻页**，不需要按 Fn。

## 原因

《真三国无双7》是光荣的老引擎，用 **DirectInput** 读键盘，对小键盘的导航键（NumLock 关掉后的 PgUp/PgDn）支持很差，经常直接认不出；而且很多游戏**启动时会强制把 NumLock 打开**，小键盘又变回纯数字模式——你在游戏里按 9/3，它收到的就是数字 9/3，不是 PgUp/PgDn。

## 解决方案（按推荐顺序）

**方案一：游戏内重新绑定键位**
进游戏「设置 → 键位设置」，找到你想要的功能，光标停在绑定框，**直接按小键盘 9 / 3**，看游戏认不认。如果绑定框里有反应，就完事了。

**方案二（推荐）：PowerToys 按应用映射**
绕过 NumLock 和 DirectInput 的坑——把小键盘 9/3 在**只对游戏**时变成 F11/F12（标准键，游戏百分百认）：

1. PowerToys → Keyboard Manager → Remap a key → **勾选 "App-specific"**（按应用映射）
2. 选择游戏进程（任务管理器里看下真三7 的进程名，一般是 `DW8XLCE.exe`）
3. 映射：`Numpad 9` → `F11`，`Numpad 3` → `F12`
4. 进游戏，把你想用的功能绑到 F11/F12

这样平时小键盘照常输入数字，只有游戏里 9/3 变成 F11/F12，不受 NumLock 影响。
