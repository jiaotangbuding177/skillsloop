# EvoMind全量任务主题与缺失资料分析

日期：2026-10-05。输入范围为现有1,466条真实用户会话。原始数据不改写，所有新结果单独存放。本轮是数据探索，不是技能生成实验或任务完成率评测。

## 怎样得到任务分布

1. 主输入只读`../matched_066/private/evomind_conversations.json`。同一内容的原重复出现保留在来源记录中，统计时使用其去重用户正文组。JSON和对应JSONL不能一起导入。
2. 为主题分析剥离已经确认的平台起始包装，例如中文回复、时间和个人助手设置；原文与来源不改。真实短反馈、业务背景、失败和不明确要求保留。用户的技能声明不作为真实消费证据。
3. 先对全部用户正文做本地字符TF-IDF、降维和球面聚类，取得主题线索。这一步没有外部模型调用，详细参数与输入SHA256在`manifest.json`。由于无明确目标的短反馈、平台模板及通用动词容易形成簇，不能把其14个词面簇直接解释为业务任务。
4. 再分三份逐会话做AI语义审阅，依可见用户目标归入任务主题。每个用户正文组都进入审阅摘要；过长正文保留首尾并明确标记截断，歧义案例回读完整原文。原分片摘要每段上限650字，主代理补审的421条另存上限400字的紧凑视图；不能声称所有长正文逐字语义审阅。分类不依赖会话标题。`private/semantic_shard_*/`保留输入和初始判读，修订另存覆盖记录。
5. 每条会话分配一个主主题；其他可辨识的独立目标记录为其他主题。因此主类总数等于1,466，多类覆盖可以大于1,466。分类依据保留去重用户正文组编号，可回查原文。领域目标优先，例如合同审阅归法务而不是泛文档；格式、子步骤及同目标的返工不另算独立主题。
6. 程序检查覆盖、重复编号、标签枚举与来源编号，并另次AI核对边界及代表案例，生成统计、图和逐会话检索页。AI置信度是判读者主观标记，不是经过校准的准确率；没有独立人工金标准，不能报告聚类准确率。

**这些数量是涉及某类主题的会话数，不是已经恢复的独立任务条数，不是经过认证的workflow簇，更不是成功任务数。** 一条会话可含多个同类或异类任务；本轮不替代研究管道的任务识别和轨迹恢复。

## 产物

- `private/index.html`：查看柱形图、逐会话类别、依据、正文摘要及完整会话链接。
- `task_distribution.csv/json`：主主题与多主题覆盖统计；`figures/`含PNG与可编辑SVG。
- `private/session_task_categories.csv/json`：全部会话标签，带来源依据。只放本地受控目录。
- `private/requested_file_references.csv`：逐文件引用补交定位表，引用次数不是独立文件数量。
- `private/session_ids.csv`：固定补交范围；`provider_export.sql`为数据方执行的只读导出模板，研究端未执行生产查询。
- `category_evidence_gaps.csv/json`：各主类输入/输出文件元数据覆盖；`private/artifact_path_lookup.csv`补查被后续会话覆盖归属的同用户同路径产物。
- `summary.json`、`delivery_validation.json`：计数与格式/覆盖验收，不充当语义准确性验收。
- `delivery_manifest.json`：本轮输入和35项交付产物SHA256；`semantic_review_notes.md`保留抽查及修订边界。

私有正文、来源记录和文件路径在`private/`内；报告和图只用必要汇总。没有将数据上传、连接生产或调用外部模型API。AI语义审阅使用本次会话的助手资源，具体耗量未单独计量。

## 本地复算

在已有Python和NumPy/Matplotlib环境执行`analyze_local.py`、`prepare_semantic_review.py`可重建本地词面线索与语义审阅输入。已经完成的语义标签冻结保存，依次执行`build_delivery.py`、`build_supplementary.py`可确定性复算表、图和定位清单。**重新让AI归类不是确定性复算**，需保存新标签及差异，不覆盖旧判读。

源文件与语义标签均应一起冻结；最终报告列出本轮校验。重绘图表可得到同一统计内容，文件字节也受Python/绘图库版本等影响；冻结结果以本轮hash为准，结束前执行`freeze_delivery.py`核对链接和清单。补数据来源及限制详见`research/reports/2026-10-05_evomind_data_supplement_request.md`。
