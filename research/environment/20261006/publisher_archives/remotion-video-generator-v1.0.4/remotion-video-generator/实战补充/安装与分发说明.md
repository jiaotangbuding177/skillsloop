# 安装与分发说明

## 这是什么

`remotion-video-generator` v1.0.4 —— 一套**标准 Agent Skills 格式**的 Remotion 视频生成能力包。
装上之后，Agent 会在用户提到"做个视频""生成视频"时自动激活，
按 **环境验证 → 分镜规划 → 代码生成 → 渲染交付** 四阶段走完整个流程。

它保的是**下限**：不漏步骤、不写出渲染不出来的代码、动效语法符合 Remotion 官方规范。

**不绑定任何 Agent。** Cursor、Claude Code、Codex、CodeBuddy —— 只要实现了
Agent Skills 格式（「一个目录 + 一份带 YAML frontmatter 的 SKILL.md」）就能加载。

---

## 安装

每个 Agent 都有自己的插件 / Skill 目录和命令，**按你自己 Agent 的方式放置即可**，
这里不假定你用的是哪一个。要放的核心只有一个目录：

```
skills/     # 6 个 Skill，每个都是「目录 + SKILL.md」的标准结构
```

把它放进你的 Agent 的 Skill 目录，就装好了。其余部分按需取用：

| 目录 | 作用 | 建议 |
|------|------|------|
| `skills/` | 6 个 Skill，能力本体 | **必装** |
| `templates/` | 24 个视频类型 / prompt 模板 | 一起装 |
| `实战补充/` | 8 个环境坑 + 3 个可复用流水线脚本 | 一起装，强烈建议 |
| `agents/` | 专家人设（「视频匠 / Remy」） | 可选 |
| `license/` | 5 个第三方协议 | 分发时必须原样保留 |

包里没有平台专属的清单、配置文件或市场元数据——不绑定任何一个 Agent。

## 前置依赖

| 依赖 | 用途 | 检查命令 |
|------|------|---------|
| Node.js 18+ | Remotion 运行 | `node -v` |
| ffmpeg / ffprobe | 音视频处理与时长读取 | `ffmpeg -version` |
| Chromium | Remotion 渲染（无头浏览器） | `which chromium` |
| Python 3 + venv | edge-tts 配音（可选，不用配音则不需要） | `python3 -v` |

装完建议先跑一次自带的校验：

```bash
cd remotion-video-generator && ./validate.sh
```

## 目录结构

```
remotion-video-generator/
├── agents/remotion-video-expert.md # Agent 人设（「视频匠 / Remy」）
├── skills/
│   ├── video-generator/            # 主编排 Skill（1323 行，四阶段工作流）
│   ├── scene-planner/              # 分镜规划（1032 行）
│   ├── environment-setup/          # 环境检测与安装（544 行）
│   ├── remotion-best-practices/    # 最佳实践（46 行主文件 + rules/ 30 个专题）
│   │   └── rules/                  # animations / timing / transitions / sequencing /
│   │                               #   audio / fonts / charts / text-animations /
│   │                               #   captions / srt / trimming / lottie / tailwind ...
│   ├── lucide-icons/               # 图标检索（含 scripts/）
│   └── bgm-library/                # 背景音乐库（含 scripts/）
├── templates/                      # 14 个视频类型模板 + 10 个 prompt 模板
├── license/                        # 5 个第三方协议（务必保留）
├── validate.sh                     # 校验脚本：目录结构 + frontmatter 合规性
├── README.md
└── 实战补充/                        # ← 本次追加，非原插件内容
```

**关键点**：它是**文件夹编排**，不是一个单文件。
`remotion-best-practices` 采用"主文件 + `rules/` 子目录"的渐进式加载——
主 SKILL.md 只有 46 行，真正的细节拆成 30 个专题文件按需读取。
这是很合理的结构：既不会一下塞满上下文，又能覆盖到细节。

## 覆盖范围自查

按全库 87 个文件统计：

| 主题 | 覆盖文件数 | 说明 |
|------|-----------|------|
| `interpolate` / `spring` 动效 | 39 | **最擅长的部分**，语法细节全 |
| 字幕 / captions / SRT | 13 | 覆盖到位，含 import-srt / display-captions / transcribe |
| 音频 / TTS / voice | 5 | 有涉及，但不深入 |
| 响度 / LUFS | 1 | 只在 polish-prompts 里提了一句 |
| **确定性伪随机** | **0** | **空白，且是 Remotion 头号陷阱** |
| **Chromium headless 兼容** | **0** | **空白** |

结论：**覆盖面比我最初判断的广**（我一开始只搜了 4 个 SKILL.md 主文件，得出"字幕 0 覆盖"
的错误结论——真实情况是 `rules/` 下有 13 个文件覆盖字幕）。
真正缺的是"确定性伪随机"和"Chromium 环境兼容"这两块，所以补了 `实战补充/`。
