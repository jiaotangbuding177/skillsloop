# 跨境贸易合同专项审查清单 · Cross-Border Trade Contract

> **法条依据**：《民法典》第 595-680 条（买卖合同）+ 《对外贸易法》+ 《海关法》+ 《出口管制法》+ 《联合国国际货物销售合同公约（CISG）》+ 《国际贸易术语解释通则（Incoterms 2020）》

---

## 跨境贸易合同核心特征

**典型模式**：
- 一般贸易（一般进出口）
- 来料加工 / 进料加工
- 跨境电商（B2C / B2B）
- 易货贸易

**核心法律关系**：除中国合同法外，还涉及：
- 国际贸易术语（Incoterms 2020）
- 海关 / 商检 / 外汇管制
- 出口管制 / 制裁名单
- 跨境支付 / 信用证 / 保理

---

## 必查核心条款（13 类）

### 1. 贸易术语（Incoterms 2020）

**审查要点**：
- 明确约定贸易术语：EXW / FOB / CIF / DAP / DDP 等
- 贸易术语决定：风险转移点 + 费用承担 + 手续办理

**Incoterms 2020 11 种术语**：
- **EXW（Ex Works）**：工厂交货，买方承担几乎所有费用和风险
- **FCA（Free Carrier）**：货交承运人
- **FOB（Free On Board）**：装运港船上交货（仅适合海运/内河）
- **CFR（Cost and Freight）**：成本加运费（仅适合海运/内河）
- **CIF（Cost, Insurance and Freight）**：成本+保险费+运费（仅适合海运/内河）
- **CPT（Carriage Paid To）**：运费付至
- **CIP（Carriage and Insurance Paid To）**：运费保险费付至
- **DAP（Delivered At Place）**：目的地交货
- **DPU（Delivered at Place Unloaded）**：目的地卸货后交货（Incoterms 2020 新增）
- **DDP（Delivered Duty Paid）**：目的地完税后交货
- **FAS（Free Alongside Ship）**：船边交货

**典型问题**：
- ❌ "卖方负责运到买方指定地点"——未明确贸易术语
- ✅ 应明确：使用 Incoterms 2020 + 具体术语 + 适用版本年份

**法条依据**：
- 《国际贸易术语解释通则》（Incoterms 2020，ICC 制定，2020.01.01 生效）

### 2. 风险转移

**审查要点**：
- 风险转移点与贸易术语一致
- 货物灭失或损毁的责任归属
- 风险转移后的通知义务

### 3. 单证交付

**审查要点**（CIF/CFR 必须）：
- 商业发票（Commercial Invoice）
- 装箱单（Packing List）
- 提单 / 空运单（Bill of Lading / Air Waybill）
- 原产地证（Certificate of Origin）
- 保险单（Insurance Policy，CIF/CIP 必须）
- 商检证 / 品质证 / 重量证
- 装运通知（Shipping Advice）

**典型问题**：
- ❌ "卖方提供必要单证"——范围不明
- ✅ 应明确：单证清单 + 交付时间 + 交付方式

### 4. 支付方式

**审查要点**：
- **T/T（电汇）**：预付 / 货到付 / 比例付款
- **L/C（信用证）**：最常用的国际贸易支付方式
  - 即期 / 远期
  - 议付 / 承兑
  - 软条款风险（必须警惕）
- **D/P（付款交单）**
- **D/A（承兑交单）**
- **O/A（赊销）**：风险最高

**典型问题**：
- ❌ "买方通过信用证付款"——未约定信用证类型、有效期、议付行
- ✅ 应明确：信用证类型 + 有效期 + 最晚装船期 + 议付行 + 软条款禁止

**法条依据**：
- 《UCP 600》（跟单信用证统一惯例）
- 《URDG 758》（见索即付保函统一规则）

### 5. 出口管制 / 制裁名单

**审查要点**（🔴 高风险）：
- 货物是否属于**两用物项**（军民两用）？
- 是否涉及**出口管制清单**（《出口管制法》第 4 条）？
- 买方 / 最终用户 / 最终用途是否在**制裁名单**？
- 俄罗斯 / 伊朗 / 朝鲜 / 古巴等受制裁国家的合规

**法条依据**：
- 《出口管制法》第 4 条（管制清单）
- 《不可靠实体清单规定》
- 《阻断不当域外适用法律措施办法》

**典型问题**：
- ❌ 货物受出口管制但未申请许可证 → 行政处罚 + 刑事责任
- ❌ 与受制裁实体交易 → 罚款 + 列入不可靠实体清单

### 6. 海关手续与关税

**审查要点**：
- 报关主体（卖方 vs 买方）
- 关税承担（贸易术语决定）
- HS 编码的认定
- 原产地证的办理
- 进口国关税 / 反倾销税

### 7. 商检 / 检疫

**审查要点**：
- 法定检验（CIQ 出具的检验证书）
- 第三方检验（SGS / BV / Intertek 等）
- 动植物检疫（涉及动植物产品的）
- 食品 / 化妆品 / 医疗器械的注册备案

**法条依据**：
- 《食品安全法》第 92 条（进口食品检验检疫）
- 《进出境动植物检疫法》

### 8. 包装与唛头

**审查要点**：
- 包装方式（适合长途海运 / 空运）
- 唛头（Shipping Mark）的标注
- 危险品包装的特殊要求
- 环保包装要求（进口国法规）

### 9. 装运条款

**审查要点**：
- 装运期（Shipping Date）
- 装运港 / 目的港（明确具体港口）
- 装运方式（海运 / 空运 / 多式联运）
- **转运 / 分批装运**（Transshipment / Partial Shipment）的允许

**典型问题**：
- ❌ "尽快装运"——时间不明
- ✅ 应明确：装运期（具体日期或月份）+ 是否允许分批 + 是否允许转运

### 10. 保险

**审查要点**：
- 保险险别（CIF/CIP 卖方必须投保 ICC A 或 ICC C）
- 保险金额（通常发票金额的 110%）
- 保险范围（一切险 vs 平安险 vs 水渍险）
- 投保人 + 受益人

**法条依据**：
- 《ICC 货物保险条款》（Institute Cargo Clauses A/B/C，2009 版）

### 11. 不可抗力

**审查要点**（跨境贸易特殊）：
- 国际通用不可抗力条款参考：**《联合国国际货物销售合同公约（CISG）》第 79 条**
- 战争 / 禁运 / 罢工 / 港口封闭等
- 通知义务与证明（需提供商会证明）

**典型问题**：
- ❌ 仅引用中国《民法典》——CISG 适用时建议同时引用
- ✅ 应明确：① 不可抗力定义 ② 通知期限 ③ 证明文件 ④ 后果（部分履行 / 解除）

### 12. 争议解决与法律适用

**审查要点**（🔴 跨境最关键）：
- **法律适用**（重要！）：
  - 中国当事人之间 → 可选中国法律或外国法律
  - 含外资当事人 → 谨慎选择法律适用
  - 《法律适用法》第 41 条（合同法律适用）
- **争议解决**：
  - **中国国际经济贸易仲裁委员会（CIETAC）**：最常用
  - **香港国际仲裁中心（HKIAC）**
  - **新加坡国际仲裁中心（SIAC）**
  - **国际商会仲裁院（ICC）**
- **CISG 的适用**：
  - 中国 1988 年加入 CISG，**默认适用**
  - 当事人可书面排除（《民法典》第 504 条）

**典型问题**：
- ❌ 未约定法律适用 → 默认适用 CISG + 中国法律
- ❌ 约定中国法院管辖 → 外国当事人执行困难
- ✅ 应明确：① 法律适用 ② 仲裁机构 + 仲裁规则 ③ 仲裁地 ④ 仲裁语言

**法条依据**：
- 《法律适用法》第 41 条（合同法律适用）
- 《承认及执行外国仲裁裁决公约》（《纽约公约》）

### 13. 知识产权与平行进口

**审查要点**：
- 知识产权归属
- 平行进口的合法性（中国原则允许，但商标权可主张"权利用尽"抗辩）
- 目的地国家的商标注册（避免商标侵权）

**法条依据**：
- 《商标法》第 57 条（侵权认定）
- 《专利法》第 11 条

## 高风险条款 TOP 10

1. **出口管制货物未申请许可证** → 行政处罚 + 刑事责任
2. **与受制裁国家/实体交易** → 列入不可靠实体清单
3. **信用证软条款** → 卖方无法议付
4. **贸易术语未明确** → 风险转移争议
5. **法律适用未约定** → 默认适用 CISG，可能非预期
6. **选择对中国不友好的争议解决地** → 执行困难
7. **保险险别不符（CIF 用 ICC C 而非 A）** → 保险范围不足
8. **装运期过紧** → 无法按时交货
9. **外汇管制条款缺失** → 跨境收款困难
10. **原产地证条款缺失** → 关税成本增加

## 使用方法

主 agent 在 Step 1 阶段：
1. 加载本清单 + `references/clause-checklist.md`
2. **优先核实出口管制 / 制裁名单合规**（决定合同能否履行）
3. 重点关注贸易术语 + 支付方式 + 法律适用 + 争议解决
4. 涉外合同另需参考 `references/law-sources.md`（CISG / UCP 600）
