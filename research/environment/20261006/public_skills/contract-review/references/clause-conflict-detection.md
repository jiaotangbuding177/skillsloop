# 条款冲突检测规则集

> **定位**：纯法律视角的条款间逻辑一致性分析，**不涉及商业意图的合理性判断**。
> **核心输出**：冲突清单（含冲突类型、位置、风险等级、修改建议）。

---

## 1. 冲突类型清单（7 大类）

### 类型 1：违约责任 vs 免责条款冲突

**典型场景**：
- 条款 A：`乙方未按时交付的，应支付合同总价 30% 的违约金`
- 条款 B：`因不可抗力导致乙方无法履约的，乙方不承担违约责任`

**冲突点**：
- B 是否覆盖了 A 的所有违约情形？
- 若 B 仅豁免"不可抗力"，则不冲突；若 B 额外豁免"乙方合理理由"则冲突

**检测方法**：
1. 提取所有违约责任条款（关键词：违约金、违约责任、罚则、滞纳金、赔偿）
2. 提取所有免责条款（关键词：免责、不承担责任、不视为违约、除外责任）
3. 列举违约情形集合 X 与免责情形集合 Y
4. 若 Y 包含 X 之外的额外情形 → 冲突

**风险等级**：🔴 高

**法条依据**：《民法典》第 590 条（免责条款效力）+ 第 1175 条（损失赔偿范围）

---

### 类型 2：争议解决方式冲突

**典型场景**：
- 条款 A：`本合同争议提交 XX 仲裁委员会仲裁`
- 条款 B：`本合同争议由 XXX 人民法院管辖`

**冲突点**：
- 仲裁与诉讼**互斥**（"或裁或审"原则）
- 同时约定两个 → 程序无效

**检测方法**：
1. 全文搜索"仲裁"关键词
2. 全文搜索"法院/管辖/诉讼"关键词
3. 若两者同时存在 → 冲突
4. 检查仲裁机构是否明确（仅说"仲裁"未指明机构 → 效力瑕疵）

**风险等级**：🔴 高

**法条依据**：《仲裁法》第 16 条（有效仲裁协议要件）

**司法实践**：仲裁条款无效时按一般管辖规则确定法院（最高法相关司法解释）

---

### 类型 3：法律适用 vs 强制性规定冲突

**典型场景**：
- 条款 A：`本合同适用香港特别行政区法律`
- 条款 B（实际条款）：涉及中国大陆境内不动产物权登记

**冲突点**：
- 不动产物权、婚姻家庭、消费者权益等领域属**强制性规定**，不允许约定排除
- 合同自由受法律强制性规定限制

**检测方法**：
1. 提取法律适用条款（关键词：适用法律、准据法、governing law）
2. 识别合同所涉领域：劳动、消费者、不动产、跨境数据、垄断
3. 比对约定法律 vs 强制适用法律
4. 若合同涉及中国大陆强制性规定领域且约定外国法律 → 冲突

**风险等级**：🔴 高

**法条依据**：《法律适用法》第 3 条（强制性规定直接适用）+ 第 36 条（不动产）+ 第 43 条（劳动合同）

---

### 类型 4：生效条件冲突

**典型场景**：
- 条款 A：`本合同自双方签字盖章之日起生效`
- 条款 B：`本合同自双方签字且经公证之日起生效`

**冲突点**：
- 多版本生效条件并存时，何者优先？

**检测方法**：
1. 全文搜索"生效"、"自...起生效"、"经...生效"
2. 列举所有生效条件
3. 若多个条款对生效条件规定不同 → 冲突
4. 特殊情形：批准/备案生效条件未满足 → 合同效力待定

**风险等级**：🟡 中

**法条依据**：《民法典》第 502 条（依法成立的合同自成立时生效）+ 第 136 条（生效条件）

---

### 类型 5：金额/数字/比例冲突

**典型场景**：
- 条款 A：`预付款 30%`
- 条款 B：`预付款 50%`

**冲突点**：
- 同一事项在不同条款中数字不一致 → 解释争议

**检测方法**：
1. 全文提取数字 + 百分比 + 比例
2. 对同一标的（如"预付款比例"）跨条款比对
3. 若同一标的数字不一致 → 冲突
4. 特殊：累计比例 ≠ 100%（参见 financial-amounts.md）

**风险等级**：🟡 中

**法条依据**：《民法典》第 142 条（意思表示解释规则）

---

### 类型 6：定义 vs 使用不一致

**典型场景**：
- 条款 A（定义）：`"服务"指甲方提供的技术支持、运维支持、培训`
- 条款 B（使用）：`乙方的服务包括但不限于上述技术支持、运维支持、培训，及乙方额外提供的咨询服务`

**冲突点**：
- 定义范围被扩大或缩窄 → 权利义务范围不一致

**检测方法**：
1. 提取"定义"章节所有定义项
2. 全文搜索每个定义项名称
3. 比对使用语境 vs 定义范围
4. 若使用范围超出定义范围 → 冲突

**风险等级**：🟡 中

**法条依据**：《民法典》第 142 条 + 第 466 条（合同解释规则）

---

### 类型 7：附件 vs 主合同冲突

**典型场景**：
- 主合同：`违约金为合同总价 20%`
- 附件 A：`违约金为合同总价 30%`

**冲突点**：
- 主从条款冲突时，**附件优先**（若主合同明确约定"附件优先"）或**主合同优先**（若附件未明确）
- 部分情形：构成"实质性变更"需重新协商

**检测方法**：
1. 识别主合同条款
2. 识别附件/补充协议/订单/SOW 条款
3. 提取同一事项的约定
4. 比对数字、比例、责任
5. 检索主合同是否有"附件优先"约定

**风险等级**：🟡 中

**法条依据**：《民法典》第 490 条（约定优先）+ 第 510 条（合同约定不明时的确定规则）

## 2. 冲突风险等级总览

| 冲突类型 | 风险等级 | 影响 | 紧迫性 |
|---|---|---|---|
| 类型 2（争议解决） | 🔴 高 | 程序无效，可能丧失管辖 | 签约前必须解决 |
| 类型 3（法律适用 vs 强制） | 🔴 高 | 合同效力风险 | 签约前必须解决 |
| 类型 1（违约 vs 免责） | 🔴 高 | 执行风险 | 签约前必须解决 |
| 类型 5（数字冲突） | 🟡 中 | 解释争议 | 谈判中力争解决 |
| 类型 6（定义 vs 使用） | 🟡 中 | 解释争议 | 谈判中力争解决 |
| 类型 4（生效条件） | 🟡 中 | 效力风险 | 谈判中关注 |
| 类型 7（附件 vs 主合同） | 🟡 中 | 解释风险 | 谈判中关注 |

## 3. 检测方法学

### 3.1 自动检测（脚本可处理）

| 检测项 | 技术手段 | 实现难度 |
|---|---|---|
| 数字比对 | 数字 + 上下文实体识别 | 中 |
| 争议解决关键词 | 正则 + 关键词组合扫描 | 低 |
| 法律适用条款 | 关键词提取 | 低 |
| 生效条件关键词 | 关键词提取 | 低 |
| 条款定位 | 段落结构解析 | 中 |

### 3.2 半自动检测（需人工确认）

| 检测项 | 需确认内容 |
|---|---|
| 强制性规定领域 | 是否属于劳动/不动产/消费者 |
| 违约 vs 免责覆盖范围 | 律师判断 |
| 定义范围扩张/缩窄 | 律师判断 |
| 实质性变更 | 是否属于实质性变更 |

### 3.3 人工审查（必须人工）

- 冲突是否真的构成"法律冲突"（vs 仅是"模糊"）
- 修改建议的法律可行性
- 条款背后真实商业意图的还原

## 4. 输出格式

### 4.1 冲突清单（JSON）

```json
{
  "conflicts": [
    {
      "conflict_id": "CONF-001",
      "type": "争议解决方式冲突",
      "clause_a": {
        "no": "第 15 条",
        "text": "本合同争议提交北京仲裁委员会仲裁",
        "para_index": 47
      },
      "clause_b": {
        "no": "第 16 条",
        "text": "本合同争议由北京市朝阳区人民法院管辖",
        "para_index": 49
      },
      "description": "同时约定仲裁和法院管辖，程序法上互斥",
      "risk": "high",
      "law_basis": "《仲裁法》第 16 条",
      "consequence": "仲裁条款可能无效，按一般管辖确定法院",
      "suggestion": "删除第 16 条法院管辖约定，仅保留第 15 条仲裁条款"
    }
  ]
}
```

### 4.2 Word 文档呈现

- 在冲突的两个条款处**双侧插入**批注（指向对方）
- 末尾附录用表格汇总全部冲突
- 冲突间使用**双向链接**（批注 A 提到"参见 CONF-002"，批注 B 反向链接）

## 5. 工具调用建议

### 优先工具
- **fyopen-lawsearch**：查类案裁判规则
- **pkulaw**：查强制性规定领域识别
- **regular expression / pattern matching**：自动扫描

### 辅助工具
- **python-docx / officecli**：批注双向插入
- **neo-crm / qcc-company**：识别主体类型（决定适用法律）

### 不建议调用
- 不调商业分析工具（违反"纯法律视角"边界）
- 不调舆情工具（不在冲突检测范围）

## 6. 边界声明

本文档**不评估**：
- 条款"是否合理"在商业上的判断
- 议价空间分析
- 关系管理建议

本文档**只评估**：
- 条款间的**逻辑一致性**
- 条款与**法律强制性规定**的一致性
- 条款触发后的**法律后果一致性**
