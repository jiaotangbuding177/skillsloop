# Memory Policy

Use memory to capture durable preferences from real usage.

## Record

- One-sentence user preference from direct feedback.
- Stable output format decisions.
- Repeated correction patterns.

## Do Not Record

- Guesses about what the user might prefer.
- One-off details that do not apply to future uses.
- Secrets, tokens, personal data, or private manuscript content.

## Template

```text
# Memory

Record one-sentence learnings from real user feedback.

## Learnings

- No stored preference yet.
```
