# No-Service Troubleshooting Checklist

Run checks in order; confirm the result of each before the next.

1. Account/billing: any Overdue bill tied to the affected line? Contract still active?
2. Reboot device; re-check service.
3. Airplane Mode: ask user to turn it OFF; re-check.
4. SIM state: check whether it reports present/missing/locked. If missing, reseat the SIM; re-check.
5. Network status: airplane mode, SIM card status, cellular connection, signal, network type, mobile data, roaming, Wi-Fi.
6. Interpret: locked_pin / PUK lock, or other security block => outside self-service scope, escalate.

Escalation summary must contain: customer id, affected line id/number, root cause, steps already taken, current device/network state, expertise required.

Guardrail: never state the issue is resolved unless a tool result or the user confirms the new state.
