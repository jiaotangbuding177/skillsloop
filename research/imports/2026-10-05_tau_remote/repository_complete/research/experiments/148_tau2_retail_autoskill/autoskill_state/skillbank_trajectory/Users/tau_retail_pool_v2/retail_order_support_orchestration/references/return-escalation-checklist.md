# Return/Refund Escalation Checklist
- [ ] Confirm item(s) and refund destination with the customer.
- [ ] Collect and echo back the order ID.
- [ ] Obtain explicit confirmation before the write.
- [ ] Call the return tool once; never fabricate IDs.
- [ ] On 'Order not found': apologize, ask to re-verify, retry at most once.
- [ ] On continued failure: offer human-agent transfer and get consent.
- [ ] Execute transfer with a factual summary; confirm to the customer.
- [ ] Never claim completion without a tool success.
