# 067 当前真实会话与待核验数量口径

用户要求简要说明真实会话总数和仍有问题的会话数。本轮复核066统计与逐会话清单，没有新增语义匹配、模型调用或清理操作。

当前主集1,466条真实企业用户历史会话。综合核验505条：85条存在AI正文无法确定对应用户输入，另420条没有未归属AI但存在用户输入暂无对应AI。剩余961条在当前候选对应结果中两侧均无未配项，不等于全部匹配正确或真实时序已经证明。

85属于505的子集，不能相加。505也不能统称顺序错乱：用户暂无对应AI可能来自空AI移除、导出缺失或匹配不足，原因不能仅凭统计确定。19条内部用途与39条只有元数据的会话不计入1,466主集。

来源：`research/datasets/evomind/matched_066/summary.json`、`private/conversation_inventory.json`、066记忆。本轮无新增实证发现，仅复核既有产物并明确互斥计数；独立语义准确率和真实时序仍未知。
