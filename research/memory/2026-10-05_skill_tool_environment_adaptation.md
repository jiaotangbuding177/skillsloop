# 工具环境适配与KM源码必要性

日期：2026-10-05。

用户希望本地环境适配实际技能工具（例如LibreOffice），询问是否一定需要kmagent源码。本轮讨论和静态核对，无软件安装、运行器修改、模型调用或案例实验。

结论：独立Demo通常无需完整KM源码，优先实际技能包、依赖版本、环境镜像/构建说明、工具输入输出契约及专属服务接口。专属能力没有可用接口或兼容实现时可能阻塞；精确复刻KM内部逻辑不能靠当前证据保证。

证据：runtime.py配置已允许read/write/edit/exec/process等；配置不证明依赖/服务可用。LibreOffice官方支持无界面命令行转换，Windows控制台可用soffice.com，需可写用户配置目录。已有81技能统计不是完整工具库存；全量工具日志缺口保持。

建议：工具协议、本地程序库、环境、私有服务四层分别盘点；按合同审查文档交付小范围适配，Linux依赖较多时考虑冻结Linux执行环境。验收覆盖程序检测、小文件、中文排版、Agent真实交付和可重复运行。方法对比固定工具环境，环境故障不冒充算法劣势。

未知：本机实际安装、KM镜像和锁文件、完整依赖及服务配置未核实。本轮无新增实证发现。
