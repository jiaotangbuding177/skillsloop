# 001｜科研立项与工作规范初始化

日期：2026-09-18。

## 本轮问题

将用户的研究目标与工作规范持久化，确保后续对话和工作沿着企业 skills 完整闭环推进。本轮不进行系统研究或实现。

## 用户已确认的要求

来源：本轮用户原始指令。

> 本项目是科研项目，禁用开发相关的skills链路，开发规则，采用科研相关skills，除非我显式要求指出进行开发，否则一概禁用，走科研路线。

> 每一轮洞察和发现都有记录成md记忆进行沉淀，以防后续丢失。

用户确认的业务和论文目标：基于已有系统，从企业用户会话发现重要 / 高频任务，自动总结可复用 skills；用户自主选择纳入个人库或提交组织库；后续选取使用，每次使用后支持自进化，形成企业级闭环，对标 WWW Industry Track 发表论文。

用户限定本轮只做立项初始化，后续不偏离主线。

## 本轮实际工作与依据

- 读取 `research-experiment-compass` 科研技能，采用证据、假设区分及研究记录原则。技能中的其他项目目标不覆盖本项目用户目标。
- 使用 FastCtx 检索当前目录的项目入口和文件，未检索到匹配文件。该观察仅描述本次检索结果，不代表用户所述已有系统不存在。
- 新建 `AGENTS.md`、`research/README.md`、`research/CHARTER.md`、`research/STATE.md` 和本记录。
- 未检索文献、未核验会议要求、未运行实验、未修改系统代码。

## 洞察与发现

- **需求澄清，依据为用户描述**：研究对象是完整生命周期，不应未经确认收窄为单独的生成算法、检索系统或通用开发平台。
- **待研究区分**：重要性与频率、对话摘要与可复用 skill、使用后触发演化与每次强制改写，分别需要定义，当前没有实证结论。
- **未知**：已有系统和数据条件、创新机制、性能收益以及投稿契合度尚未核实。
- **实证状态**：本轮无新增实证发现。

## 决策

1. 以根目录 `AGENTS.md` 固定科研优先规则和开发显式授权边界。
2. 以章程维护稳定主线，以状态文件维护当前有效判断，以逐轮 Markdown 记忆保留历史及更正。
3. 暂不选择算法、不定义未经讨论的指标阈值、不宣称创新或 SOTA；先把不确定项显式保留。
4. 不启动任何后续研究或开发动作，等待用户下一步指令。
