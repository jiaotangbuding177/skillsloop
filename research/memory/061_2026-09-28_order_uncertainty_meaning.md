# 061 顺序待核验的含义澄清

- 用户询问060第三条会话的顺序是否不一定正确。本轮解释：是，当前显示顺序可能不同于实际发生顺序；不是已经证明整条会话错乱。
- 依据059审计及060样例：原包消息日期不可用，新包仅用户日期；原导出行序与数字编号排序不一致，且用户时间与编号存在冲突。msg_N的事件序语义仍未证实。
- 正文完整性与时间顺序正确性是两项不同性质的核验。060已验证原消息和正文保留，不代表已验证回复归属；展示分组也可能受排序影响。
- 第三条存在明确排序依据冲突；前两条没有因此自动获得完整时间线已核验的资格。样例可阅读核对，不宜直接当作已确认的任务轨迹或回复关系评测真值。
- 后续建议核验上游消息序号含义或取得可靠的完整消息时间／原始历史列表顺序；未知前不由模型补造历史。此为建议，未执行新增数据接入。
- 本轮无新增实证发现，无数据改写或实验。来源：[060说明](../datasets/evomind/preview_060/README.md)、[059审计](../reports/059_evomind_conversation_order_audit.md)。
