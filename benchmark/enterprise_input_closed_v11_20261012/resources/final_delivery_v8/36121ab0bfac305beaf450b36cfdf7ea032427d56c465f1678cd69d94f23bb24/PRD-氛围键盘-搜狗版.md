## 3. 背景

### 为什么是搜狗

搜狗输入法皮肤平台是中国第三方输入法中规模最大、生态最成熟的：

| 指标 | 数据 |
|------|------|
| 市场占有率 | **42.3%**（第一，遥遥领先） |
| 用户规模 | 月活约6亿 |
| 皮肤平台 | 2007年创立，近20年历史 |
| 皮肤总数 | **10万+** |
| 注册作者 | **3万+** |
| 年总下载量 | **百亿次** |
| 创作者机制 | 开放注册、版权归作者、支持打赏 |
| 动效支持 | Flash动画 + Lottie JSON |
| 2026年 | 鸿蒙版上线皮肤商城，AI深度集成 |

### 市场空白

**搜狗皮肤库没有"动态响应式"皮肤。** 当前所有皮肤都是被动式的——用户下载什么就是什么，不会根据打字输入发生任何变化。这是一个明确的竞争空白。

### 2026年最大的机会

搜狗输入法20.0版全面接入腾讯混元大模型，AI能力大幅升级（AI帮写、AI陪伴、AI搜索），但**AI能力与皮肤之间的联动完全空白**。我们的"氛围键盘"可以成为搜狗首个将AI语义能力与皮肤视觉联动的产品。

## 6. 解决方案

### 6.1 核心机制

```
用户打字 → 关键词命中 → 氛围切换 → ssf皮肤状态更新 → 动效呈现
                ↑
      全部本地处理，零网络请求
```

### 6.2 氛围状态（V1）

| 氛围名 | 关键词示例 | 配色 | Lottie动效 |
|--------|-----------|------|-----------|
| ☀️ **灿烂** | 太棒了/绝了/开心/哈哈哈/好喜欢/超爱 | 暖金→蜜桃渐变 | 按键星点闪烁 |
| 🌧️ **雨歇** | 累了/困了/emo/难受/算了/有点烦 | 薰衣草紫→雾蓝 | 柔光波浪流淌 |
| 🍃 **微风** | 好美/感动/真好/舒服/太暖了 | 薄荷绿→淡粉 | 边缘微光呼吸 |
| 🌙 **静夜** | 晚安/睡了/好梦/zzZ | 深海蓝→星紫 | 按键渐暗暖光 |
| 🔥 **燃** | 冲啊/加油/必胜/拼了/不服 | 炽红→焰橙 | 底部微焰粒子 |
| ◻️ **日常** | （默认态） | 灰蓝极简 | 无动效 |

### 6.3 隐私与品牌（A+C方案）

**品牌名**：氛围键盘 / 打字氛围灯（❌ 不叫"情绪皮肤"）

**隐私设计**：
- 关键词库打包在ssf文件中，纯本地匹配，**零网络请求**
- 设置页文案不出现"情绪""识别""监控"等字眼
- 品牌Slogan：「一个会呼吸的键盘」

### 6.4 技术方案（搜狗ssf格式）

搜狗皮肤格式为ssf（基于zip压缩），包含：
- `config.ini`：皮肤配置（尺寸、按键位置、配色参数）
- `png图像资源`：按键、背景、候选栏等切图
- `Lottie json`：动效文件（搜狗支持Lottie动画）

| 事项 | 说明 |
|------|------|
| 皮肤格式 | ssf（zip压缩包） |
| 制作工具 | 搜狗皮肤编辑器 + Photoshop/Figama |
| 动效格式 | Lottie JSON（行业标准，百度也有Lottie能力） |
| 每套容量 | 约1-3MB（含Lottie动效） |
| 关键词匹配 | 配置在皮肤中，本地触发（非应用内置，需通过皮肤预设实现） |

> **关于"动态切换"的技术实现说明：** 搜狗皮肤本身不支持运行时代码逻辑。氛围切换需要通过**预设多个静态皮肤版本 + 打包成多状态皮肤包**来实现。用户下载后，皮肤包内置6套静态变体配置，根据预先设定的关键词→状态映射做本地切换。这是目前搜狗皮肤技术框架下最可行的实现方式。

## 7. 发布流程

搜狗皮肤开放平台的上线流程：

```
① 注册搜狗开放平台账号（QQ/微博/搜狗通行证）
② 完善个人资料（头像、昵称、简介）
③ 使用皮肤编辑器 + Figma 产出设计稿
④ 制作ssf皮肤包（配置+切图+Lottie）
⑤ 上传至开放平台 → 等待审核（≤2天）
⑥ 审核通过 → 自动上架搜狗皮肤商城
⑦ 开放打赏功能（绑定银行卡信息）
⑧ 申请商城首页推荐位（联系搜狗运营）
```

### 关键优势

- ✅ **不需要签约** — 个人账号即可上传
- ✅ **版权归你** — 搜狗不像百度那样抢版权
- ✅ **有打赏机制** — 用户可直接打赏创作者
- ✅ **设计排行榜** — 优秀作品被平台推荐
