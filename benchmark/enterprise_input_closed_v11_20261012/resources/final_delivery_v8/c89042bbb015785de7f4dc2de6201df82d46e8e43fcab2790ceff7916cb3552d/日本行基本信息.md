| **電話** | 03-3841-4686 |

| **可預約** | ✅ 可以電話預約 |

**小明補充情報：**
- 🏆 昭和17年（1942年）創業，已傳承至第四代，超過80年老店
- 🍞 **只賣兩種麵包**：吐司（食パン）和餐包（ロールパン），不做花哨款式
- 📖 曾拍成紀錄電影《淺草的幸福吐司》

- 🕐 強烈建議**開門就衝**或提前預約，以免完售撲空
- 💰 價格：一整條吐司約在1,000日圓以內

**Tips（你給的+我搜的）：**
1. 不要太晚去買，會撲空
2. 1.5斤/條，切厚片約可切7片
3. 小麵包是一樣的東西，只是形狀不一樣
4. 距離店家約300-400公尺有自營咖啡店
5. ⚠️ **只收現金**，帶夠錢
6. 可以先電話預約再過去取

### 2. 五代目 花山うどん 日本橋店（Godaime Hanayama Udon）

**东京最难排的乌冬面，没有之一。**

| 项目 | 详情 |
|------|------|
| **评级** | Tabelog 3.59 · 乌冬面天下一决定战三年连冠🏆 |
| **地址** | 〒103-0027 東京都中央区日本橋2-10-12 プレリー日本橋ビル 1F |
| **交通** | 東京メトロ銀座線/東西線「日本橋駅」C4出口 徒步2分／JR東京駅 徒步8分 |
| **电话** | 03-6910-3808 |
| **预算** | 午餐 ¥1,000～¥2,000 / 晚餐 ¥2,000～¥3,000 |
| **付款** | ✅ 信用卡可 · 電子マネー可（Suica等）· ❌ QR碼支付不可 |
| **座位** | 40席（吧台16+桌20），有半包间 |

**营业时间（重要！）：**
| | 午餐 | 晚餐 |
|--|------|------|
| **平日（月-金）** | 11:00–15:30（L.O.15:00） | 17:30–21:30（L.O.21:00）|
| **土日祝** | 11:00–16:00（L.O.15:30） | ❌ 不营业 |
| **定休日** | 無（全年無休）※但麺切れ即終了 | |

**小明补充情报：**
- 🏅 最招牌的是 **「鬼ひも川」**（Oni Himokawa）——宽5cm的扁宽乌冬面，口感Q弹爽滑，像宽面版拉扎尼亞
- 🏆 **日本一×3**：在「乌冬面天下第一决定战」实现三年连霸
- 🍜 **日本橋店限定**「花山七宝つゆ」——7种蘸汁自由选（伝承つゆ/胡麻つゆ/旨だしカリーつゆ等）
- 🏛️ **130年+的历史**：创业明治27年（1894年），群馬・館林发源
- 🛍️ **本店有伴手礼专区**：可以买包装好的面条和特制つゆ回去，还提供寄送服务
- 🍶 **晚餐很值得**：除了乌冬还有赤城牛熔岩焼き、鬼ひも川焗烤等配酒菜，群马地酒也很丰富

**Tips（你给的+我搜的）：**
1. 🕐 错峰来吃，别赶中午12点高峰期
2. ⚠️ 日本橋是本店，有银座分店。但**银座店中午12点面就可能卖完**，本店稳一点
3. ✅ **平日晚餐可以电话预约**，建议预约免排队
4. 🔖 取号制→到店先在店内取**番号札（号码牌）**
5. 🍚 推荐加一份「小釜めし」（海老天or上州五目），用乌冬出汁煮的釜饭
6. 店内装饰非常美——整面墙绘有群馬館林つつじ（杜鹃花）公园的壁画 + 七宝组子细工
