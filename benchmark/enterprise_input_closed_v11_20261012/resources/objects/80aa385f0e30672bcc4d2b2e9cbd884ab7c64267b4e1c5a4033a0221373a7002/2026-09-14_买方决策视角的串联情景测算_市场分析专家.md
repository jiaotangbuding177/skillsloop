# 买方决策视角的串联情景测算_市场分析专家

实验合成输入：依原用户请求与文件名推断用途；不是原企业文件，不构成真实政策、人物履历或公开论文。

## 生产计划与数据口径

买方决策视角的串联情景测算_市场分析专家记录合成产品的物料需求。单套用量乘以计划套数为需求数量；可用库存不包含已锁定库存，在途数量需结合到货日期判断。

## 物料与供应商

物料包括控制板、电源模块、传感器、连接线、安装支架等。每个物料编码唯一，规格型号与供应商记录保持一一对应，不同批次可以具有不同交期。

## 仓储规则

库存盘点以本次生成数据为输入快照。现有库存可能无法覆盖全部需求；尚未到货的采购不能当作已经入库。实验中由 agent 实际完成缺料、齐套或采购计算。

## 业务条件

同一套产品需同时具备全部必要物料。急件可采用分批到货；替代物料须经过技术确认，不默认按相同数量替换。
