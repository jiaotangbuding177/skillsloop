# 技术开发合同专项审查清单 · Technology Development Contract

> **法条依据**：《民法典》第 844-870 条（技术合同）+ 《专利法》第 26 条（职务发明）+ 《著作权法》第 11-18 条 + 最高人民法院《关于审理技术合同纠纷案件适用法律若干问题的解释》（2020 修订）

---

## 技术开发合同核心特征

**典型类型**：
- **委托开发**（甲方委托乙方研发）：成果归甲方（《民法典》第 847 条）
- **合作开发**（双方共同研发）：成果共有（《民法典》第 848 条）
- **技术成果转化**：技术成果的许可、转让

**核心法律关系**：技术成果的 IP 归属 + 开发失败的责任 + 技术指标的认定

---

## 必查核心条款（12 类）

### 1. 合同性质（委托 vs 合作）

**审查要点**：
- 合同性质决定 IP 归属默认规则：
  - 委托开发 → 成果归委托方（甲方），除非约定归受托方（《民法典》第 847 条）
  - 合作开发 → 成果共有，按贡献比例分配（《民法典》第 848 条）
- 是否明确约定"委托开发"还是"合作开发"

**法条依据**：
- 《民法典》第 847 条（委托开发成果归属）
- 《民法典》第 848 条（合作开发成果共有）

**典型问题**：
- ❌ 合同性质模糊 → 成果归属争议
- ✅ 应明确：合同性质 + IP 归属 + 共有比例

### 2. 技术成果 IP 归属

**审查要点**：
- **背景 IP**（双方在合同签订前已拥有的 IP）：各自所有
- **前景 IP**（合同履行过程中产生的 IP）：按合同性质归甲方或共有
- **衍生 IP**：基于背景 IP 产生的改进，归谁？
- **第三方 IP 侵权责任**：谁提供 IP 谁负责

**法条依据**：
- 《民法典》第 847-850 条
- 《专利法》第 26 条（职务发明）
- 《著作权法》第 11-18 条

**修改建议模板**：
> "1. **背景 IP**：各方各自拥有本合同签订前已形成的 IP。
> 2. **前景 IP**：本合同项下产生的全部 IP 归甲方所有；乙方对前景 IP 享有署名权（如适用）。
> 3. **衍生 IP**：基于乙方背景 IP 产生的衍生 IP，由双方共有，按贡献比例分配收益。
> 4. **第三方侵权**：由提供 IP 一方承担全部赔偿责任。"

### 3. 技术指标与验收标准

**审查要点**：
- 技术指标的**量化**（性能参数 + 测试方法）
- 验收标准（功能完整性 / 性能 / 兼容性）
- 验收程序（初验 / 复验 / 终验）
- 未达标的后果（整改 + 再次验收 + 解除 + 退款）

**典型问题**：
- ❌ "达到甲方满意"——主观标准，争议空间极大
- ❌ 技术指标无量化数据
- ✅ 应明确：① 量化指标 ② 测试方法 ③ 验收程序 ④ 未达标的处理

### 4. 里程碑与阶段交付

**审查要点**：
- 阶段划分（需求调研 / 方案设计 / 原型 / 开发 / 测试 / 上线）
- 每个里程碑的交付物清单
- 阶段验收的程序与期限
- 阶段付款与里程碑绑定

### 5. 技术人员安排

**审查要点**：
- 关键人员（项目经理 / 架构师 / 核心开发）锁定
- 人员变更程序（需委托方同意）
- 人员资质要求（学历 / 经验 / 认证）
- 离岗处理（知识产权交接）

**法条依据**：
- 《民法典》第 850 条（技术成果完成人的权利）

### 6. 技术资料与源代码交付

**审查要点**：
- 技术文档的范围（需求文档 / 设计文档 / 测试报告 / 用户手册）
- 源代码的交付（完整可编译代码 / 文档 / 编译环境）
- 数据库 / 配置文件 / 部署脚本
- 交付形式（电子 / 纸质 / Git 仓库）

**典型问题**：
- ❌ "乙方提供完整的技术资料"——范围不明
- ✅ 应明确：附件列出交付物清单（含格式 + 版本）

### 7. 后续维护与升级

**审查要点**：
- 维护期（质保期）时长
- 维护内容（Bug 修复 / 安全补丁 / 功能升级）
- 维护费的计算方式
- 升级的额外费用

### 8. 技术成果的发表与公开

**审查要点**：
- 乙方是否可以发表涉及项目内容的论文
- 发表前是否需经委托方审核
- 涉及商业秘密的技术成果的限制

**法条依据**：
- 《民法典》第 852 条（技术成果完成人署名权）

### 9. 风险责任

**审查要点**：
- **技术开发失败**的责任划分（乙方是否承担开发失败的全部责任？）
- **不可抗力**（技术路线变更、政策变化）
- **第三方因素**（原料供应、设备故障）
- 风险承担与违约金的关系

**法条依据**：
- 《民法典》第 855 条（技术开发失败的风险责任）

**典型问题**：
- ❌ "乙方对开发失败承担全部责任"——显失公平
- ✅ 应明确：因乙方原因失败 → 乙方责任；因技术客观原因失败 → 双方分担

### 10. 付款与发票

**审查要点**：
- 付款节点（签约 / 阶段 / 终验 / 维护期）
- 发票类型（增值税 6% 服务费发票 / 13% 货物销售发票——按性质）
- 税率认定（技术服务通常 6%，技术转让通常免税）

### 11. 保密与知识产权保护

**审查要点**：
- 技术资料的保密（**比一般合同保密更严**）
- 保密期限（建议合同终止后 3-5 年）
- 涉密人员的限制
- 保密技术措施（数据加密、访问控制）

**法条依据**：
- 《反不正当竞争法》第 9 条（商业秘密）

### 12. 争议解决

**审查要点**：
- 建议约定**仲裁**（技术争议保密 + 专业）
- 仲裁机构（北京仲裁委员会 / 上海国际仲裁中心 / 深圳国际仲裁院）
- 技术专家库的建立

---

## 高风险条款 TOP 10

1. **合同性质未明确（委托 vs 合作）** → IP 归属争议
2. **背景 IP / 前景 IP / 衍生 IP 未区分** → IP 流失
3. **技术指标无量化** → 验收争议
4. **验收标准"甲方满意"** → 主观判断争议
5. **开发失败责任完全由乙方承担** → 显失公平
6. **源代码未交付或交付不完整** → 甲方无法独立运维
7. **关键人员未锁定 + 变更程序缺失** → 项目中断风险
8. **维护期过短或缺失** → 后续维护无保障
9. **技术成果发表限制缺失** → 商业秘密泄露
10. **税率认定错误（6% vs 13%）** → 税务风险
