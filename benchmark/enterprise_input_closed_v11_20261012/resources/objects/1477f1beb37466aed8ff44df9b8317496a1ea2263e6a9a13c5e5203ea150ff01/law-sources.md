## 引用规范

### 法条引用格式

```
《[法律全称]》第 [X] 条 第 [X] 款
```

**示例**：
- ✅ 《中华人民共和国民法典》第 506 条
- ✅ 《民法典》第 585 条第 2 款
- ❌ "民法典 506"（过于简略，validate.py 会校验）

### 司法解释引用格式

```
最高人民法院《关于[解释名称]》第 [X] 条
```

**示例**：
- 最高人民法院《关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》第 47 条

### 案例引用格式

```
[案号] 最高法 / [省高院] 民申 / 民终 字 [年份] 第 [号] 号
```

**示例**：
- (2020) 最高法民申 1234 号
- (2021) 京民终 5678 号

## 使用方法

主 agent 在 Step 4 阶段：
1. 对每个风险条款，**优先**调用 fyopen-lawsearch 检索
2. 工具不可用时，回退到本文件预录的索引
3. 引用必须含**法律全称 + 条款号**
4. 必带检索时点（如"2026-08-06 检索"）
5. 高风险条款必带法条 + 案例（如有）

`validate.py` 校验项：
- [ ] 高风险条款引用具体法条（不接受"相关法律法规"）
- [ ] 法条引用格式正确（含法律全称 + 条款号）
- [ ] 引用时点不超过 6 个月前（数据时效性）
