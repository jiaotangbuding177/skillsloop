# 基础学习素材字段说明

这是本来源独立的教学知识库整理素材，不是原历史教学文件。关联基础学习资料.docx及学习活动原始记录.xlsx。

字段为匿名学习者、活动、时长分钟、题目数、答对数、答对率。时长单位分钟；题目数及答对数单位题；答对率为同一行答对数除以题目数。
四条原始活动分别为匿名甲6/10题8分钟、匿名乙8/10题10分钟、匿名丙7/10题9分钟、匿名丁9/10题12分钟。所有值均人为指定，无真实日期或学生身份。
工作表总时长39分钟、总题目40题、总答对30题通过公式计算，属于材料自检，不提供用户所求知识库整理结果或清明教案。
尚未建立知识库索引、摘要卡、标签汇总或最终报告。
