# 科技产业匹配制作包：运行兼容说明

这份说明是实验文件恢复的派生兼容资料。原用户提供的 ZIP、包内所有素材和原始说明保持原字节；此处不认证它们与历史附件为同一版本。

原完整会话仅要求用附件完成视频并发送，没有在用户正文中硬性指定逐场秒数。原包自身给出了约 57 秒的七场景时间线与完整旁白。实际使用中文女声、正文 1.3 倍、口号 1.0 倍并去除首尾和长间隔静音后，S03、S04、S05 的原旁白分别约需 5.900、6.164、4.347 秒，超过原槽 5.8、4.9、4.0 秒。不能同时按原槽截断声音，又称完整旁白通过。

`timeline_manifest_compatible.json` 保持总长 57 秒、30fps、七场景、全部原文、正文 1.3 倍、口号 1.0 倍，从 S02 富余槽移出 70 帧给上述三场景及 0.2 秒尾部余量。S06、S07 起止不变。原 D01 素材完整播放约 1.13208 倍，其余素材结束后冻结最后一个有效画面；不能让最后两帧出现空屏。若再次合成的语音时长不同，应重新测量槽容量，而非截断句子。

渲染还需处理原素材的这些特性：

- 数字人 `keyed.webm` 是 VP9 alpha 文件，时长约 10.01 秒。使用支持 alpha 的解码和循环；不能用原绿幕代替。
- `透明电脑_trimmed.png` 仍有宽的低 alpha 边缘。以实际可见 bbox 测量电脑宽度；alpha 大于 64 的 bbox 为 `(225,185)-(1287,876)`，需按此归一至画面 72%，不能把 PNG 的 1511px 画布直接当可见主体。
- 屏幕 mask 是 L 模式灰度图，必须使用亮度 mask。默认 alpha mask 会把整块画布视为不透明。按原校准坐标裁切，再叠 bezel。
- 原数字人衣服上有 `Zzz4Ai` 字样，与包内统一易知品牌的要求不一致。可以在合成时用易知标记覆盖；保留原视频字节。
- 字幕和标题需保证与所给浅背景有足够对比度。
- 原片有少量真实浏览器灰色加载画面；冻结末帧会延长这种画面。`source_loading_blank_profile.json` 按源片逐帧标出这些加载区段；可在这些区段、屏幕 mask 内显示“匹配请求已启动”或“AI分析进行中”的动画状态提示。提示不是原录屏像素，不伪造报告或完成结果，源片仍完整播放。

这份兼容资料允许实际文件用途操作，不等于已完成历史 agent 任务。独立渲染控制视频、生成的配音文件及控制代码不属于会话起始输入，不应投递给 actor 或学习器。最终任务中联系人与飞书发送仍依实验服务映射执行。
