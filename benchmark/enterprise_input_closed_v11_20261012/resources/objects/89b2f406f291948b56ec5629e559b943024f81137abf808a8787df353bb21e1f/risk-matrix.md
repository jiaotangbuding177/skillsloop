# 风险评估矩阵 · Risk Matrix

> 高/中/低 三级风险等级的**量化判定标准**，统一审查口径。每个等级含：① 触发条件 ② 法条依据 ③ 必标内容 ④ 应对策略。

---

## 高风险 🔴（`#cf222e`）

### 触发条件（满足任一即触发）

| 维度 | 量化标准 |
|---|---|
| **金额损失** | 可能导致 ≥ 10% 合同金额损失 |
| **主体资格** | 对方主体不适格、资质缺失、超授权签约 |
| **法律效力** | 条款可能因违法被认定无效（如违反法律强制性规定） |
| **重大违约** | 一方违约金 ≥ 30% 且对方无对应约束 |
| **不可抗力滥用** | 不可抗力范围包含政策、市场等非法定情形 |
| **管辖陷阱** | 管辖约定导致维权成本 > 标的金额 |
| **IP 真空** | 工作成果 IP 归属完全无约定 |

### 必标内容（高风险必带三要素）

1. **法条引用**：具体到条款号（如《民法典》第 506 条）
2. **量化损失预估**：金额或比例（如"可能导致违约金 XX 万元，相当于合同金额 X%"）
3. **必标颜色**：`#cf222e`（红色）+ 批注开头标识 `【高风险】`

### 应对策略

- ✅ **必须谈判修改**：不可接受现状签署
- ✅ **法条不可抗辩**：高风险条款通常基于强制规定（如第 506 条免责无效）
- ❌ **不依赖对方善意**：高风险条款一旦触发即生效

### 常见场景示例

- 违约金 30%+ 单向 → 高风险
- 管辖在对方偏远地区法院 → 高风险
- 主体为未经授权的分支机构 → 高风险
- 保密条款无期限 + 范围过宽 → 高风险
- IP 归属完全无约定 → 高风险

## 中风险 🟡（`#9a6700`）

### 触发条件（满足任一即触发）

| 维度 | 量化标准 |
|---|---|
| **对等性偏差** | 权利义务不对等（违约金差异 ≥ 20%） |
| **违约金偏离** | 偏离行业惯例 20%+ |
| **管辖不利** | 管辖约定我方成本显著增加（非陷阱级） |
| **付款条件** | 付款周期 ≤7 天且无合理验收期 |
| **解除不对等** | 一方可"随时解除"，对方需"违约时解除" |
| **赔偿上限不对等** | 一方 ≤10% 上限，另一方无上限 |
| **不可抗力瑕疵** | 未约定通知义务 / 证明文件 / 后果 |
| **保密瑕疵** | 保密范围模糊 / 期限过长 / 无例外条款 |

### 必标内容（中风险必带两要素）

1. **法条引用**：建议引用（如《民法典》第 585 条违约金调整）
2. **修改建议**：具体修改方向
3. **必标颜色**：`#9a6700`（橙色）+ 批注开头标识 `【中风险】`

### 应对策略

- ✅ **建议谈判修改**：争取对等条款
- ✅ **可接受现状但需记录**：用于未来纠纷举证
- ⚠️ **重大合同必须改**：金额 > 100 万的合同建议必须修改

### 常见场景示例

- 违约金对等但偏离行业惯例 25% → 中风险
- 管辖约定对方城市中级法院 → 中风险
- 验收期仅 3 天且无默示合格条款 → 中风险
- 解除条款不对等但有合理补偿 → 中风险

## 低风险 ⚪（`#d0d7de`）

### 触发条件（满足任一即触发）

| 维度 | 量化标准 |
|---|---|
| **表述瑕疵** | 条款表述不严谨但不影响实质权利 |
| **格式问题** | 编号、引用、标点错误 |
| **次要优化** | 非关键条款可优化空间 |
| **附件缺失** | 附件清单不全但内容可补 |
| **通知条款** | 未约定送达地址但可补充 |

### 必标内容（低风险必带一要素）

1. **修改建议**：简单优化建议
2. **必标颜色**：`#d0d7de`（灰色）+ 批注开头标识 `【低风险】`

### 应对策略

- 💡 **建议优化但可接受**：不阻断签约
- 💡 **可在执行阶段补正**：通过补充协议修正

### 常见场景示例

- 合同标题"合作协议"但实质为买卖 → 低风险
- 未明确合同签订日期 → 低风险
- 附件未列编号 → 低风险
- 签字未盖章 → 低风险（视金额而定）

## 风险分布合理性自检

**触发 `validate.py` 检查**：

| 检查项 | 通过标准 |
|---|---|
| 高风险条款数 | < 5 条（超出需重新评估） |
| 高+中风险总数 | < 15 条 |
| 风险等级覆盖率 | 高中低 ≥ 1 条（如全部为低风险，需复审） |
| 风险分布合理 | 高 < 中（如高 > 中，提示审查标准过严） |

## 量化参考：违约金行业惯例

| 合同类型 | 行业惯例违约金比例 |
|---|---|
| 买卖合同 | 10-20%（迟延履行） |
| 服务合同 | 10-30%（视服务周期） |
| 建筑工程 | 5-10%（合同金额较大） |
| 股权转让 | 10-20%（履约保障） |
| 知识产权许可 | 20-50%（侵权成本高） |

> **判定原则**：偏离上述惯例 ≥20% 即触发中风险；≥30% 即触发高风险。

## 损失预估量化模板

每条高风险条款必带损失预估，按以下模板：

```
【高风险】第 X 条 - 违约金比例失衡
问题本质：约定违约金 30% 远超行业惯例 10-20%
量化损失：按合同金额 100 万计算，最坏情况下需支付违约金 30 万（行业最高为 20 万），超额风险约 10 万
法条依据：《民法典》第 585 条 - 约定违约金过分高于造成损失的，可请求适当减少
修改建议：下调至 20% 或增加"如过分高于实际损失可请求调整"条款
```

## 使用方法

主 agent 在 Step 4 阶段：
1. 对每个问题条款对照本表判定等级
2. 高风险条款必查法条（调用 fyopen-lawsearch）+ 量化损失
3. 中风险条款必查法条 + 给修改建议
4. 低风险条款给简单建议
5. 输出前用 `validate.py` 自检分布合理性
