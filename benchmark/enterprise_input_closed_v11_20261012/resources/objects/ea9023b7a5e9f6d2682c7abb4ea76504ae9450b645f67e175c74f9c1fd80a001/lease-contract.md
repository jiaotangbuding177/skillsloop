# 租赁合同专项审查清单 · Lease Contract

> **法条依据**：《民法典》第 703-734 条（租赁合同）+ 第 732-734 条（房屋租赁）+ 第 175-178 条（居住权）

---

## 租赁合同核心特征

**典型类型**：
- 房屋租赁（住宅 / 商业 / 工业厂房）
- 设备租赁（机械 / 车辆 / 办公设备）
- 土地租赁（经营权 / 使用权）
- 转租 vs 共同租赁

**核心法律关系**：出租人转移租赁物占有 + 使用 + 收益，承租人支付租金——**不转移所有权**

---

## 必查核心条款（11 类）

### 1. 租赁标的

**审查要点**：
- 标的明确性（具体地址 / 设备型号 / 序列号）
- 出租人是否有处分权（所有权 / 用益物权 / 经营权）
- 共有财产出租是否经其他共有人同意

**法条依据**：
- 《民法典》第 711 条（出租人义务）
- 《民法典》第 716 条（共有物出租）

**典型问题**：
- ❌ 出租人无所有权或处分权 → 合同效力争议
- ❌ 共有财产未经其他共有人同意 → 合同可撤销

### 2. 租赁期限

**审查要点**：
- 租赁期限不得超过 20 年（《民法典》第 705 条）
- 超过 20 年的部分无效
- 默示续租的处理（建议明确约定）

**法条依据**：
- 《民法典》第 705 条（最长 20 年）
- 《民法典》第 734 条（默示续租）

**典型问题**：
- ❌ 租期 25 年 → 超出部分无效
- ✅ 应约定：明确起止日期 + 续租程序

### 3. 租金与押金

**审查要点**：
- 租金金额 + 支付方式（月付 / 季付 / 年付）
- 租金调整机制（商业租赁通常 3-5% / 年递增）
- 押金（保证金）金额 + 退还条件 + 扣留情形

**法条依据**：
- 《民法典》第 726 条（租金拖欠）
- 《民法典》第 727 条（租金部分支付）

**典型问题**：
- ❌ 押金无明确退还条件 → 退还争议
- ✅ 应明确：押金 X 元 + 退租验收 X 日内无息退还

### 4. 维修责任

**审查要点**：
- 房屋维修责任划分（《民法典》第 712-713 条）
  - 出租人：房屋主体结构 + 必要修缮
  - 承租人：正常使用下的损耗
- 设备维修责任（按合同约定，无约定则承租人负责日常维护）
- 紧急维修的程序与费用承担

**法条依据**：
- 《民法典》第 712 条（出租人维修义务）
- 《民法典》第 713 条（承租人损害赔偿）

**典型问题**：
- ❌ "房屋维修由承租人负责"——违反《民法典》第 712 条，出租人不能完全免除

### 5. 装修与改造

**审查要点**：
- 装修是否需经出租人书面同意
- 装修标准的限制（如商业装修的消防合规）
- 退租时装修归属（恢复原状 / 折价补偿 / 现状移交）

**法条依据**：
- 《民法典》第 715 条（承租人改善或增设他物）

**典型问题**：
- ❌ 装修归属不明 → 退租争议
- ✅ 应明确：经书面同意的装修，退租时按"现状移交"或"折价补偿"

### 6. 转租与共同租赁

**审查要点**：
- 是否允许整体转租（**未经出租人同意不得转租**，《民法典》第 716 条）
- 转租期限不得超过原租赁期限
- 共同租赁人的连带责任

**法条依据**：
- 《民法典》第 716 条（擅自转租——出租人可解除）
- 《民法典》第 719 条（次承租人造成损失——承租人赔偿）

**典型问题**：
- ❌ 允许乙方自行转租 → 出租人丧失控制权
- ✅ 应明确：转租需经书面同意 + 不得超过原租期 + 承租人对次承租人承担连带责任

### 7. 押金 / 保证金扣留情形

**审查要点**：
- 房屋损害赔偿的扣留
- 拖欠租金的扣留
- 提前退租的扣留

**常见问题**：
- ❌ 押金全额不退 → 显失公平
- ✅ 应明确：可扣留情形 + 扣留比例

### 8. 提前退租

**审查要点**：
- 承租人提前退租的违约责任（通常 2-3 个月租金）
- 出租人提前收回的违约责任
- 不可抗力退租的处理

**法条依据**：
- 《民法典》第 727 条（租金部分支付）
- 《民法典》第 729 条（租赁物毁损灭失）

### 9. 房屋返还

**审查要点**：
- 返还时的状态要求（恢复原状 / 现状移交）
- 返还时的验收程序
- 逾期返还的占用费（建议按日租金 ×1.5-2 倍）

### 10. 特殊租赁类型

**住宅租赁**：
- 群租 / 隔断间禁止（地方性法规）
- 居住权登记（《民法典》第 366 条）

**商业租赁**：
- 营业执照办理配合义务
- 商业保险（公众责任险）

**工业厂房租赁**：
- 环评手续的办理
- 排污许可
- 消防安全

**设备租赁**：
- 设备维护责任
- 设备保险
- 操作人员配备

### 11. 争议解决

**审查要点**：
- 不动产租赁 → 必须**不动产所在地法院**管辖（《民事诉讼法》第 34 条专属管辖）
- 不能约定异地法院
- 不能约定仲裁（与建设工程相同，租赁合同**不能仲裁**——《仲裁法》第 3 条）

**法条依据**：
- 《民事诉讼法》第 34 条（不动产专属管辖）
- 《仲裁法》第 3 条

## 高风险条款 TOP 10

1. **租期超过 20 年** → 部分无效
2. **出租人无处分权** → 合同效力争议
3. **未经同意的转租** → 出租人可解除
4. **房屋维修责任完全由承租人承担** → 部分违反强行规定
5. **押金扣留情形过宽** → 显失公平
6. **租金递增幅度过高** → 中风险
7. **装修归属不明** → 退租争议
8. **异地管辖约定** → 不动产专属管辖违反
9. **约定仲裁管辖** → 违反《仲裁法》第 3 条
10. **租赁期默示续约条款缺失** → 退租争议
