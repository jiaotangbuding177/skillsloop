# Creative Brief 模板（每次视频任务先填写）

> 本文件是 Creative Director 层的产出物。制作任何视频前先完成此简报，
> 再进入素材生成与代码编写。**禁止直接"生成图片 → 写 TSX → 渲染"。**

## 1. Creative Concept（核心视觉概念）

- 一句话概念：这条视频的视觉母题是什么？
  （例：数据在空间中逐层展开 / AI Agent 像研究团队协作 / 产品从暗处进入高光 / 复杂流程逐渐变简单 / 从混乱信息到清晰结果）
- 视觉语言：主色 / 辅助色 / 光影方向 / 材质 / 风格（插画·摄影·3D·抽象）
- 贯穿元素（Visual Motif）：同一条视频重复出现的元素
  （AI 科技：光线·网格·数据节点；报告：文档·数据卡·引用；产品：光影·材质·微距）

## 2. 视频信息

- 主题 / 目的 / 观众 / 平台
- 比例（横屏 1920×1080 / 竖屏 1080×1920 / 方形 / 4:5）/ 目标时长
- 内容类型：讲解型？品牌型？数据型？Demo？

## 3. 模块开关（不要默认全开）

- AI Image: ON / OFF / 按需
- Voiceover: ON / OFF（讲解型默认 ON）
- Subtitle: sentence / keyword-highlight / word / OFF（讲解型+配音默认 keyword 或 sentence）
- BGM Preset: ambient-tech / corporate-clean / documentary / minimal-piano / premium-product / cinematic-soft / warm-education / future-interface / 无
- SFX: ON / OFF

## 4. Storyboard（逐 Scene）

对每个 Scene 明确：

| 项 | Scene 1 | Scene 2 | ... |
|---|---|---|---|
| 为什么存在（目的） | | | |
| 观众应该看哪里（视觉焦点） | | | |
| 时长（秒） | | | |
| 是否配音（VO 内容） | | | |
| 字幕内容 | | | |
| AI 图片 / 真实素材 | | | |
| 动画 / 镜头运动 | | | |
| 转场方式 | | | |
| BGM 情绪（弱/稳/升/留白） | | | |

节奏原则：不要所有 Scene 等长；Hook 快速建立主题；核心信息给足阅读时间；
"安静"也是声音设计——不是全程都要有音乐。

## 5. 声音设计（音乐属于 Creative Direction）

- 开场：轻微建立氛围？
- 核心信息：稳定背景（低存在感）？
- 重要结论：适度提升？
- 复杂讲解：降低存在感 / 留白？
- 片尾：自然收束？
- 有无 Voiceover 决定 BGM 基量与 Ducking 参数。

## 6. 字幕与配音

- 配音稿：口语化改写，避免长句/连续数字/特殊符号；屏幕标题与旁白互补。
- 字幕模式：按内容类型选择（企业=句级，Demo=关键词，讲解=句级+关键词，短视频=词级）。
- 关键词列表（keyword 模式用，须与配音稿实际用词一致）。
