# 实验知识素材字段约定

本文件是本来源独立实验环境的字段字典，不是原个人知识库或原企业系统接口。
关联文件：实验知识素材记录.json。schema 为 local_knowledge_specimen_v1。

| 字段 | 类型 | 约定 |
|---|---|---|
| id | 字符串 | 单份素材内唯一的本地行键 |
| title | 字符串 | 待整理笔记的标题 |
| kind | 字符串 | 概念笔记、录入笔记、阅读摘记或整理约定 |
| tags | 字符串数组 | 原始标签，未完成用户所求整理 |
| body | 字符串 | 待分类的原始笔记正文 |

顶层字段还有 schema、synthetic、scope、source_scope、record_fields 和 records。
所有记录人为设置，没有人物、金额、日期、远端笔记内容或未来任务信息。
