# 灌装机日常点检表说明

**文件编号**：EQ-MNT-008  
**版本**：V1.2  
**适用范围**：设备部、生产部灌装机操作工  
**编制部门**：设备部  

---

## 1. 目的

通过班前点检及早发现灌装设备隐患，减少非计划停机。

## 2. 点检时机

每班开机前 **30 分钟内**完成点检，未点检或不合格不得开机。

## 3. 点检项目

| 项目 | 检查方法 | 合格标准 |
|------|----------|----------|
| 气压 | 压力表读数 | 0.5～0.6 MPa |
| 计量泵 | 目视、听音 | 无泄漏、无异响 |
| 灌装嘴 | 目视 | 无破损、对中 |
| 传送带 | 运行一圈 | 平稳、无跑偏 |
| 安全门联锁 | 开门测试 | 门开则停机 |
| 润滑 | 油位视镜 | 在上下限之间 |

## 4. 异常处置

- 气压不足：检查空压机、滤芯，通知设备部；
- 计量不准：执行复秤校验，偏差超 ±1% 须校准后首件确认；
- 安全联锁失效：**禁止运行**，立即报修并挂牌。

## 5. 记录与保存

填写《灌装机日常点检表》，班长每周抽查，记录保存 **1 年**。
