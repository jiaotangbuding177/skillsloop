# 包装线首件确认规程
**文件编号**：PROD-SOP-018  
**版本**：V2.0  
**适用范围**：生产部包装线（装盒、喷码、装箱）  
**编制部门**：生产部  

---
## 1. 目的
在换线、换批、停机超过 2 小时后复机时，通过首件确认防止错标、漏标、混批。
## 2. 触发时机
下列情况**必须**执行首件确认：
- 更换产品 SKU 或批号；
- 更换包装盒、标签、外箱印刷版；
- 喷码机重新开机或修改喷码内容；
- 计划外停机超过 **2 小时**。

## 3. 首件检查项目
| 序号 | 检查项 | 合格标准 |
|------|--------|----------|
| 1 | 外盒产品名称、规格 | 与生产指令一致 |
| 2 | 批号、限用日期喷码 | 清晰可读，与指令一致 |
| 3 | 条码扫描 | 可正常识别，与 MES 一致 |
| 4 | 说明书、配件 | 齐全、无错放 |
| 5 | 封箱胶带、外箱标识 | 批号、数量正确 |
## 4. 确认流程
1. 操作工完成首件 3 件（或 1 箱）自检；
2. 班长现场复核并签字；
3. QA 按抽检比例复核（至少 1 件）；
4. 三方确认合格后方可批量生产。

## 5. 记录
填写《包装首件确认记录》，保存期限不少于产品保质期加 **1 年**。
