# 课程实施说明

实验合成输入：依原用户请求与文件名推断用途；不是原企业文件，不构成真实政策、人物履历或公开论文。

## 材料范围

课程实施说明是供实验任务使用的业务输入，涵盖背景、现状、规则和待确认记录。本文件提供任务处理前的合成原始材料。分析、修改、总结及最终交付由运行中的 agent 完成。

## 业务现状

实验组织设业务、技术和运营三个部门。文件由负责人按月维护，每条事项记录日期、数量、金额与状态；数据尚未做用户要求的总结或调整。

## 处理流程

材料接收后先确认版本与字段完整性，再按事项类型流转。需要跨部门确认的记录保留待审核状态，修改需注明原因并保存原始输入。

## 记录口径

金额采用人民币，日期使用公历。数量与金额为合成值，不代表历史真实业务。缺失或模糊描述应保留说明，不能自行补为真实事实。

## 待确认事项

本批资料包含字段命名不一致、负责人待确认及日期格式不同等可处理问题。具体判断、重排、改写与输出由运行中的agent完成。
