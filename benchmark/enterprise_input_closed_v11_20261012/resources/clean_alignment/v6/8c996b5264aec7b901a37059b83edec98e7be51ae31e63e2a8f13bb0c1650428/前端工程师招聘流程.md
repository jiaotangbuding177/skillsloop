# 前端工程师招聘流程
1. 用人负责人确认岗位职责、技术栈及预算。
2. 招聘专员发布JD并建立候选池。
3. 简历初筛检查Vue/React、TypeScript、工程化与项目角色。
4. 技术面试通过实际项目讨论和小型调试任务观察能力。
5. 用设计协作、接口联调、性能和可访问性案例评估。
6. 采用同一评分表记录证据，技术、交付、沟通三项权重50/30/20。
7. 交叉面试核验履历；评审确定录用；签署Offer后进入试用培训。
8. 保留JD、评分表、面试记录和候选反馈，招聘结束复盘。
