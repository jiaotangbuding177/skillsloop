# 平台Agent安全安检技术｜实验起始材料

本材料依据会话可知对象描述重建，为实验素材，不是原企业文档或最终客户介绍。

## 原始技术要点
- 输入层：识别用户文本与附件中的提示词注入、越狱、凭证泄漏和危险操作意图。
- 策略层：规则与关键词先筛；存在变体或上下文诱导时进入语义分类；高敏文档采用本地模型脱敏与改写。
- 执行层：核对工具输入、文件范围、操作对象与审批条件，记录操作证据。
- 输出层：检查敏感字段、未证事实和错误外发风险，保留可追溯处理日志。
- 能力档位：基础规则安检、语义安检、本地LLM安检；部署成本随资源与供应商变化，需另外核价。

## 面向客户的约束
读者是普通业务用户；应说明作用、分层选项与使用体验，避免泄露内部算法、策略细则和系统凭据。
