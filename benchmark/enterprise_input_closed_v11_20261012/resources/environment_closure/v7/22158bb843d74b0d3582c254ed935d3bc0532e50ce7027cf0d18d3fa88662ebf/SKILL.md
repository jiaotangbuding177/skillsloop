# 发散与收敛

这是用户已授权的上下文重建输入技能，原自带同名包的字节和历史版本未恢复。它提供方法，不包含原会话最终文案、产品结论或可直接抄用的历史目标输出。阅读 `references/ideation-method.md`。

先读取当前已可见的用户文章、产品说明与本次需求，写清目标受众、平台、字数、语气和必须保留的事实。区分用户原文事实、当前公开证据、创作假设和缺失信息；后轮尚未提交的材料不可先用。

分别从用户痛点、产品可验证特点、使用场景、表达形式四个角度发散。每个角度先给若干不同方案，然后按与任务相关性、事实支撑、表达清晰度和可执行性比较。选出一个主方案并说明选择理由。不要把“新颖”当作可以虚构功效、数据或用户口碑的许可。

当用户只要文案时，把发散与比较用于组织当前输出，最终交付用户要求的文案；当用户要方案时交付候选比较和下一步验证。没有数据时列出验证方法，不编造统计结论。需要文件时用环境中实际可用的文件工具生成，报告实际路径。
