历史 AI · 第 1 段（审计，不发给评测助手）
可以的，Outlook 邮箱支持 IMAP/SMTP 协议，可以通过技能中的 **custom（自定义）** 模式配置使用。

不过在开始之前，我先确认几件事：

### 使用 Outlook 邮箱需要准备的信息

| 项目 | 说明 |
|------|------|
| **邮箱地址** | 你的 Outlook 邮箱（如 `***@***` 或 `***@***`） |
| **授权码/密码** | Outlook 一般使用**应用专用密码**（需在微软账户安全设置中开启"应用密码"功能获取），或者你开启了两步验证后的应用密码 |
| **IMAP 服务器** | `outlook.office365.com`（端口 993，SSL） |
| **SMTP 服务器** | `smtp.office365.com`（端口 587，STARTTLS） |

### 你需要做的

1. 登录 [微软账户安全设置](https://account.microsoft.com/security)
2. 确保已开启**两步验证**，然后生成一个**应用密码**（如果没有应用密码选项，直接用账户密码也可以尝试）

### 配置方式

当你准备好邮箱地址和应用密码后，告诉我，我来帮你写入配置。格式如下：

```
PROVIDER=custom
USERNAME=你的outlook邮箱
PASSWORD=***
SMTP_HOST=smtp.office365.com
IMAP_HOST=outlook.office365.com
```
