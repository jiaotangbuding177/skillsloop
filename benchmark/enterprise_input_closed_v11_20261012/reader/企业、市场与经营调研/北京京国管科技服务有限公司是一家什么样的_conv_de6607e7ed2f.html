## 🔒 安全的配置方法

```bash

source ~/.bashrc
```

### 方法二：配置文件

创建配置文件：

```bash
# 创建目录
mkdir -p ~/.baoyu-skills/baoyu-imagine

# 创建配置文件
cat > ~/.baoyu-skills/baoyu-imagine/EXTEND.md << 'EOF'
# baoyu-imagine 配置

default_provider: openai
default_model:
  openai: gpt-image-2
default_quality: 2k
default_aspect_ratio: 16:9
EOF

# 创建 .env 文件存储 Key
cat > ~/.baoyu-skills/.env << 'EOF'
OPENAI_API_KEY=[隐藏] key 在这里
EOF
```
