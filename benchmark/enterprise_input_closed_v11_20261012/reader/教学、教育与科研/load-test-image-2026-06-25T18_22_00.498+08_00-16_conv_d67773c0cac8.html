在动手之前，我想先了解一下你期望的技能是怎样的。

现有的 `image-ppt-generation` 技能已是"图片式PPT生成"（每页生图为整图再打包成 PPTX），覆盖了我们刚才做的那次操作。

你有几种方向可选：

| 方案 | 说明 |
|------|------|
| **① 可编辑文字 PPT** | 用 python-pptx 制作，每页文字、图表、形状都可编辑，不用生图 |
| **② 混合式** | 封面/关键页用生图，正文用 python-pptx 做文字排版 |
| **③ 特定主题模板化** | 比如"述职报告""教学课件""商业计划书"等，固定版式+变量填充 |
| **④ 定制流程** | 修改现有图片式 PPT 的流程、prompt 风格、确认机制等 |

你想做哪种？另外，这个技能主要是自己用，还是打算发布到 clawhub 上给其他人用？
