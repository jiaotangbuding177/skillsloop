### 🔴 两大关键发现

**1. [CRITICAL] Smax vs SC 的 P 值声称严重不一致**
- 论文 Extended Data Table 1 称 `r = 0.48, P > 0.5`（不显著）

**2. [MAJOR] 南迁物种比例被夸大**

### 🛠️ 使用方法

```bash
# DOCX 直接加 20% 透明度的水印
python3 watermark_pdf.py --input 报告.docx --text "ZZZ4AI" --opacity 20

# PDF 加中文水印
python3 watermark_pdf.py --input 文档.pdf --text "内部资料" --size 300 -o 文档_水印版.pdf

# 全参数配置
python3 watermark_pdf.py \
  --input report.pdf --text "CONFIDENTIAL" \
  --size 260 --opacity 20 --color "180,180,180" \
  --rotate 45 --dpi 150
```
