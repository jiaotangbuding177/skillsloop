## 📋 基金形式审查实操指南

### 一、审查流程（建议打印出来逐项打勾）

**第一步：基础信息核对**
- [ ] **申请代码** — 查最新指南，确认到二级甚至三级代码（如 E0808 → E080801），代码错了直接送错口
- [ ] **研究期限** — 面上/青年通常4年（2027.01-2030.12），重点项目5年，别写成已经过去的年份
- [ ] **申请金额** — 严格按照当年指南上限：面上约53万/4年，青年约30万/3年，重点约300万/5年（以当年指南为准）
- [ ] **申请类型** — 面上/青年/重点/杰青/优青，别选错

**第二步：人员信息**
- [ ] **申请人** — 职称、学位、单位、联系方式，一字不差
- [ ] **团队成员** — 成员身份证号、单位、职称是否完整？是否有超项风险？参与人是否知情确认？
- [ ] **超项核查** — 所有人（含申请人）正在主持和参与的项目总数是否超标？面上/青年限2项，重点限1项

**第三步：正文格式**
- [ ] **摘要≤400字** — 严格计字，超1个字也不行（系统自动检测）
- [ ] **立项依据** — 参考文献注明年份、格式统一（GB/T 7714）
- [ ] **研究内容** — 2-4条为宜，每条有明确的科学目标
- [ ] **研究方案** — 与技术路线图的箭头逻辑一致
- [ ] **创新点** — 2-3条，每条要写清楚"新在哪里、和谁比新"
- [ ] **研究基础** — 不宜过长，突出与你假说的直接关联性

**第四步：附件与辅助材料**
- [ ] **个人简历** — 使用系统自带的模板生成（在线填写），不要上传自制的
- [ ] **代表作** — 5篇以内，近5年为主，第一/通讯作者标注清楚
- [ ] **伦理审批** — 涉及动物/人体实验的，必须有伦理批件
- [ ] **合作单位** — 如有合作单位，需加盖公章的合作协议

**第五步：系统提交前的终检**
- [ ] PDF全文预览一遍（系统生成的最终版没问题？图表乱不乱？）
- [ ] 生成后的文件是否完整无损？
- [ ] 最终提交前让同事或学生做一次**第三方盲审**（最容易发现笔误和逻辑跳跃）

### 二、常见"一票否决"的红线（P0级）

| 类型 | 典型错误 | 后果 |
|------|---------|------|
| 超项 | 申请人/成员超2项 | 直接不予受理 |
| 代码 | 代码选错/过细 | 送错评审专家 |
| 金额 | 超指南上限 | 系统拦停 |
| 期限 | 写成过去年份 | 直接退回 |
| 成员 | 成员不知情 | 严重者列入诚信记录 |
| 伦理 | 涉动物/人而无批件 | 不予受理 |
| 格式 | 摘要超400字 | 系统自动截断 |

### 三、实用技巧

**1. 做一张"形式审查表"**
Excel拉一张表，列：检查项→检查方式→结果→修改人→修改日期。每年提交季直接复用。

**2. 设立"冷处理期"**
初稿完成后放24h再回头检查，自己写的东西容易"看习惯了"跳过错误。

**3. 三人审查制**
- 申请人自查（熟悉内容但可能盲视）
- 同行检查（懂学术逻辑）
- 行政助理检查（只看格式，不管内容）

**4. 系统预览＝最终版**
ISIS系统在线生成的PDF就是评审专家看到的样子——一定要下载完整预览，检查页边距、插图清晰度、表格换页等排版问题。

3. **摘要文本复制到Word/记事本，计字数**，超过400字的立刻压缩
4. 导出PDF，用**两人三遍**的方式过一遍
