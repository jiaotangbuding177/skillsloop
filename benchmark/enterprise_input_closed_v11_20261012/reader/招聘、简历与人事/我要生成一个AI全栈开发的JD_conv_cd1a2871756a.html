## 排查结论

**问题根因：** 共享技能库的 SKILL.md 里规定了：

```yaml
requires:
  env:
    - PROVIDER
    - USERNAME
    - PASSWORD
```

这三个环境变量**启动时必须存在**技能才注册。因为没有预配置，系统启动时直接跳过了它，所以我一开始看到的可用技能列表里没有它，这才说"没找到"。

```yaml
      env:                        ← 移除

```

**修改版（用户目录）：**
```yaml
metadata:
  openclaw:
    emoji: "📧"
    requires:

        - node
        - npm
```

就是删掉了 `requires.env`（`PROVIDER`、`USERNAME`、`PASSWORD` 三个环境变量要求）和 `primaryEnv` 字段。这样技能就不会因为环境变量未配置而被静默过滤掉，而是正常加载，等用户使用时再引导配置。
