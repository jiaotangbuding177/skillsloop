## 📌 头条：OpenAI 与 Anthropic 同日发新模型，打响价格战

**Claude Opus 5.5（Anthropic，9/22 发布）**
- 官方称在编程和知识型工作上树立新行业标杆，性能媲美顶级模型 Fable 5.1，但运行成本降低约 40%
- 定价：每百万输入 token 4 美元 / 输出 20 美元，比 Opus 5 低 20%

- 沟通风格也调了：少用专业术语、重要信息前置，更适合长 session 的 Agentic Coding
- Sonnet 5.5 和 Haiku 5.5 将在几周内推出

**GPT-6 Sol / GPT-6 Luna（OpenAI，同日发布）**
- 扩充 GPT-6 产品线，继承部分旗舰 Astra 能力，价格砍半
- Sol：$2 / $10（每百万输入/输出 token），主打编程等复杂任务
- Luna：$0.10 / $0.50，主打信息抽取、文档摘要等大规模任务
- 背景：面临中国开源模型（阿里、Moonshot、DeepSeek）的成本压力
