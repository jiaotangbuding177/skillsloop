| 命令 | 功能 |
|------|------|
| `init` | 初始化企业微信机器人配置 |
| `contact` | 通讯录 — 成员查询和搜索 |
| `doc` | 文档 — 文档/智能表格创建和管理 |
| `meeting` | 会议 — 创建/管理/查询视频会议 |
| `msg` | 消息 — 聊天列表、发送/接收消息、媒体下载 |
| `schedule` | 日程 — 日程增删改查和可用性查询 |
| `todo` | 待办事项 — 创建/查询/编辑待办项 |
| `cache` | 管理本地缓存 |

### 🚀 首次使用

运行以下命令进行初始化配置：
```bash
wecom-cli init
```

这会引导你配置企业微信机器人的凭证（Bot ID 和 Secret）。
