3. 安装到技能目录：`/root/.agents/skills/Edsby-Grades-Board/`（含 SKILL.md、index.js、package.json、_meta.json）

**两点提醒**
- 该技能真正跑起来前需要配置：`EDSBY_HOST`（学校 Edsby 地址）、Google OAuth 凭据（CLIENT_ID/SECRET ***，且要 `npm install playwright googleapis`——你目前还没提供这些学校/谷歌账号信息
