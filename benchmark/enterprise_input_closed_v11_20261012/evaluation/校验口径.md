# 最终状态基本交付校验口径

每条完整评测会话仅在最后一次用户输入处理完后评分一次。检查对象为本次运行仍有效的文字交付、当前实际文件、持久记忆/技能目录和服务记录；不读取历史AI答案，不逐轮打分。早先已交付且未取消的独立结果仍在终态集合中，同一对象的重复、Continue、重发及修订只计最后有效版本。

只保留代码能够核对的基本条件：文字去空白非空；文件实际存在、非空、可原生解析；用户明确的格式、数量、页数/图像比例/必需组成；最终持久状态和用户明示参数。未要求下载时，文字、内存/状态或技能安装不强制额外导出链接。输入文件格式不自动变成输出格式；不同文件不能合成一个评分对象。

不评专业观点、内容深度、美观、语义正确性、与历史答案的一致性、中间工具或技能使用、重试和临时失败。无法机械确认的细节不纳入计分，不能用“计划/承诺是否实质完成”等语义分类器代替交付基本条件。近似字数仅作描述；图片张数不直接当PDF页数，图片比例不当PDF页面比例。

阅读页及有效轨迹JSONL保留历史AI用于科研审计。评测助手必须从episode.py/逐轮投递文件读取用户输入及当前附件，不将审计轨迹全文当作助手上下文。资源路径完整映射由控制器维护，按dispatch激活；助手每轮可见映射仅限当前已投递附件。本次运行后生成的回复允许留在自己的连续会话里。

本轮已人工审查逐条校验规格并验收输入；没有运行223条业务任务或计算评测分数。最终规则文件是评分规格，通用command评分器尚未实现/激活。环境原生文件和路径控制不能替代业务成功率。
