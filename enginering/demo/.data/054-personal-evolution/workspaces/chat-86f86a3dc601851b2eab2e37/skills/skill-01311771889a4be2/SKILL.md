# 特定条款修改文本单独输出

## 触发

当用户要求仅单独输出特定条款的修改文本而不重新生成完整文件时触发本技能。

## 输入

- 目标条款的修改内容
- 输出格式要求

## 步骤

### s1: 提取特定条款的修改内容并按要求格式化输出
<!-- SKILLSLOOP_METHOD:m7 -->
提取特定条款的修改内容并按要求格式化输出。具体流程：1) 接收用户指定的目标条款名称或编号以及对应的修改内容；2) 确认用户指定的输出格式（如纯文本、Markdown、对比标注等）；3) 将修改内容按照指定格式整理并输出，不包含完整文件的其他部分。

#### 多条条款输出偏好（用户固定习惯）
当一次性输出多条（≥2条）修改后的条款且用户未另行指定不同格式时：
- 保持原来的条款编号和原始顺序，不得重排或合并
- 每条条款放在单独的纯文本代码块里，不合并成一个大代码块
- 输出仅包含代码块本身，不添加标题、解释、提醒或总结，方便逐条复制

## 适用条件

- 用户要求单独输出修改文本

## 完成检查

输出特定条款的修改文本。确认输出内容仅包含目标条款的修改文本，格式符合用户要求，且未重新生成完整文件。

## 限制

- 业务效果未知
- 本技能仅支持有出处的方法与可见过程；业务效果、专业正确性及真实文件交付未经独立验证，均为UNKNOWN。
- 本技能仅执行文本提取与格式化输出，不涉及法律、商务或专业领域建议。
- 文件操作前置条件：用户需提供明确的目标条款修改内容及输出格式要求；若缺少上述输入，需先向用户确认后再执行。

## 市场信息

### 适合人群

需要针对合同中特定条款快速查看或分享修改内容、而不必传递完整文件的用户，如合同审核协作中的局部修改确认场景。

### 核心亮点

- 无需重新生成完整文件，仅输出目标条款修改文本，降低信息传递量。
- 支持按用户指定格式灵活输出，便于直接嵌入沟通或文档流程。

### 典型输入/需求

- 目标条款名称或编号及其修改后的文本内容。
- 期望的输出格式说明（如纯文本、Markdown、带删除线/高亮标注等）。

### 输入预填模板

```
目标条款：[条款名称或编号]
修改内容：[修改后的条款文本]
输出格式：[纯文本 / Markdown / 对比标注 / 其他]
```

### 预期输出/成果

- 输出仅包含目标条款修改文本的独立内容块，格式符合用户要求。
- 用户可直接复制该输出用于沟通、审核记录或其他下游流程。
