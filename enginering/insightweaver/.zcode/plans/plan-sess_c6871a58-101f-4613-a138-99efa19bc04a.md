## 成员默认配额配置页 UI 重构方案

### 核心问题
1. 三个「保存」按钮认知混乱 → 分卡片独立保存
2. 策略开关与模式选择重叠 → 开关控制模式可见性，移除"无限制"选项
3. 信息架构混乱 → 卡片式布局，每卡一个维度
4. 1503 行单文件 → 拆分为 4 个卡片组件 + 主页面

### 新布局（4 卡片）
1. **配额策略卡片** — Switch 开关 + 状态 badge（已生效/被月套餐覆盖/未启用）
2. **配额限制与有效期卡片** — 模式 Radio（对话次数/月Token/批次Token）+ 数值输入 + 有效期配置（策略开启时显示，独立保存）
3. **成员默认工作区容量卡片** — 存储配额输入（始终可见，独立保存）
4. **批次到期后行为卡片** — 三种购买模式 Radio（策略开启时显示，独立保存）

### 文件结构
```
admin/conversation-quota/
├── page.tsx                          # 主页面（~300行，数据加载 + 布局）
├── QuotaPolicyCard.tsx               # 配额策略卡片
├── QuotaLimitCard.tsx                # 配额限制与有效期卡片
├── WorkspaceStorageCard.tsx          # 工作区容量卡片
├── PostExpiryBehaviorCard.tsx        # 批次到期后行为卡片
└── _components/
    └── QuotaModeRadioGroup.tsx       # 配额模式 Radio Group
```

### 关键设计决策
- 策略开关关闭 → 配额限制卡片 + 到期行为卡片隐藏
- 系统管理员视图（多行表格）的卡片内联逻辑复用相同组件
- 保留 draft-based 编辑模式（Record<enterpriseId, value>）
- i18n 需要更新 key 以匹配新 UI 文案

### 实现步骤
1. 创建新卡片组件文件（QuotaPolicyCard, QuotaLimitCard, WorkspaceStorageCard, PostExpiryBehaviorCard）
2. 重构主页面 page.tsx 使用新卡片布局
3. 更新 i18n messages
4. 清理旧代码，确保无功能遗漏
