# UI Entry Point Specification

> 从 cron-task-create-dialog 变更中沉淀。规范 UI 功能入口的实现要求。

## 原则

1. **每个 UI feature 必须有明确的触发入口**：没有入口的功能等于不存在。
2. **入口位置优先参考同页面已有模式**：一致性 > 创新性。
3. **入口必须在设计文档中明确标注**：不能在实现时才决定。

## 入口位置规则

### 模块级功能

放在模块标题栏右侧，与模块标题同行。参照"已安装智能体"模块的"创建智能体"按钮。

```
┌──────────────────────────────────┐
│ 📅 定时任务           [创建]     │  ← 标题栏右侧
├──────────────────────────────────┤
│  任务列表内容...                  │
│  (工具栏：运行结果 | 刷新)        │  ← 工具栏不放创建按钮
└──────────────────────────────────┘
```

### 页面级功能

放在页面顶部操作区域，与页面标题同行或并列。

## 入口样式规则

- 模块级创建按钮：使用 `var(--color-primary)` 实心填充，白色文字
- 图标 + 文字组合（如 `+ 创建`）
- hover 状态使用 `var(--color-primary-hover)`

## 反模式（避免）

- ❌ 在内容区工具栏放置"创建"按钮（与操作按钮混在一起）
- ❌ 只实现 Dialog 不实现触发按钮
- ❌ 入口样式与同页面其他入口不一致
