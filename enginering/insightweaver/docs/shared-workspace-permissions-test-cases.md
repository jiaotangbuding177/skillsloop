# 共享工作区权限测试用例

## SWP-001：不同组织角色访问共享工作区权限校验

### 前置条件

1. 已存在一个组织空间，且该组织已配置可用 OpenClaw 实例。
2. 组织内存在 5 个用户，角色分别为：`viewer`、`member`、`editor`、`admin`、`owner`。
3. 共享工作区中已存在文件 `测试资料/a.md` 和文件夹 `测试资料`。
4. 所有用户均可正常登录 InsightWeaver。
5. 用户通过 InsightWeaver 前端或 API 访问共享工作区，不直接访问 EvoMind。

### 测试步骤与预期结果

| 角色 | 操作 | 预期结果 |
| --- | --- | --- |
| `viewer` | 查看共享工作区目录 | 成功 |
| `viewer` | 打开/下载 `测试资料/a.md` | 成功 |
| `viewer` | 上传文件 | 失败，提示无写入权限 |
| `viewer` | 新建文件夹 | 失败，提示无写入权限 |
| `viewer` | 编辑文件内容 | 失败，提示无编辑权限 |
| `viewer` | 重命名文件/文件夹 | 失败，提示无移动或重命名权限 |
| `viewer` | 删除文件/文件夹 | 失败，提示无删除权限 |
| `member` | 查看共享工作区目录 | 成功 |
| `member` | 打开/下载文件 | 成功 |
| `member` | 上传文件 | 成功 |
| `member` | 新建文件/文件夹 | 成功 |
| `member` | 编辑文件内容 | 成功 |
| `member` | 重命名文件/文件夹 | 失败，提示无移动或重命名权限 |
| `member` | 删除文件/文件夹 | 失败，提示无删除权限 |
| `editor` | 查看/下载文件 | 成功 |
| `editor` | 上传/新建/编辑文件 | 成功 |
| `editor` | 重命名文件/文件夹 | 成功 |
| `editor` | 移动共享工作区内文件/文件夹 | 成功 |
| `editor` | 删除文件/文件夹 | 失败，提示无删除权限 |
| `admin` | 查看/下载/上传/新建/编辑 | 成功 |
| `admin` | 重命名/移动 | 成功 |
| `admin` | 删除文件/文件夹 | 成功 |
| `admin` | 配置共享工作区权限规则 | 成功 |
| `owner` | 查看/下载/上传/新建/编辑 | 成功 |
| `owner` | 重命名/移动 | 成功 |
| `owner` | 删除文件/文件夹 | 成功 |
| `owner` | 配置共享工作区权限规则 | 成功 |

### 通过标准

1. 每个角色只能执行其权限范围内的操作。
2. 无权限操作必须在服务端被拒绝，不能只依赖前端按钮隐藏。
3. 前端提示应与权限类型匹配，例如写入、移动、删除权限不足。
4. 操作失败后，共享工作区文件内容和目录结构不应发生变化。
