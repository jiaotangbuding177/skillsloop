# C 端用户充值中心使用指南

## 适用对象

本指南适用于需要在工作台内查看或购买个人充值套餐的 C 端用户。

## 入口位置

进入工作台后，在页面左侧栏底部找到充值中心入口。

充值中心入口位于我的分享区域下方、AI 会话记录区域上方。点击充值中心后，页面中间会打开充值弹窗，当前工作台页面会保留在弹窗背景中。

## 查看月包套餐

打开充值中心后，默认展示月包套餐。

月包套餐包含以下内容：

- 价格：259 元/月
- Token：3,000 万
- 容量：10G

该套餐适合需要长期、稳定使用 AI 对话与文件空间能力的个人用户。

## 查看资源包套餐

在充值弹窗顶部切换到资源包，即可查看资源包套餐。

资源包套餐包含以下内容：

- 价格：60 元/包
- Token：3,000 万

该套餐适合需要临时补充 Token 用量的个人用户。

## 切换套餐

充值弹窗顶部提供月包套餐和资源包两个选项。

点击对应选项后，弹窗内容会切换到对应套餐，右侧套餐卡片也会同步展示当前套餐价格与权益。

## 关闭弹窗

点击弹窗右上角关闭按钮，即可关闭充值中心并返回当前工作台页面。

关闭弹窗不会影响当前对话、文件树、分享面板或其他已打开的工作台内容。

## 注意事项

- 页面展示文案面向最终用户，不会展示内部辅助说明词。
- 当前充值弹窗用于展示个人套餐入口与套餐信息。
- 如后续需要完成真实支付，请以页面后续接入的支付流程为准。
