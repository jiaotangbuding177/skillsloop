## 1. 产品概述

### 1.1 什么是 EvoMind

EvoMind（内部代号 InsightWeaver）是一款**基于自进化 AI Agent 的组织智能系统**，核心能力包括：

- **深度研究（Deep Research）**：输入研究主题，AI 自动生成结构化研究报告（大纲 → 正文 → 导出），支持市场调研、竞品分析、技术趋势等多种模板
- **AI 工作台（超级龙虾）**：集成对话、文件管理、知识库、技能库的 AI Agent 工作台，支持多模型配置和企业级协作
- **组织智能**：企业空间、数字员工、知识库共享，将 AI 能力融入组织协作流程

### 1.2 产品架构

EvoMind 包含两大产品线：

| 产品线 | 入口 | 核心功能 |
|--------|------|----------|
| **Deep Research** | 首页 `/dl` | AI 研究报告生成、历史管理、积分体系 |
| **超级龙虾工作台** | `/` (Zclaw Shell) | AI 对话、文件管理、知识库、技能、数字员工、企业协作 |

### 1.3 系统要求

- 现代浏览器（Chrome、Edge、Safari、Firefox 最新版）
- 移动端适配（响应式布局）
- 需要网络连接

## 2. 登录与认证

### 2.1 登录方式

EvoMind 采用**手机号 + 短信验证码**登录，无需设置密码。

<!-- 截图占位：登录页面 -->
![登录页面](./images/login-page.png)

### 2.2 操作步骤

1. 访问 EvoMind 首页，系统自动跳转至登录页
2. 在左侧或顶部输入**手机号**（支持 13-19 开头的 11 位手机号）
3. 点击**「获取验证码」**，系统发送 6 位数字短信验证码
4. 输入收到的验证码
5. 点击**「登录」**按钮

> **注意**：验证码 60 秒内只能发送一次，请在有效期内完成输入。

### 2.3 登录页面元素说明

| 元素 | 说明 |
|------|------|
| 手机号输入框 | 仅允许输入数字，自动过滤非数字字符 |
| 验证码输入框 | 6 位数字验证码 |
| 获取验证码按钮 | 点击后 60 秒倒计时，期间不可重复发送 |
| 登录按钮 | 验证通过后自动跳转至首页 |

### 2.4 会话管理

- 登录成功后，系统通过 HttpOnly Cookie 存储 JWT 令牌
- Access Token 过期后自动使用 Refresh Token 刷新，无需重新登录
- 若 Refresh Token 也过期，系统自动提示重新登录

## 4. 研究报告生成

### 4.1 生成流程概览

研究报告生成页面采用**左右双栏布局**：左侧为对话区（AI 交互 + 参数确认），右侧为画布区（大纲/正文实时预览）。

顶部显示 **4 步进度条**，反映当前研究阶段：

<!-- 截图占位：研究流程进度条 -->
![研究流程进度条](./images/research-progress-bar.png)

| 步骤 | 名称 | 说明 |
|------|------|------|
| 1 | 环境初始化 | 进入页面即自动完成 |
| 2 | 深度配置 | AI 生成研究参数，用户确认或调整 |
| 3 | 逻辑构建 | AI 生成研究报告大纲 |
| 4 | 全文撰写 | AI 根据大纲生成完整正文 |

完整流程：

```
输入主题 → AI 生成研究参数 → 用户确认参数 → AI 生成大纲（SSE 流式） 
→ 用户编辑/确认大纲 → 选择报告类型 → AI 生成正文（SSE 流式） → 导出报告
```

### 4.2 研究参数确认（深度配置）

进入报告生成页面后，AI 首先分析研究主题并生成**研究参数卡片**，包括研究方向、分析维度等建议。

<!-- 截图占位：研究参数确认卡片 -->
![研究参数确认](./images/research-params.png)

**操作选项**：

| 按钮 | 说明 |
|------|------|
| **确认并生成大纲** | 接受参数，进入大纲生成阶段 |
| **暂不生成** | 取消当前参数确认，回到输入状态 |

> 参数确认阶段输入框被锁定，无法发送自由消息。

### 4.3 追问机制（Elicitation）

在研究过程中，AI 可能通过追问（Elicitation）向你获取更具体的需求信息。追问会以**交互式卡片**的形式出现在左侧对话区。

<!-- 截图占位：追问卡片示例 -->
![追问卡片](./images/elicitation-card.png)

#### 追问类型

| 类型 | 交互方式 | 说明 |
|------|----------|------|
| **单选** | 圆形单选按钮列表 | 从预设选项中选择一个 |
| **多选** | 方形复选框列表 | 从预设选项中选择多个 |
| **单选+自定义** | 单选按钮列表 + 自定义输入框 | 可选预设选项，也可自行输入 |
| **文本问答** | 文本输入框 + "提交回答"按钮 | 自由文本回答 |
| **文本确认** | 文本输入框 + "确认无误"/"提交修订"两个按钮 | AI 展示内容供确认或修订 |

> 追问可能在大纲生成前或正文生成中出现，回答后 AI 可能继续追问，直到获得足够信息。

### 4.4 大纲生成

确认研究参数后，系统进入大纲生成阶段：

1. 左侧对话区显示"正在生成大纲..."卡片
2. 右侧画布区自动打开，切换到**「大纲结构」**标签页，实时流式展示大纲内容
3. 大纲以 Markdown 格式展示，包含章节标题和结构层级

<!-- 截图占位：大纲生成中 -->
![大纲生成中](./images/outline-generating.png)

> **计费**：大纲生成消耗 10 积分。

### 4.5 编辑大纲

大纲生成完成后，可以通过两种方式修改：

#### 方式一：直接编辑

1. 点击左侧卡片下方的**「修改大纲」**按钮，或在右侧画布点击**「编辑内容」**按钮
2. 进入大纲编辑器：
   - 支持 `##`（二级标题）和 `###`（三级标题）格式的编辑
   - 粘贴内容时自动转为纯文本
   - 失焦自动保存
3. 编辑完成点击**「保存修改」**

> 大纲编辑器为纯文本模式，仅支持 Markdown 标题语法，不支持富文本格式。

#### 方式二：对话式修改

在输入框中输入 `/edit <修改指令>`，例如 `/edit 增加竞争对手定价分析章节`，AI 会根据指令修改大纲并自动更新。

- 蓝色说明卡片包含:
  - **适用场景**：初版研究、快速获取概览、标准化分析需求等 4 个场景
  - **预期产出**：结构化行业研究报告（大纲 + 正文）

### 4.7 正文生成

- 右侧画布自动切换到**「行研报告」**标签页

- 生成过程中顶部显示"正在进行深度研读与撰写..."进度指示
- 正文包含：研究概述、详细分析、数据图表（Mermaid）、引用来源
- 正文以 Markdown 格式渲染，支持代码高亮、数学公式、表格

### 4.10 错误处理与重试

#### 全局错误提示

EvoMind 采用统一的错误处理系统：

- 所有错误自动转换为**中文友好提示**（如"网络连接异常，请检查网络后重试"）
- 错误提示显示在页面**右下角**，暗色低调风格
- 同一类型错误 **30 秒内只弹出一次**，避免重复打扰
- 严重错误（如积分不足）会弹出对话框而非 Toast

#### 重试机制

- 生成过程中如果发生错误（网络中断、服务异常等），页面显示**「重试当前步骤」**浮动按钮
- **大纲阶段**重试：直接重新调用生成接口
- **正文阶段**重试：弹出确认弹窗（"重试会清除该步骤已经生成的内容，是否确定重试？"），确认后清除失败步骤产生的内容并重新生成

<!-- 截图占位：重试确认弹窗 -->
![重试确认弹窗](./images/retry-confirm.png)

#### 退出确认

如果报告尚未完成时点击返回，系统弹出退出确认弹窗：

- 标题："正文尚未生成"
- 说明："研究报告正文尚未生成，完成后可直接返回，请稍候。"
- 选项：「仍要返回」或「继续生成」

#### 积分不足

- SSE 返回积分不足（错误码 4001）时，弹出积分不足提示对话框
- 点击「充值」按钮跳转充值页面

### 4.11 历史记录恢复

通过 `/generate?sessionId=xxx` 访问历史研究时：

- **正文已就绪**状态：以只读模式打开，可直接查看和导出
- **大纲已就绪**状态：可继续编辑大纲或生成正文
- **草稿**状态：可重新开始研究流程

## 16. 常见问题

### Q1：验证码收不到？

- 确认手机号输入正确
- 检查短信是否被拦截或归入垃圾短信
- 等待 60 秒后重新发送
- 如持续收不到，联系管理员

### Q2：积分不足怎么办？

- 点击页面上的「充值」按钮
- 选择套餐并微信扫码支付
- 管理员也可通过后台手动发放积分

### Q3：研究报告生成失败？

- 检查网络连接
- 确认积分余额充足
- 刷新页面重试
- 使用「重试当前步骤」按钮重新生成
- 如持续失败，联系技术支持

### Q4：超级龙虾无法访问？

- 首次使用需要申请开通，等待管理员审批
- 审批通过后刷新页面即可使用

### Q5：如何切换组织空间？

- 在超级龙虾侧边栏底部找到组织切换器
- 选择要切换的组织或「默认空间」（个人）
- 切换后文件树、对话历史、知识库等资源自动切换

### Q6：文件分享链接过期了？

- 分享创建者可在「我的分享」面板查看和管理分享
- 如已过期，需重新创建分享

### Q7：如何配置自定义 AI 模型？

- 在超级龙虾工作台打开模型配置对话框
- 输入 Provider、Base URL 和 API Key
- API Key 仅存储在本地，不会上传服务器

### Q8：附件上传失败？

- 检查文件格式是否支持（PDF / DOCX / TXT / MD / XLS / XLSX）
- 检查单个文件大小（不超过 20MB）
- 检查文件数量（最多 5 个）
- 检查网络连接

### Q9：AI 追问怎么回答？

- 追问是 AI 为了更好地完成研究而提出的补充问题
- 按照追问类型选择选项或输入文本即可
- 回答后 AI 可能继续追问，直到获得足够信息

### Q10：大纲生成前为什么需要确认参数？

- AI 根据你的主题自动分析研究维度和方向
- 确认参数可以让 AI 生成更精准的大纲
- 如不满意参数，可以选择"暂不生成"重新输入

### Q11：报告生成中可以退出吗？

- 可以，但系统会弹出确认提示
- 如果正文尚未生成，退出后可从历史记录恢复继续
- 生成中的内容通过 sessionStorage 临时保存，刷新页面后可恢复

### Q12：如何用对话方式修改大纲？

- 在输入框中输入 `/edit <修改指令>`
- 例如：`/edit 增加竞争对手定价分析章节`
- AI 会根据指令自动修改大纲

## 17. 操作场景示例

### 场景一：使用市场调研模板生成行业报告

1. 登录 EvoMind，进入首页 `/dl`
2. 点击底部工具栏的**「市场调研」**模板按钮
3. 模板激活后，在蓝色高亮的 `[输入主题]` 占位处输入研究主题（如"中国新能源汽车市场"）
4. （可选）点击**「输入优化」**，让 AI 优化描述
5. （可选）上传行业报告附件（PDF/DOCX）作为参考
6. 点击发送按钮
7. 在报告生成页面，AI 展示研究参数卡片 → 点击**「确认并生成大纲」**
8. 如有追问，按要求选择选项或输入文本
9. 大纲生成完成 → 查看右侧大纲预览 → 如需修改，点击**「修改大纲」**或输入 `/edit` 指令
10. 确认大纲后点击**「确认并生成全文」** → 选择报告类型（自动版/高级版）
11. 等待正文生成完成 → 使用目录导航浏览 → 点击导出按钮选择格式下载

### 场景二：在超级龙虾中使用 AI 编辑文件

1. 进入超级龙虾工作台
2. 在左侧文件树中找到要编辑的文件，点击打开预览
3. 点击**「编辑内容」**进入编辑模式
4. 选中需要优化的文本段落
5. 从 AI 编辑操作中选择「润色」/「翻译」/「总结」/「扩写」
6. AI 自动处理选中文本，结果写回编辑器
7. 点击**「保存修改」**保存文件

### 场景三：创建文件分享给同事

1. 在超级龙虾文件树中选择要分享的文件或文件夹
2. 点击右键菜单中的**「分享」**按钮
3. 设置密码保护（可选）、有效期（可选）
4. 配置下载/复制权限
5. 确认创建 → 复制分享链接发送给同事
6. 同事通过链接访问，输入密码（如有）即可查看

### 场景四：管理员审批用户开通申请

1. 以管理员身份登录，进入管理后台
2. 点击**「开通申请」**卡片
3. 查看待审核列表，按状态筛选或手机号搜索
4. 查看申请说明，填写审核备注
5. 点击**「通过申请」**或**「拒绝申请」**
