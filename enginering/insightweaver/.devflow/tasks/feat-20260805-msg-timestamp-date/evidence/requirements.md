# 需求：会话消息时间戳显示日期（月-日）+ 时间

## 设计树决策摘要（grill 产出）

- 显示策略：今天只显示时间；非今天的消息显示「月-日 + 时间」（微信风格）
- 格式：数字格式 `08-05 18:02`（zh/en 统一，不新增 i18n 键）
- 时区：沿用浏览器本地时区（与现状一致，不做转换）
- 数据源：`message.createdAt`（ISO 字符串），类型见 `types/super-lobster.ts:39`

## Goal

把对话消息气泡下方的时间戳从纯时间（`18:02`）改为：当天消息仍显示时间，历史消息显示「月-日 + 时间」（`08-05 18:02`），便于跨天会话区分消息日期。

## In scope

- `MessageBubble.tsx` 时间戳渲染（第 874-878 行 `toLocaleTimeString` 调用）
- 在 `apps/web/src/lib/format-utils.ts` 新增/扩展纯函数：判断是否当天 + 格式化「月-日 时:分」

## Out of scope

- 消息按日期分组 / 日期分隔线（MessageList 无此逻辑，不新增）
- 会话列表侧边栏分组（sessionGroups 翻译键，不动）
- 时区转换

## Acceptance criteria

1. 当天消息：显示 `18:02`（两位时:分，与现状一致）
2. 非当天消息：显示 `08-05 18:02`（两位月-两位日 + 两位时:分）
3. zh/en locale 均使用数字格式，无新增 i18n 键
4. 状态后缀（发送中/失败/已中止）行为不变
