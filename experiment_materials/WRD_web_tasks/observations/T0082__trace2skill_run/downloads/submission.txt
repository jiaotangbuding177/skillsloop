一、三请求结果
  A  GET /status  -> 200 OK（请求成功）
  B  GET /missing -> 404 Not Found（资源不存在，客户端路径问题）
  C  GET /busy    -> 503 Service Unavailable（服务端暂不可用）

二、404与503的不同处置
  404（请求B）：核对URL与资源名，修正后重发一次
  503（请求C）：间隔后有限重试（≤3次），仍503则停止并上报
  我的重试边界：等待2秒再重试，最多3次，仍503时停止并记录上报。
