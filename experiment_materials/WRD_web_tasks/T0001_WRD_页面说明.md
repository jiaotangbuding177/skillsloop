# 禾序采购中心 首页说明

交付文件：`index.html`（单文件静态首页，可直接双击或经 HTTP 打开）、`页面说明.md`（本文）。

## 一、版块结构

| 版块 | 对应需求 | 内容说明 |
|---|---|---|
| 顶部导航 | 品牌/导航要求 | 左侧内嵌 logo.svg（原文保留），右侧导航：首页、业务模块（下拉）、关于平台、联系我们、账号登录按钮 |
| Hero 首屏 | 平台目标 | 一句话定位 + 两个主按钮（跳转品类 / 供应商名单），注明演示版口径 |
| 采购品类 | 核心版块 1 | 4 张卡片：检测设备、电子器件、办公耗材、包装材料，每张标注合格供应商数量 |
| 供应商管理 | 核心版块 2 | 清晰表格展示样例数据全部 4 家：S01 禾岚仪器、S02 松源电子、S03 启明耗材、S04 华越材料，含资质有效期与供货周期 |
| 公告中心 | 核心版块 3 | 3 条公告，全部由样例数据推导（华越材料临近到期提醒、松源电子信息、供应商总数概览），不编造事实 |
| 合同进度 | 核心版块 4 | 表格 + 进度条，剩余天数按打开页面当日自动计算，状态徽章自动分级（有效 / 临近到期 / 已到期） |
| 关于平台 | 导航「关于平台」 | 平台定位与演示版使用说明 |
| 联系我们 | 联系入口 | 邮箱 contact@example.com、电话 400-000-0109，页脚同步保留 |
| 登录弹窗 | 保留登录入口 | 「账号登录」打开原生 `<dialog>` 演示弹窗，明确说明未接入真实登录服务，不伪造账号 |

## 二、视觉风格

- 深蓝（#173d49 / #0f2a33）为主色、米白（#f8f3e7 / #fffcf4）为底色，teal（#176b79）呼应 logo 方块色。
- 表格深蓝表头 + 斑马纹 + 悬停高亮，满足「清晰表格」要求。
- logo.svg 原始图形内嵌保留，仅将文字填充色改为米白以适配深色头部，图形未改动。

## 三、交互实现

- **下拉菜单**：「业务模块」为 button 触发，支持点击、`ArrowDown/ArrowUp` 在菜单项间移动焦点、`Escape` 关闭并回焦按钮，`aria-expanded/aria-haspopup/role=menu` 齐全。
- **登录按钮**：打开演示弹窗，`Esc`、点击遮罩、点击「知道了」均可关闭。
- **导航与主按钮**：均为页内锚点跳转，目标版块设置 `scroll-margin-top` 避免被吸顶导航遮挡。
- **键盘可达**：页面首元素为「跳到主要内容」跳转链接；全局 `:focus-visible` 高对比橙色焦点框。

## 四、响应式适配

- ≥1025px：品类 4 列、双栏面板。
- 761–1024px（平板）：品类 2 列、面板单栏、标题缩小。
- ≤760px：导航居中换行、品类单列；表格容器 `overflow-x:auto` 保证小屏可横向滚动查看。

## 五、数据口径与边界

- 全部业务事实取自 `样例数据.json`，未添加任何未提供的真实客户、业务收益或登录后数据。
- 「合同进度」按资质有效期以 365 天口径折算剩余进度；剩余天数、状态徽章由页面脚本按当日日期计算（华越材料 2026-10-20 到期，当前显示「临近到期」）。
- 页面不依赖外部网络资源（无 CDN、无外部字体请求），可离线以 `file://` 打开。
