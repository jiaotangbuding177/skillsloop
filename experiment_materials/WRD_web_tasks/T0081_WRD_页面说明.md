# 页面说明：澜桥成果服务 · 成果转化平台首页

## 交付文件

- `index.html`：改版后的平台首页，单文件静态页面，双击或任意静态服务器即可打开，无需后台。
- 本说明文件。

## 页面结构

| 区块 | 位置（页内锚点） | 内容 |
| --- | --- | --- |
| 顶部导航 | 固定吸顶 | Logo（原样保留附件 SVG）、首页、业务模块下拉、关于平台、联系我们、右侧「账号登录」 |
| 首屏 | `#top` | 平台定位一句话 + 两个主按钮（了解业务模块 / 联系我们） |
| 环形模块入口 | 首屏下方 | 成果评估、产业匹配、政策匹配、专家服务四个环形入口，点击滚动到对应模块 |
| 核心业务模块 | `#modules`（含 `#assess / #match / #policy / #expert`） | 四个模块的文字说明与入口按钮，全部可访问，无「待开发」占位 |
| 样例成果 | `#results` | 按样例数据.json 展示 R01–R04 四条成果：名称、产业方向、TRL、负责人、验证情况，「查看详情」弹出详情对话框（含 TRL 刻度条） |
| 关于平台 | `#about` | 平台定位、服务方式、数据口径（仅使用样例包事实） |
| 联系我们 | `#contact` | 邮箱 contact@example.com（mailto）、电话 400-000-0108（tel），可点击 |
| 页脚 | — | 版权与联系入口 |

## 交互与可用性

- **导航与下拉**：业务模块为下拉菜单，鼠标点击/悬停外区域收起，键盘可操作（Enter 展开、ArrowDown 进入、Escape 关闭并归还焦点），带 `aria-expanded` 状态。
- **登录**：保留登录入口；弹窗明确说明当前为演示页、未接入真实登录服务，并给出联系途径，不伪造账号或登录后数据。
- **按钮指向页内详情**：模块按钮滚动到样例成果/联系区，成果卡片「查看详情」打开内嵌数据的详情对话框，未编造任何客户案例或业务收益数字。
- **键盘与对比度**：提供「跳到主要内容」跳转链接，所有交互元素有清晰 `:focus-visible` 焦点环，文字配色满足对比度要求，支持 Escape 关闭对话框。
- **动效克制**：仅轻微悬停位移/阴影过渡，并尊重系统「减少动态效果」（prefers-reduced-motion）设置。

## 响应式

- **PC（≥921px）**：导航横排，环形入口 4 列，模块/成果卡片 2 列。
- **平板（≤920px）**：主导航收纳为「菜单」按钮展开的抽屉式面板，环形入口变 2×2，关于区单列。
- **窄屏（≤640px）**：卡片转单列。
- 目标元素设置了 `scroll-margin-top`，吸顶导航不遮挡锚点内容。

## 数据与实现要点

- 样例数据（R01–R04）以 JavaScript 常量形式内嵌在 `index.html` 中，与 `样例数据.json` 逐字段一致，避免 `file://` 协议读取外部 JSON 失败。
- Logo 直接内嵌原 `logo.svg` 内容，未做变形重绘。
- 视觉风格遵循约定：浅色背景（#f7fbfc）、环形模块入口、主色取自 Logo 的青色系（#176b79 / #173d49）。
- 页面为纯静态单文件，无外部依赖、无构建步骤；不要求真实后台或发布上线。

## 已知边界

- 登录为演示说明弹窗，无真实认证。
- 首页数据仅为附件样例事实，不代表真实客户或收益。
