1. 操作页面说明

以下是 北辰企业协同平台 智能协作平台的产品界面说明，核心功能模块及交互逻辑如下：

1.1 左侧「文件管理区」

定位：企业级文件与组织管理中枢。

功能：

「个人工作区」「共享工作区」：支持团队/个人文件的分类存储，共享工作区整个企业/组织可见。

「我的分享」「AI会话记录」：快速访问分享的文件、过往AI历史会话存档。

「企业/组织切换」：适配多企业/组织架构场景，一键切换所属主体。

「个人信息区」：展示和修改账号头像等信息，查看云盘空间大小。

1.2 中间「对话核心区」

由「会话区」+「对话框区」组成，是人机交互的核心场景：

1.2.1 会话区

定位：AI与用户的对话内容展示窗口。

功能：

呈现自然语言对话，支持多轮连续交互。

AI回复包含结构化信息，兼顾可读性与实用性。

1.2.2 对话框区

定位：用户输入指令、调用工具的操作入口。

功能：

基础操作：输入消息后按 Enter 发送，Shift + Enter 换行；支持拖拽本地/左侧文件到输入框，实现“对话+文件处理”联动。

快捷功能：「新对话」（开启全新会话）、「快捷指令」（预设常用指令模板）、「技能库」（调用AI扩展能力）、「人格」（自定义AI交互风格）。

模型配置：「默认大模型」支持切换底层AI模型，可配置自定义模型。

辅助工具：「输入优化」（润色/补全用户输入）、「上传文件」（向对话注入文档等素材）、「发送」（提交当前输入）。

1.3 右侧「AI工作台」

聚焦任务自动化、智能体协同、技能扩展三大方向，是企业效率提升的“工具箱”：

1.3.1 定时任务区

定位：自动化任务调度中心。

功能：创建周期性/一次性任务，设置触发时间，减少重复人工操作。

1.3.2 智能体区

定位：垂直场景AI助手集合。

功能：提供「销售助手」、「招聘助手」等行业专属智能体，覆盖业务全流程提效。

1.3.3 推荐技能区

定位：通用型AI能力插件库。

功能：推荐「合同风险审查」、「法律风险评估」等专业技能，按需调用解决特定问题。

5.2 HR智能体能力演示

5.2.1 能力定位

HR 工作智能体用于辅助处理企业人力资源场景中的制度化、流程化任务，覆盖招聘录用、培训管理、员工离职、政策合规和绩效评估五类核心工作。智能体回答和生成建议时应优先引用已编译的证据原子，避免编造未被制度或流程文件支持的业务事实。

该智能体适合用于内部 HR 助手、制度问答、流程核查、表单草拟、审批前材料整理和证据追溯等场景。涉及员工个人信息、离职原因、纪律处分、薪酬补偿、内部制度细节或对外输出时，应触发人工确认。

5.2.2 包含技能

human-resources-recruitment：处理招聘录用流程、候选人材料核验、面试安排、录用审批和入职材料检查。

human-resources-training：处理培训项目设计、培训计划、目标人群、培训方式、日程安排和评估标准。

human-resources-departures：处理员工离职、辞职、终止试用、解除劳动合同、离职材料和补偿相关流程。

human-resources-compliance：处理 HR 制度合规、政策适用性、违规风险、制度审查和证据化合规报告。

human-resources-performance：处理绩效评估周期、评价标准、反馈整理、评级尺度、改进计划和培训建议。

5.2.3  使用案例

用户选择HR智能体

当用户提出以下类型请求时，触发对应智能体技能：

招聘录用：例如“帮我设计财务岗位招聘流程”“检查候选人入职材料是否齐全”“安排一轮多部门面试”“生成录用审批前的核验清单”。

培训管理：例如“制定新员工培训计划”“为销售团队设计培训日程”“根据培训目标生成评估标准”“整理培训项目执行步骤”。

员工离职：例如“处理员工主动离职流程”“离职需要哪些材料”“终止试用应该怎么走流程”“生成离职面谈要点”。

政策合规：例如“检查这个考勤制度是否合规”“判断某个 HR 操作是否违反制度”“生成政策执行情况报告”“找出制度依据和风险点”。

绩效评估：例如“设计季度绩效评估流程”“根据反馈生成改进计划”“整理员工绩效评价要点”“给出培训建议和下一步行动”。

如果用户请求同时涉及多个 HR 主题，将先识别主任务，再调用最相关的技能；必要时按流程顺序组合多个技能。例如“招聘后安排入职培训”可先使用 human-resources-recruitment，再使用 human-resources-training。

11. 常见问题汇总

Q1：验证码收不到？

检查短信是否被拦截或归入垃圾短信

等待 60 秒后重新发送

如持续收不到，联系管理员

Q2：北辰企业协同平台无法访问？

首次使用需要申请开通，等待管理员审批

审批通过后刷新页面即可使用

Q3：如何切换组织空间？

在侧边栏底部找到组织切换器

选择要切换的组织或「默认空间」

切换后文件树、对话历史、知识库等资源自动切换

Q4：文件分享链接过期了？

分享创建者可在「我的分享」面板查看和管理分享

如已过期，需重新创建分享

Q5：如何配置自定义 AI 模型？

打开模型配置对话框

输入 Provider、Base URL 和 API Key

Q6：附件上传失败？

检查文件格式是否支持（PDF / DOCX / TXT / MD / XLS / XLSX）

检查单个文件大小（不超过 100MB）

检查文件数量（最多 5 个）

检查网络连接
