# 企业协同平台安全能力说明
本期产品具备三个可配置层级：基础检查、敏感材料加强检查、高敏人工复核。基础检查覆盖会话输入的恶意指令模式和常见敏感标识；加强检查另处理上传文件的正文及引用，按企业定义的敏感词/项目编号规则提示；高敏流程会暂停外发并交给指定审核人。
组织数据定义由企业管理员维护，平台不能凭关键词准确识别所有商业秘密，图片文字识别质量和材料版本均可能影响检出。系统记录触发规则、材料版本、处理动作和审核结论，不保存无限期全文。
现有边界：未对第三方邮件服务作外发拦截；本地下载后再外传不在控制范围；不能承诺零漏报。默认基础检查；加强与高敏需管理员配置，不按未提供价格编预算。
客户展示强调按业务密级逐步升级、可追溯审查和人的最终责任，避免“百分百安全”或“完全替代法务”。
