# 20人SaaS团队绩效设计条件
团队研发10人、产品4人、销售6人，季度评价。公司要求量化KPI与行为评级两个维度。研发关注按期交付、缺陷与协作，但不得单以代码行数；产品关注需求确认、验收样本、上线使用与交付，但不把销售收入全部归产品；销售关注实际回款、客户质量和交接，不只看合同签字金额。
综合权重KPI70%、行为30%。行为五级，需定义可观察证据与适用范围。评分由本人自述、直属主管核证和校准会议，未给数据不预填员工分数；季度中应有一次检查以避免月底突袭。
面谈应包括事实、问题、改进行动、支持资源与下季目标，容许员工补充证据。方案不自动产生降薪/辞退决定。奖金政策本次不设计，不能虚列员工个人绩效。
