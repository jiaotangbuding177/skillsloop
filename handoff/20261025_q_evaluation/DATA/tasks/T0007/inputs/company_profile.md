# 澄川工业软件资料卡
资料日期：2026-09-30；成立于2022年；总部苏州；员工36人，其中研发22、交付8、销售4、行政2。
产品：设备运维助手年费8万元/站点；工艺知识检索年费5万元/团队；私有部署初装12万元，年维护费为初装费15%。
2025年营业收入620万元，2026年前三季510万元；已有付费客户18家、试点客户7家。客户合同口径不是注册账户口径。
已验收案例：A工厂设备排障平均耗时从42分钟降至29分钟（12名工程师、8周、176工单）；B物流中心知识检索从11分钟降至6分钟（23名员工、4周）。样本是两客户实测，不外推所有客户。
优势：支持离线部署、来源定位、操作审计；边界：没有自动执行设备控制指令，不能处理未接入设备的实时数据。
2027计划：完成国产数据库适配，新增渠道认证服务；计划并非已经完成。
