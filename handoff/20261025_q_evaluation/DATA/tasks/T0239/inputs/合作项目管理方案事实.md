# 合作项目管理方案事实资料
受众：双方工作组。

项目周期16周，阶段1四周材料整理、阶段2六周系统配置、阶段3四周测试、阶段4两周培训。总费用80万元，付款30%启动、40%配置验收、30%最终验收。材料变更通过书面变更单，未批准追加不进入范围。双方每周会议、问题表含责任人和截止日。

## 目标与范围
16周项目建设企业设备知识库，输入120份确认版资料，交付目录、权限工作区、检索、导出、30条确认样本测试记录和2场培训；不含客户所有历史聊天、额外OCR或底座源代码所有权。
## 四阶段计划
阶段1为2026年10月12日至11月8日四周，客户数据管理员交目录/版号，供应商整理与去重，双方确认字典。阶段2为11月9日至12月20日六周，配置权限/检索/导出并演示；阶段3为12月21日至2027年1月17日四周，用确认样本测试并留缺陷；阶段4为1月18日至31日两周，交操作手册、培训和验收材料。
## 职责与交接
客户项目经理确认范围/样本/验收，客户管理员确认数据版本与权限，供应商交付经理排期，研发实现配置，测试负责人保存结果。每周三会议，问题表列编号、事实、影响、责任、截止日与状态；决策变更需双方授权人确认。
## 付款和证据
80万元含税，启动30%为24万、配置验收40%为32万、最终验收30%为24万；不得仅按日历到点称已达验收。付款凭据、验收记录和模型/文件版本分别保存；第三方按量费未纳入合同总价，需另行确认。
## 风险与变更
缺文件版本、权限配置待确认、样本答案缺失、现场网络和导出版式是已知风险。范围新增按变更单说明工期/费用/验收影响，未签不纳入；不以“全部交付”掩盖待客户依赖。冲突由双方项目经理先协调，重大事项交管理层。
