# 公司2026年10月社保基数调整实施通知
这是公司批准的本次计算口径，供材料整理，不要求判断地方政策或法律效力。适用范围为员工明细中的在岗人员，10月起执行，离职人员不进入本次调整。
缴费基数以上年度月平均工资为基础，低于6200元按6200，高于31000按31000，其余按实际月平均工资，统一保留整数元。职工个人养老8%、医疗2%、失业0.5%；单位养老16%、医疗9%、失业0.5%、工伤0.4%。本次不含住房公积金、不计算补缴，不按工资当月变化自动变更基数。
每人每险种先计算并四舍五入到分，再按个人/单位合计。通知需要列变化前后基数、个人合计、单位合计与差额，财务总额应与人员表合计一致。
实施责任：HR核上年度工资和在岗状态，薪酬专员出表，财务复核，负责人审批后再录入。本次仅整理报告与测算，不实际申报。
