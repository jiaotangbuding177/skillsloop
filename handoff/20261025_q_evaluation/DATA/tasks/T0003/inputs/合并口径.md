# 公司现金流分类口径
产品销售回款、研发补贴为经营流入；材料采购、员工报销、备用金转出、服务外包为经营流出；设备采购与项目投资款为投资流出；股东增资为筹资流入。
银行利息收入按公司本报告口径单列“经营流入—利息收入”，不混入销售收入。流水每条同时只能入一个类别。金额为人民币元。日期包括起止日；无需税务判断。
报告列经营/投资/筹资收支小计和净额、总净额；明细保留流水ID与摘要；未匹配摘要列待核，不猜分类。
主体单独报表中的内部往来收款归“经营流入—内部往来”，内部往来付款归“经营流出—内部往来”，分别完整展示；集团层只抵销匹配对。
内部匹配编号IC-20260612-01：母公司TA001收入120000元对应子公司TB001支出120000元；为内部往来且仅在合并层抵销。未匹配的内部记录另列待核，不能自动按金额抵销。
