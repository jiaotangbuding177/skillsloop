岗位说明书（JD）

生产制造运营总监

一、公司与岗位背景

云衡巡检设备公司是复杂恶劣场景机器人巡检的开创者，全国出货量第一，复杂恶劣场景市场占有率超60%。集团正处于科创板上市准备阶段（2023-2027战略目标），产品涵盖四大系列（复杂恶劣场景巡检机器人、常规场景巡检机器人、智慧安全监测专用设备、作业机器人），覆盖电力、石化、矿业、冶金四大高危行业，服务国家能源集团、华能、国电投、大唐、国家电网、宝武钢铁、山东能源等15+头部央企客户。

公司当前拥有三个生产场地——广州（总部）、山东临沂（新建）、安徽淮北（成熟运行），正处于从初创期向成长期转型的关键阶段。生产制造环节面临多场地协同、生产模式重构、管理体系从零搭建等多重挑战，亟需一位既有大型企业规范化管理功底、又能适应高科技机械产品柔性生产特点、还能在初创成长期环境中快速落地的资深生产管理人才，全面搭建生产运营管理体系。

二、岗位概览

三、当前生产运营现状（候选人入职前需了解的真实背景）

本公司以坦诚态度向候选人说明现状。这是一份"从混乱中建体系"的工作，而非"接手成熟团队做优化"的工作。如果你更擅长在规范环境中做精细化管理，本岗位可能不适合你。

1. 三个生产场地的差异化定位

2. 亟需解决的核心问题

•  广州生产模式转型：原按标准化生产模式设定，但实际生产内容为定制款/初代产品/研发型产品，研发与生产职责边界不清、推诿严重。现已决定改为"研发团队主导、资深生产技术人员协助"模式，但两者的配合分工机制需要由本岗位来界定和落地

•  仓库管理混乱：流程不清晰；现有信息系统不能很好支持库存管理与跨场地调拨，大量工作依赖手动完成

•  生产计划职能缺失：无合适人员负责生产计划排期、采购协同、入库品质管控，流程制度缺乏或未有效执行

•  生产现场布置不专业：三个场地的布置不符合机器人产品的生产环境要求，现场管理混乱

•  跨场地调度无机制：哪些订单在广州/临沂/淮北生产缺少决策规则；跨场地物料调拨依赖人工协调，库存无法合理利用

3. 已有条件（非全部从零开始）

•  公司已有ERP类信息系统，但不满足跨场地仓库管理与调拨需求，需评估升级或替换

•  已有采购人员，但与生产计划脱节，需统筹整合进生产运营体系

•  安徽淮北基地标准化生产已成熟稳定，可作为管理体系的参照样板

•  公司业务增长强劲、订单充足，生产体系改革有明确的业务牵引

四、岗位职责

（一）生产运营管理体系搭建（核心职责，精力占比约35%）

1. 设计"双轨制"生产管理模式

•  生产I（广州模式）——研发主导的柔性生产：

•  定制款、初代产品、研发型产品由研发设计人员主导生产过程

•  界定研发人员与生产技术人员在生产各环节的职责边界（方案设计、工艺执行、过程记录、质量把关、问题反馈、改进迭代）

•  广州仅保留仓管+少量资深现场技术人员编制

•  建立工艺与质量全程跟踪记录机制，确保可追溯

•  生产II（临沂+淮北模式）——规模化标准化生产：

•  临沂：从零搭建生产及管理团队，规划工艺布局与产线，打造全国可复制模板

•  淮北：优化现有标准化生产流程，根据订单灵活扩缩

2. 搭建生产计划与物料控制体系（PMC）

•  从零建立PMC职能：销售订单→生产排程→物料需求（MRP）→采购协同→车间生产→入库→出货全链路管理

•  建立订单分配决策机制：根据产品类型、订单规模、交付周期、场地产能、成本结构，明确"哪类订单去哪个场地"的调度规则

•  建立产能评估与三场地负载平衡机制

•  建立生产异常响应与升级处理机制

3. 搭建品质管理体系

•  建立来料品质管控（IQC）、制程品质管控（IPQC）、出货品质管控（OQC）三道关卡

•  设计问题追溯机制：质量问题能定位到设计端、工艺端、供应链端的源头

•  针对机器人产品特性（防爆认证、煤安认证、可靠性要求），建立专项品质控制点

•  建立品质数据看板与月度品质分析报告机制

4. 搭建仓库管理与跨场地物料体系

•  重新设计仓库管理流程：入库、出库、调拨、盘点、报废全流程规范化

•  评估现有信息系统，决策升级或替换（WMS/ERP模块），实现三场地库存实时可视与智能调拨

•  建立物料编码体系、BOM管理体系、安全库存机制

•  建立呆滞料预警与处理机制，通过跨场地物料合理调拨，降低整体库存水平

5. 统筹整合采购职能

•  将现有采购人员整合进生产运营体系，建立"生产计划驱动采购"的协同机制

•  建立供应商管理基础流程：准入评估、交付考核、质量追溯

•  建立采购提前期与安全库存的联动机制

（二）三个生产场地的实际运营管理（精力占比约35%）

1. 广州生产场地——模式转型落地

•  与研发负责人协同，落地"研发主导生产"的具体协作机制（研发驻场要求、现场反馈流程、过程记录规范、改进闭环）

•  主导广州生产部门人员盘点与整改，重新定岗定编，妥善处理人员优化

•  在场地极为有限的约束下，重新规划现场布置，最大化空间利用效率

2. 山东临沂生产场地——主力基地从零建设

•  主导临沂生产管理团队搭建：招聘生产主管、班组长、核心技术人员、品质人员

•  设计临沂生产基地工艺布局、产线规划、仓储区域规划，确保符合机器人产品生产环境要求

•  制定临沂从首单试产到批量爬坡的路线图

•  将临沂管理体系文档化、标准化，输出可复制到未来新分公司（无锡、赣州等）的生产管理模板

3. 安徽淮北生产场地——成熟基地优化

•  梳理淮北现有流程，保留成熟做法，补齐制度短板

•  将淮北纳入统一的三场地调度与物料体系

4. 三个场地的现场管理

•  按机器人产品生产环境要求，重新规划三个场地的功能分区、物流动线、5S管理

•  建立生产现场巡检与定期审计机制

（三）信息系统建设（精力占比约10%）

•  全面评估现有ERP/WMS系统的能力与缺口

•  主导系统升级或替换的选型、实施、上线、推广全流程

•  确保系统落地后支撑：三场地库存实时同步、跨场地物料调拨、生产计划排程、采购协同、品质数据采集

（四）团队建设与人才培养（精力占比约15%）

•  搭建生产运营管理团队：生产计划（PMC）、品质管理（QC）等关键岗位从零招聘与培养

•  建立各场地生产人员的培训体系与技能矩阵

•  建立生产运营的例会、报表、复盘机制（周例会/月度经营分析）

•  为公司培养储备未来的生产基地管理人才，支撑全国分公司复制扩张

（五）向上管理与跨部门协同（精力占比约5%）

•  直接向CEO/总裁汇报生产运营状况与改革进展

•  与研发部门建立深度协作机制（广州模式转型关键）

•  与销售部门对接订单需求与交付承诺

•  与财务部门协同成本核算与库存资产盘点

•  有精益生产（Lean）或六西格玛落地实践经验

•  有在场地受限条件下（如广州总部）做产线优化的实战经验

明确不适合的人群（降低双方试错成本）

•  习惯层层汇报、需要长期决策流程、无法接受初创企业快速变化节奏的管理者

•  只擅长战略规划、不擅长亲自动手解决现场问题的管理者——本岗位前90天就要下车间、理仓库、定规则
