# T0232 · 可填写的采购报价表单

类别：ASSIST。状态：DRAFT_PENDING_HUMAN_REVIEW。

## 原始委托

禾原采购希望把重复填写的器材报价做成可离线使用的表单，请根据产品目录.csv、客户样例.json、字段契约.json和业务规则.md交付报价表单.html及使用说明.md。表单支持选择多个商品、数量、客户信息和日期，计算未税额、9%税额与含税总价，并可导出可读CSV；用附件样例演示，校验空客户、非法数量和不存在型号，页面不连接真实采购系统。

交付：报价表单.html、使用说明.md
